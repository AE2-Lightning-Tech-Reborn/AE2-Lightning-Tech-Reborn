# 大型过载处理工厂配方接入与机器参数

[文档首页](../README.md) · [工厂设计目录](设计目录.md)

本机向框架提供源配方适配、中央核心用途、工艺授权和执行预算，使用框架的真实材料分配、资源消耗与恢复契约。普通样板的输入输出描述用于发布，完整绑定在首次真实执行发生；这是本机对[通用配方编译](../通用多方块框架/加工/配方描述与样板编译.md)的时机选择。

## 基础配方与工艺核心

本节的基础目录与额外工艺授权只适用于 T1–T4 普通工厂；苍穹专用工厂使用[苍穹专用成型](结构与建造设计.md)的唯一配方类型。处理核心决定“每 tick 能做多少”，工艺核心决定“允许做哪些额外工艺”。工艺核心仓保存真实核心物品，不需要 ME 节点、不占频道；授权在本厂所有加工仓间共享，不受这些仓接入哪个网络影响。同类核心重复放入不叠加速度、产量或解锁范围，核心不作为每次加工耗材。

| 配方来源／工艺 | 解锁要求 | 边界 |
| --- | --- | --- |
| 过载工厂 `ae2lt:overload_processing` | 基础开放 | 读取最终有效目录，包含现有手写兼容配方及最终保留的处理器包装配方 |
| AdvancedAE 反应仓 `advanced_ae:reaction` | 基础开放 | 保留当前过载工厂已适配的反应仓范围及成本口径，源模组和配方须实际存在 |
| LT 闪电模拟 `ae2lt:lightning_simulation` | 闪电模拟工艺核心 | 保留源配方材料、闪电等级及其他执行条件 |
| LT 闪电装配 `ae2lt:lightning_assembly` | 闪电装配工艺核心 | 与闪电模拟分别解锁 |
| LT 水晶催化 `ae2lt:crystal_catalyzer` | 水晶催化工艺核心 | 水晶仓生成条目也必须满足此授权及真实催化材料条件 |
| NeoECO 集成工作站 | 集成工作站工艺核心 | 接入 `neoecoae:integrated_working_station`；不按整个模组名称放行其他工艺 |
| AE2 Crystal Science 晶能聚合、晶能粉碎、电路蚀刻 | 对应工艺核心，三类分别解锁 | 适配各自实际配方类型与条件，不将该模组全部配方一并开放 |
| ExtendedAE 水晶装配器 | 水晶装配工艺核心 | 接入 `extendedae:crystal_assembler`，不连带解锁切割器、修复器或普通工作台配方 |

**解锁按源配方工艺判断，不按配方 ID 命名空间或产物所属模组判断。** 例如现有过载工厂目录中的 NeoECO 晶体锭、水晶科技处理器仍基础开放；NeoECO 提供的反应仓配方也保持基础开放。水晶科技或 NeoECO 注册到 EAE 水晶装配器的配方则使用水晶装配工艺核心，不能因为另有同产物的基础配方就绕过该源工艺授权。

所有适配只读取最终 RecipeManager 中仍存在的源配方，不补回被 KubeJS 删除的内容。工艺核心只开放已正确适配的配方；随机输出、特殊输入、环境条件或额外成本无法完整表达时，条目保持不支持并显示原因。核心制造配方应体现对应工艺的取得门槛，具体造价待平衡。

工艺核心增减时更新本厂工艺版本，使相关执行缓存失效。首次真实匹配只搜索当前获准的工艺；每次提交前复核授权。已知来源且失去授权的条目停止发布和新执行；尚未绑定的普通样板在首次执行时验证，不为判断工艺而提前逐槽完整搜方。未提交的托管材料按来源退款，已经生成的产物继续交付。重新装入核心后按当前配方与工艺版本惰性重建。


## 0t 加工与整机预算

0t 表示已经具备实际材料、成本和交付空间的操作在本次服务器执行中完成，不要求等待 4 tick，不保存逐 tick 加工进度。缺料、缺电、等待调度和等待回网仍可使任务停留，不能把这些等待说成产物已完成。

核心限制的是**每 tick 累计完成的源配方操作份数**，不是瞬时在途数量。设本 tick 核心额度为 `P`，已完成为 `used`，则剩余额度为 `P - used`；操作完成后不返还当 tick 额度。若一份样板等于 4 次源配方，完成 100 份样板就扣 400 份额度。

所有仓、CPU 派发、被动生产与完成唤醒共享同一预算，不能各自获得完整 `P`。除源配方份数外，还要限制实际配方匹配工作、外部存储调用和输出交付工作；核心升级不解除服务器工作预算。同 tick 的多次调用、回调或重入不能重置计数。

每批成本由确定的源操作数计算。材料、产物和闪电按适配器定义的单份关系精确倍增；普通工厂的 0t FE 加价先作用于一份源操作，再乘实际次数，避免拆单改变价格。普通工厂的具体加价倍率与制造配方待定，不能通过一次只扣单份费用却输出整批来实现“高效”。苍穹专用档按[苍穹专用成型](结构与建造设计.md)保留零加工 FE／闪电成本，仍完整扣除材料和源操作额度。

当次可接受数量同时受材料实际分配、已获准的工艺、本次可实际支付的 FE 与本 tick 功率额度、闪电、整机剩余额度和输出/退款空间限制。FE 可由外部储能或所属 ME 网络提供，所有来源共用全厂消耗上限。费用必须完整支付后才能完成对应份数。可安全倍增的确定性配方按“描述＋数量”执行，不创建逐份对象；动态输出或特殊条件只有在适配器能够证明正确处理时才支持。


## 首次执行初始化与 reload

### 缓存内容和边界

放入样板时只解析其输入、输出声明，不搜索真实配方。首次有实际材料执行时，完整匹配真实配方，检查输入分配、数量倍率、组件、流体、全部输出及副产物，再建立执行缓存。

执行缓存至少绑定：

- 仓室/槽位身份、样板或水晶材料版本；
- 当前配方、标签及相关适配规则代次；
- 当前中央核心种类、机器用途、工艺核心版本与该源配方所需的授权；
- 实际材料签名及输入分配关系，不能只按物品 ID 或样板对象地址判断；
- 源配方 ID、一次样板对应的源操作数；
- 验证后的单份输出、FE/闪电等成本和常驻材料条件。

同一材料签名与代次下复用执行描述，不重新搜整张配方表。真实提取数量、能源、常驻材料是否仍在、输出空间和权限仍在每次提交前检查。不能仅缓存第一次的产物后，对以后任意替代材料直接倍乘。

### 惰性失效

配方重载、KubeJS 最终配方变化、标签更新、样板更换、水晶材料变化、机器用途或中央核心变更、工艺核心增减和相关配置变化都使相应缓存过期。重载完成后下一次执行才重建，不能在 reload 当帧遍历全部工厂、全部样板并探测主网。

配方缓存和已生成水晶样板目录必须使用当前代次。水晶目录的旧条目立即停止发布，新目录可按有界工作重建；普通样板的声明可保留，但已知缺少工艺授权的条目停用，旧执行缓存不得继续放行。样板/材料版本、工艺版本和代次在提交前复核；跨 tick 的待重试记录只保存真实托管资源，不保存旧配方仍可执行的承诺。

只有“该代次、该实际材料签名确定没有合法配方”等确定失败才做负缓存；缺料、缺电、临时无法取料和输出受阻不能被永久标成无效配方。替代原料签名变化时可重新匹配。已完成的真实产物不随 reload 重新生成或删除。


## 参数状态

已定参数为固定 9×7×9 结构、由中央核心选择普通／苍穹专用用途、背面九仓位、样板仓 36／144 槽和每厂最多一个工艺核心仓；苍穹专用档为每 tick 1,024 次源操作、0t、零加工 FE／闪电。待定参数为工艺核心仓与水晶仓的槽位数、T1–T4 每 tick 份数与 FE 数值、普通工厂 0t 加价/各核心造价、内部运行预算及水晶条目的新机平衡。第三方适配需按目标版本验证全部输入、输出与特殊成本后才算可用。已定额度是设计上限，实际吞吐仍需验证，不宣称“不掉 TPS”，实现完成前不把设计验收项写成测试已通过。
