# 大型过载处理工厂验收与性能预算

[文档首页](../../README.md) · [工厂设计目录](../设计目录.md)

以下是设计验收要求，尚未代表实现测试已经通过。共用基础先通过[框架通用验收与性能预算](../../通用多方块框架/验收与性能预算.md)，本页验证本机固定结构、双用途和 0t 配置对共用机制的接入效果，不重复定义通用算法。

## 本机验收

| 领域 | 必须验证的行为 |
| --- | --- |
| 范围 | 普通处理核心 T1–T4 或苍穹转换核心两条成型路线；背面九仓位允许四类功能仓，样板仓有两种容量；没有旧稿的物流/并行/调度仓 |
| 成形 | 仅背面中央九位接受功能仓；四朝向、错误成员、重复工艺仓、相交控制器、卸载与恢复正确；稳定结构不逐 tick 扫描 |
| 苍穹成型 | 中央苍穹核心且星舰位置有效才接管，至少一个样板仓；原库存／进度未清空时不接管；普通核心不能靠工艺仓解锁苍穹 |
| 苍穹独占 | 只接受 `ae2lt:firmament_conversion`，过载／反应及额外工艺均关闭，水晶仓不生成催化条目；用途变化与 reload 不能复用旧授权 |
| 苍穹执行 | 全厂每 tick 最多 1,024 次源操作，按单／被动／多仓共享，完成不返还当 tick 额度；四倍样板最多 256 份；0t、零加工 FE、每次 1 极高压闪电、多输出完整结算 |
| 苍穹接管 | 成型时单机 tick 与手动／管道进料停用；解散后恢复且资源不重复；成型／重建不重抽自然奖励 |
| 多样板仓 | 36／144 槽，多仓混装；扩展仓四页均发布和保存，界面换页不影响执行；拆除或降级不丢隐藏页样板 |
| 工艺授权 | 普通工厂基础反应仓和过载目录保持开放；新增工艺分别解锁；按源类型判断，不误锁已有兼容配方或跨类型绕过核心 |
| 核心变更 | 重复核心不加速；取走核心后旧缓存停止新加工；被动托管输入退款，已生成产物继续交付；装回后惰性重建 |
| 供电 | 无能源仓时 ME 自动供电；外部优先、仅外部模式和不足等待正确；多仓多面不突破整机上限；不同网络费用不串用；换算、部分扣电和模拟调用守恒 |
| 闪电下限 | 普通基础配方、第三方工艺和水晶条目每次至少 1 高压；原方更高费用保留且不重复叠加下限；苍穹每次 1 极高压 |
| 批量闪电 | 一份四倍样板收四次源成本；产出 16 件或四种产物仍按一次源操作计费；苍穹 1,024 次收 1,024 极高压或代偿 4,096 高压；部分接受只结算接受份数 |
| 单向代偿 | 默认允许 4 高压补 1 极高压，不需要矩阵；2 极高压费用可付 1 极高压加 4 高压；高压需求不能反向用极高压支付；混合扣取、部分失败退款和交付重试不重复计费 |
| 惰性绑定 | 放入普通样板不全量搜方；首次真实输入初始化；同签名命中；组件或替代原料变化正确失效 |
| reload | 配方删除、标签输出变化及成本修改后旧缓存不能放行；重建不集中扫描所有机器；已生成产物保留 |
| 输入分配 | 重叠 Ingredient、组件、流体及样板倍率准确，不重复使用同一份材料 |
| 按单 | 100 份接受 24 份返回 76；拒收只有 CPU 退款；接受后异常不重复返料 |
| 0t 回传 | 扣费完成才产出；CPU 先完成派发记账再收货；Sink 拒绝与普通 CPU 路径保留实际产物 |
| 被动 | 不发布接单样板，不发起缺料合成；首次实际提取后绑定；部分提取、失败匹配和退款受阻均守恒 |
| 调度 | 空闲 100 tick 轮询；完成额外唤醒；事件合并、错峰、无递归、无停服补轮询；预算耗尽可续接 |
| 核心预算 | 同 tick 反复调用、多个仓/CPU、0t 循环配方都不突破累计份数和工作额度 |
| 水晶目录 | 工艺授权和材料条件均满足才发布；多模式输出区分；取走材料或核心、模组缺失、配方删除和空输出标签立即失效 |
| 水晶费用 | 常驻材料不消耗、不作为 CPU 输入重复返还；实际流体、FE、闪电与输出按明确源操作数结算 |
| 水晶共用 | 与普通样板同时接单或被动时共用缓存规则、执行器、回流和全厂额度，不各自加速 |
| 恢复 | 断网、满网、拆仓、拆核心、区块卸载与正常保存/加载后，原料/产物/退款各有唯一归属 |
| 性能 | 测试大量网络键、存储总线、多工厂、大样板目录、缺料、满输出和连续完成；记录增量 MSPT、调用数与 GC |


## 性能预算

库存工作随本轮实际检查的样板输入和配方候选增长，不随主网全部资源种类逐仓重复扫描。避免在热路径调用全量库存枚举，也不能仅因为 API 名为“缓存”或“监听”就假定没有全网刷新成本；目标 AE2 版本的实际路径必须检查。

每台工厂限制本轮配方匹配、网络查询/提取/插入和交付工作；服务器再对所有工厂安排总工作预算。共享查询只作为提示，权限不同不混用缓存，实际提交重新核验。外部存储单次调用也可能昂贵，总预算只能限制调用数量，不能中断一个已经进入的第三方调用，必须在大网络环境实测。
