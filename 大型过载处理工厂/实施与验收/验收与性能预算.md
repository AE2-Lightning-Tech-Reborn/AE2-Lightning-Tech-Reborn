# 大型过载处理工厂接入验收

[文档首页](../../README.md) · [工厂设计目录](../设计目录.md)

先通过[框架通用验收与性能预算](../../通用多方块框架/验收与性能预算.md)。本文件只验证本机选用配置、配方来源和闪电适配，不重复定义仓室、调度或恢复的通用算法。

## 工厂接入场景

| 领域 | 本机成功条件 |
| --- | --- |
| 预设与角色 | 选用框架三种预设，控制器在外表面，内部中央位置映射为过载处理核心，棱角映射为过载约束框架 |
| 装配约束 | 外壳至少 32 块、仓室总数不超过 64、至少一个能源仓；各类安装数量符合工厂装配表 |
| 配方覆盖 | 逐类对照 `OverloadProcessingRecipeCatalog` 的本体、处理器推导与已适配反应仓；来源模组缺失或 KubeJS 删除后不私自恢复 |
| 格式映射 | 保留源配方最多 9 种物品输入、1 种输入流体和 1 种输出流体的限制，准确转换普通物料、产物、FE 与闪电成本 |
| 运行参数 | 工厂的基础份数/通道、65,536/64 封顶、最少 4 tick、3:1 接收权重和事务预算被框架正确应用 |
| 输出配置 | 持续生产选用 ME 输出仓优先、普通仓兜底；启用成品目标时使用框架统一计数，样板任务仍原路交付 |
| 闪电接入 | 空标记且样板无闪电项时仍可支付成本；仅样板总成联网、没有 ME 输入/输出仓时也可完成有闪电成本的任务 |
| 闪电策略 | 样板任务选择接单总成网络；持续生产优先 ME 输入仓端点，再按本机策略选择其他端点；实际来源遵守框架权限与去重规则 |
| 等级替代 | 两种闪电等级准确计量，处理核心装入闪电塌缩矩阵后按 4:1 用高压补足极高压；多键支付失败进入框架补偿流程 |
| 费用隔离 | FE、AE 待机消耗与闪电分别计费，闪电不重复作为样板物料；无闪电成本的配方不额外要求联网，已支付闪电不因恢复重扣 |
| 旧机兼容 | 工厂使用独立 ID，旧单方块工厂保留原非线性能耗与存档；新机采用框架线性策略 |
| 专有展示 | 工厂名称、材料、处理核心和闪电不足/等级替代信息正确接入通用界面及指南 |

## 工厂实测组合

使用本机三种预设、单/多总成、有/无 ME 物流及闪电等级替代配置，运行 AE 任务、持续生产、混合生产和多工厂同服场景。共用扫描、缓存、传输与存储预算按[框架性能规则](../../通用多方块框架/验收与性能预算.md#性能预算)执行，记录本机配方覆盖和参数应用结果。
