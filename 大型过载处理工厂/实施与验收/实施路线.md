# 大型过载处理工厂接入路线

[文档首页](../../README.md) · [工厂设计目录](../设计目录.md)

## 前置条件

[完整框架验收](../../通用多方块框架/实施与验收.md)已通过，包括搭建、通用仓室、配方处理、消耗、调度、产出与恢复。工厂接入不承担这些通用模块的首次实现。

## 接入步骤

1. 注册独立工厂 ID、控制器、外壳、处理核心和模型资源；保留旧单方块工厂。
2. 提交 `LargeOverloadFactoryDefinition`，引用框架预设与模板，映射工厂角色并配置仓室白名单与安装上限，直接使用框架预览和搭建。
3. 通过 `OverloadProcessingRecipeCatalog` 注册来源适配，转换为统一执行描述，使用框架样板编译与材料分配。
4. 配置基础并行、通道封顶、线性 FE、最短时间、调度权重及事务预算，实例化框架运行时。
5. 注册 LT 闪电成本适配器，定义来源网络、等级替代、真实扣除与返还策略，由框架提交与恢复批次。
6. 配置控制器展示、配方分类、语言和指南；通用仓室菜单与库存保持框架实现。
7. 按[工厂验收与性能预算](验收与性能预算.md)验证现有配方覆盖和整机接入效果。

不另建 `FactoryScheduler`、资源托管、产物回流或 SavedData 状态机。若工厂接入暴露通用能力缺口，先完善框架契约和实现，再通过接口接入。

## 兼容与资源

旧单方块工厂 ID 和原有非线性能耗保持不变，不强迫玩家改建产线。矩阵与天枢按框架迁移文档分阶段推进。新模型、材质和指南保留许可证与必要署名，不复制第三方已被删除或未安装的配方。
