# 大型过载处理工厂结构接入设计

[文档首页](../README.md) · [工厂设计目录](设计目录.md)

本机使用框架的[通用结构预设与形状生成](../通用多方块框架/结构预设与形状生成设计.md)。预设尺寸表、长方体算法、锚点定位、模板选择与搭建流程均在框架维护，本文件只声明工厂的选用配置和方块映射。

## 选用预设

默认选择框架标准工业型 `thunderbolt:standard_industrial`，同时允许集群生产型 `thunderbolt:cluster_production` 与中央处理型 `thunderbolt:central_processing`。本机沿用这一预设族的尺寸范围、步长、前表面控制器锚点和内部中央模块锚点，不提供专用形状生成器。

## 工厂角色映射与装配约束

| 框架角色或位置 | 工厂映射 |
| --- | --- |
| 前表面控制器 | 大型过载处理工厂控制器，持有机器身份 |
| 固定棱角 | 过载约束框架，不允许仓室替换 |
| 默认可替换表面 | 过载工厂外壳，可按白名单替换为观察玻璃或通用仓室 |
| 内部中央模块 | 启用一个过载处理核心，表示机器类型与配方结构要求；不替代能源或并行仓 |
| 其他内部位置 | 沿用所选预设的留空要求；扩展结构通过框架模板声明 |

至少保留 32 块真实工厂外壳，观察玻璃和仓室不计入这个数量；仓室总数最多 64 块，至少一个能源仓。各类仓室的安装上限见[仓室接入方案](仓室接入方案.md)。控制器、固定棱角和处理核心不能被仓室替代。

## 数据包模板

以下是工厂结构定义引用框架预设的示例。`default_preset` 和 `allowed_presets` 由框架解析，工厂只提供角色映射与本机约束；完整定位及预设格式见[框架预设设计](../通用多方块框架/结构预设与形状生成设计.md#预设格式与机器引用)。

```json
{
  "format": 1,
  "machine": "ae2lt:large_overload_processing_factory",
  "default_preset": "thunderbolt:standard_industrial",
  "allowed_presets": [
    "thunderbolt:standard_industrial",
    "thunderbolt:cluster_production",
    "thunderbolt:central_processing"
  ],
  "constraints": {
    "minimum_casings": 32,
    "maximum_hatches": 64,
    "minimum_energy_hatches": 1
  }
}
```

本例省略角色注册描述，其方块映射按上表由工厂接入层提供。数据包若扩展本机可选外形，仍由框架统一加载、编译、预览与扫描，不另建工厂模板协议。

## 本机成形与运行要求

成形要求结构正确、一个控制器、一个处理核心、至少一个能源仓，并满足上述计数规则。其余仓室按生产方式配置：没有样板总成仍可持续生产；没有可用输出路径时，仅暂停需要该路径的配方。

零个并行仓或调度仓仍提供本机基础 `1` 份操作与 `1` 个配方通道。实际配方需要闪电时，已绑定活动 ME 端点必须能取得所需成本，不要求 ME 输入仓预存或标记闪电。

预设、尺寸或模板变更统一使用[框架维护与搭建流程](../通用多方块框架/搭建与预览设计.md#尺寸与模板变更)，保留在途任务与仓室资源。
