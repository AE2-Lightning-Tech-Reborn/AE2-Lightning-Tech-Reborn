# 球状闪电反应堆启停与事故处理

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

## 首次点火

首次建立球状闪电需要同时具备：

1. 完整的中央反应腔。
2. 六套完整且核心在线的磁极阵列。
3. 放入控制器的球雷胚核。
4. 高能相变燃料。
5. 一只闪电苦力怕。
6. 满足最低磁场启动条件。

闪电苦力怕提供首次建立球雷所需的活体雷电现象与初始高能扰动。具体的放置、识别、融合过程以及点火演出后续定义。

## 球雷建立状态

首次成功点火后获得“球雷已建立”状态。只要没有发生灾难性约束崩溃，该状态可以保留。

正常停机、燃料耗尽和普通维护均不要求重新制作胚核或重新准备闪电苦力怕。这里的“熄火”表示反应衰减并进入休眠，不表示清除球雷建立状态。

## 停机与恢复运行

| 情况 | 处理过程 | 结果与边界 |
| --- | --- | --- |
| 正常停机 | 控制器停止燃料注入，球雷逐渐降低活动并进入休眠 | 胚核与球雷建立状态保留，不惩罚正常停机 |
| 单纯燃料耗尽 | 输出逐渐降低，反应自然衰减并进入休眠 | 不因断料而爆炸，不清除球雷建立状态 |
| 恢复运行 | 确认结构完整、磁场系统正常且燃料充足后恢复反应 | 不重复首次点火流程；不预先规定补料后自动启动 |
| 紧急停堆（SCRAM） | 立即停止燃料注入，主动降低反应负荷，尝试让球雷休眠 | 用于抢救，不能保证在严重事故条件下成功 |

紧急停堆不是立即清除所有危险状态。如果阵列已经严重损坏、磁通过高、稳定度接近崩溃，且球雷仍处于极高能状态，停止注入后仍可能发生事故。

单纯断料导致安全休眠，与既有高能失稳在断料或 SCRAM 后继续恶化，是不同情况；停止新燃料不应被当作瞬间消除存量能量。

## 约束崩溃的触发原则

真正的灾难性事故是球状闪电约束场彻底崩溃。事故由运行与结构状态决定，不以随机概率触发；稳定度低也不直接等于爆炸。

当前建议在以下危险状态同时存在时，才进入真正的约束崩溃：

- 稳定度极低。
- 磁通很高。
- 球状闪电仍处于高能状态。
- 燃料持续注入，或停止注入后反应负荷仍然很高。

具体阈值、持续时间与判定公式尚未确定。设计上区分普通断料、正常停机、设备故障和灾难性事故：缺少燃料会使反应衰减，无法约束仍处于高能状态的球雷才是爆炸风险。

## 事故后果

| 对象 | 后果 | 限制 |
| --- | --- | --- |
| 控制器与胚核 | 控制器必定损毁，内部胚核随之消失 | 控制器是唯一明确规定必毁的关键功能块，不另设胚核损坏判定 |
| 中央反应腔 | 部分框架、玻璃与端口损毁 | 不无条件删除整个 7×7×7 结构，保留抢修价值 |
| 六向磁极阵列 | 随机损坏部分磁极结构与功能模块 | 不无条件全部删除；损坏比例可随事故严重度提高 |
| 结构外周边 | 出现若干小范围次生爆炸，表现高能放电逸散 | 可以破坏附近管线和少量装饰，范围不以摧毁整个基地为目标 |
| 连接的 AE 网络 | 瞬间抽空其中的高压闪电与极高压闪电 | 抽空效果不清理 FE、普通物品、普通流体或其他 AE 网络资源 |

“事故不随机”约束的是触发机制；事故已经触发后，外围阵列的具体受损位置可以随机，两者不冲突。

网络抽空的设定解释为：约束场崩溃后，球雷沿 AE 闪电网络的最低阻抗通路吸收网络中可用的闪电能源，并在崩溃中释放。连接网络的识别范围与实际清空方式仍需单独定义，见[待定事项](待定事项.md)。

灾难性事故清除球雷建立状态，后续必须重新完成首次点火。

## 事故后恢复

1. 修复中央反应腔。
2. 修复六向磁极阵列。
3. 重新放置控制器。
4. 重新制作并装入球雷胚核。
5. 重新准备闪电苦力怕。
6. 补足燃料、满足最低启动条件，重新完成首次点火。

事故成本来自结构维修、胚核重制、闪电苦力怕准备和网络闪电损失；损毁比例与次生爆炸范围留待平衡。
