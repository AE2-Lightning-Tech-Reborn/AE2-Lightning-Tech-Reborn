# 球状闪电反应堆设计目录

[文档首页](../README.md)

项目：AE2 Lightning Tech Reborn。设计版本：v0.1。状态：整体设计草案，不代表相关功能已经实现或发布。

球状闪电反应堆是终局大型多方块设施。玩家通过六向磁场阵列的模块配比和燃料注入率，在 FE、现有闪电与原生等离子体三种产出方向之间取舍，并承担相应的失稳风险。

| 文档 | 内容 |
| --- | --- |
| [总体设计](总体设计.md) | 定位、资源流、燃料与物质产物、核心设计原则 |
| [结构与磁场系统](结构与磁场系统.md) | 反应腔、控制器、通用端口、六向阵列与视觉约束 |
| [产出与运行参数](产出与运行参数.md) | 三种模块、C／U／F、燃料注入率、稳定度及产出取舍 |
| [启停与事故处理](启停与事故处理.md) | 首次点火、球雷建立状态、停机、紧急停堆、事故与恢复 |
| [待定事项](待定事项.md) | 配方、数值、结构细节、表现与需要补充定义的边界 |

正文中的“暂定”“建议”“示例”均保留草案性质；注入档位、稳定度区间和阵列间距不作为最终平衡数值。
