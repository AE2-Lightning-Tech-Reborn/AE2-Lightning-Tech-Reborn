## 原草案保留的设计事项

以下内容尚未确定，不把示例数值或定性关系当成最终实现规格。

| 主题 | 待设计内容 |
| --- | --- |
| 高能相变燃料 | 具体配方、制作产线、每桶／每 mB 能量价值、消耗与注入速度 |
| 球雷胚核 | 具体配方、是否使用现有终局材料、制作成本 |
| 原生等离子体后续体系 | 分化种类、加工机器、配方、终局合金与材料体系、材料简化配方 |
| 基础产出 | FE/t、高压闪电产率、极高压闪电产率及其占比、原生等离子体产率 |
| 模块与磁场 | 三类模块系数、C／U／F 最终公式、相互影响与损失计算 |
| 运行负荷与稳定度 | 燃料注入档位、最低启动条件、稳定度公式、状态阈值及惯性变化速度 |
| 供能 | 是否需要基础供能、磁场供能来源与消耗、FE 输入模式是否启用及断电行为 |
| 事故数值 | 约束崩溃阈值与触发时间、损坏比例、事故严重度、次生爆炸数量和范围 |
| 中央结构 | 7×7×7 外壳逐层模板、削角形状、控制器与端口的合法替换位置 |
| 外围结构 | 磁极阵列最终固定距离及坐标定义，空隙格数的计量口径 |
| 视觉与演出 | 球雷模型、光束、粒子、材质、发光、报警、点火过程与爆炸效果 |

## 整理时识别出的待补充边界

这些问题用于后续完善草案，不代表已经新增玩法或确定实现方式。

| 边界 | 需要明确的问题 |
| --- | --- |
| 闪电苦力怕参与点火 | 放置位置、识别范围、融合流程及点火失败时如何处理；与反应空间的方块检查分开定义 |
| 运行中的模块调整 | 是否允许直接替换模块，阵列短暂不完整时如何降负荷、报错或进入失稳 |
| 休眠与状态保存 | 普通维护、控制器拆装和世界重载时，如何保存并恢复胚核与球雷建立状态 |
| 恢复运行入口 | 补充燃料后由玩家手动启动还是允许自动恢复，以及恢复前的完整性检查 |
| 输出受阻 | FE、两档闪电或等离子体无法输出时，如何处理库存、燃料注入和反应负荷 |
| AE 网络事故范围 | 多端口、多网络、子网及外部存储接入时，哪些闪电属于当前连接网络；如何执行抽空而不影响其他资源 |
| 实现接入 | 反应堆的具体实现方式，以及与现有多方块能力或未来通用框架的关系 |

## 当前示例的使用边界

- 约 4 格阵列空隙是结构建议，最终距离固定且六向一致。
- `25% / 50% / 75% / 100% / 125%` 是注入档位示例，不是确定的倍率或流量。
- 稳定度的五档区间用于表达反馈层次，最终阈值、变化速度和事故触发时间仍待平衡。
- 模块作用和产出关系仅确定方向，不隐含线性叠加公式，也不确定最终收益系数。
