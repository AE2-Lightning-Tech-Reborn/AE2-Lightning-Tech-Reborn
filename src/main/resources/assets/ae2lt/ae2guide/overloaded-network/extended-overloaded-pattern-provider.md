# Extended Overloaded Pattern Provider

<ItemGrid>
  <ItemIcon id="ae2lt:extended_overloaded_pattern_provider" />
  <ItemIcon id="ae2lt:extended_overloaded_pattern_provider_upgrade" />
</ItemGrid>

The **Extended Overloaded Pattern Provider** expands the [Overloaded Pattern Provider](overloaded-pattern-provider.md) with paged pattern storage for high-density processing lines.

## Capacity & Upgrading

* **Paged Capacity**: **36 pattern slots per page**, defaulting to **4 pages (144 pattern slots)**; server config supports **1–64 pages**.
* **Shared Feature Set**: Inherits all normal and wireless dispatch modes, blocking strategies, adaptive batching, 20–128 tick active return polling, input filtering, and Overload Pattern support.
* **Crafting or In-Place Upgrade**: Craft it directly or apply an **Extended Overloaded Pattern Provider Upgrade** to a placed Overloaded Pattern Provider to upgrade in place while retaining existing patterns and settings.
