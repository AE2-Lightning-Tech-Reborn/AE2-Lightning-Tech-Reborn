# Hyperdimensional Pigmee Research

This record does not appear in the ordinary guide index. Hover over a **Hyperdimensional Pigmee Fumo** and hold the guide key to reopen the secret it carried back from beyond space and time.

## The Ritual in the Note

Every generated Research Note lists nine offerings (right-click an ungenerated Research Note to roll its list). The first three are always:

1. **Pigmee Core**
2. **Overload Protection Module**
3. **Phase Lock Module**

The remaining six are chosen separately for every note, so always follow the list written in the note you are holding.

First, drop the note directly above an **Atmospheric Ionizer**. Then follow its list from top to bottom, dropping the nine materials separately. A dropped stack may contain extras, but the ritual takes only one item from each. Materials released on the same tick will not fail merely because their order is too close to distinguish.

Finally, load a **Thunderstorm Condensate** into the Atmospheric Ionizer and activate it. If every offering and its order are correct, lightning carries the nine offerings away and leaves behind an enormous **Hyperdimensional Pigmee Fumo**. Pigmee Core, Overload Protection Module, and Phase Lock Module shatter in the lightning one after another. Shortly after, the Pigmee shrinks and can be picked up.

If the material set is correct but the order is not, the lightning burns the offerings and leaves 1–3 **Charred Ritual Fragments**. The note survives; after a successful ritual it remains as a keepsake and cannot be used for another ritual.

## One Remaining Conversion

Craft a Hyperdimensional Pigmee Fumo together with any one of the items below. It performs one boundary-crossing conversion, then returns to being an ordinary Pigmee Fumo.

| Target | Result |
|--------|--------|
| Lightning Rod | Infinite High Voltage Lightning Cell |
| Thunderstorm Condensate | Infinite Extreme High Voltage Lightning Cell |
| Lightning Collapse Matrix | Infinite Lightning Collapse Matrix Cell |
| Bulk Lightning Storage Component | Infinite Storage Cell |
| Tianshu Supercomputer Overload Main Core | Tianshu Supercomputer Multidimensional Main Core |
| Tianshu Matter Warping Matrix Overload Main Core | Tianshu Matter Warping Matrix Multidimensional Main Core |
| Overload Execution Module | Multidimensional Execution Module |
| Overload Protection Module | Multidimensional Protection Module |

The Creative Pigmee Fumo can perform the same conversions without losing its power, and can also copy a Hyperdimensional Pigmee Fumo. JEI and EMI do not show these unusual recipes; this record is the complete clue they leave behind.
