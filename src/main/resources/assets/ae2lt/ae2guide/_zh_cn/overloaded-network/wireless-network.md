# 无线网络

<ItemGrid>
  <ItemIcon id="ae2lt:wireless_overloaded_controller" />
  <ItemIcon id="ae2lt:advanced_wireless_overloaded_controller" />
  <ItemIcon id="ae2lt:wireless_receiver" />
</ItemGrid>

无线网络系统可在无需铺设线缆的情况下，远距离或跨维度扩展过载 ME 网络。**无线过载控制器**在指定频率上广播，一个或多个**无线接收器**调谐到同一频率即可建立虚拟网格连接。

## 组件

### 无线过载控制器

<Row>
  <BlockImage id="ae2lt:wireless_overloaded_controller" scale="4" />
</Row>

**无线过载控制器**是一台兼具无线发射功能的[过载 ME 控制器](overloaded-controller.md)。它在选定的频率上广播自身的网格节点，使远程的无线接收器可以连接到它。

* 提供与普通过载控制器相同的额外频道和能量
* 整个过载控制器多方块结构只需要**一台**无线或高级无线过载控制器作为发射器；其他控制器方块可以继续使用普通过载 ME 控制器
* 每台控制器同一时间只能广播**一个频率**
* 每个频率同一时间只能被一台发射器占用
* 仅支持同维度连接；每条接收器链路有频道容量限制（默认 AE2 频道模式下为 **32 频道**）

### 高级无线过载控制器

<Row>
  <BlockImage id="ae2lt:advanced_wireless_overloaded_controller" scale="4" />
</Row>

**高级无线过载控制器**提供以下功能：

* **跨维度支持**：其他维度中的无线接收器也可以连接到它
* **取消接收器链路频道上限**：网络本身仍受当前 AE2 频道模式与控制器容量约束
* **频率卡接入**：支持使用[过载频率卡](overloaded-frequency-card.md)直接连接 ME 设备和部件
* **无线 FE 供电**：安装 Applied Flux 后，可向兼容机器输送网络中存储的 FE
* **网络管理**：集中查看 ME 设备、FE 供电记录和频率连接，并对支持的设备进行远程操作

### 无线接收器

<Row>
  <BlockImage id="ae2lt:wireless_receiver" scale="4" />
</Row>

**无线接收器**是与无线过载控制器配对的接收端。将它放置在世界任意位置，设置为与控制器相同的频率，即可自动建立虚拟网格连接。

* 空闲功耗 5 AE/t
* 同一时间只能连接一个频率
* 跨维度连接需要发射端为**高级**无线过载控制器

## 搭建步骤

1. 在过载控制器多方块结构中放置或替换一台**无线过载控制器**，右键打开频率界面
2. 选择或创建一个频率
3. 在远程位置放置一台**无线接收器**，右键打开其频率界面
4. 选择相同的频率——接收器会自动与控制器的网格建立虚拟连接

连接建立后，接收器的行为等同于通过线缆直接连接到控制器。接入接收器本地网络的设备可以访问控制器的 ME 网络，包括频道、存储和合成。

## 频率界面

高级无线过载控制器与过载频率卡使用统一的顶部导航。将指针悬停在图标上可查看页面名称。

| 页面 | 用途 |
|------|------|
| 概览 | 查看当前频率、连接状态、权限与网络频道信息；频率卡另有自动连接开关 |
| 频率 | 搜索并绑定已有频率，或创建新频率；使用“断开连接”解除当前绑定 |
| 成员管理 | 查看成员及权限，并在权限允许时调整角色或移除成员 |
| 网络管理 | 在“ME 设备”“FE 供电”“频率连接”三种视图之间切换 |
| 频率设置 | 修改当前频率的名称、颜色及安全设置；所有者可删除频率 |

频率设置与成员操作受角色权限限制。管理员可修改名称和颜色、管理较低权限的成员；安全等级、密码、所有者及管理员角色调整和删除频率需要所有者权限。删除频率不可恢复，其关联的无线连接也会被解除。若仅需切换当前设备或卡片的频率，点击“断开连接”即可解除绑定，切勿误删频率。

### 网络管理

* **ME 设备**：查看网络设备及工作状态。选中设备后，可使用“定位”或“远程打开界面”；远程界面中的返回按钮可返回网络管理。
* **FE 供电**：查看供电路径、来源、目标与实际供电速率。统计包括频率无线供电及其他受支持的供电方式；“解绑无线端点”仅解除所选频率的无线供电，不会断开 ME 链接。
* **频率连接**：查看无线频道链接点及其加载状态，用于检查接收器和频率卡连接。

列表支持搜索、排序及按类型分组。搜索可使用设备名称、类型、模组 ID、维度或坐标，多个关键词以空格分隔；展开分组后可选择单个设备。“定位”会显示坐标，并对可定位的设备进行 15 秒高亮；坐标消息可点击复制。

FE 供电视图可切换 1t、1s、5s、30s 和 1min 统计窗口，数值均以 **FE/t** 表示窗口内的平均实际输出，无输出时段也计入平均值。该数值不代表设备储能或额定输入上限。

远程操作要求目标可用且玩家具有相应权限。支持的设备可跨维度打开原生界面，但网络管理不会强制加载目标区块；不支持远程菜单的设备无法通过此方式配置。频率卡需绑定可用的高级无线发射源后才能进入网络管理。

## 频率安全

频率支持访问控制：

| 级别 | 行为 |
|------|------|
| 公开 | 任何人都可以将接收器绑定到此频率 |
| 私有 | 仅频率所有者和允许的成员可以绑定 |
| 加密 | 需要输入密码才能绑定 |

未绑定的控制器和接收器始终可以访问，不受安全级别限制。

## 使用建议

* 需要跨维度桥接网络时使用高级版本
* 单个接收器需要承载超过普通无线链路的频道数量时，使用高级版本
* 一台控制器可以服务多台接收器，每台接收器各自建立独立的虚拟连接
* 不需要把多方块里的每个控制器都换成无线版本；只有想要额外的独立发射频率时，才需要放置更多无线控制器
