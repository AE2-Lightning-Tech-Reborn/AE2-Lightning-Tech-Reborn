# 彩虹猪咪染色

<ItemGrid>
  <ItemIcon id="ae2lt:rainbow_pigmee_fumo" />
  <ItemIcon id="ae2lt:dye_base" />
</ItemGrid>

**彩虹猪咪**不仅可用于制作 16 色染料和 [猪咪建材](pigmee-building-materials.md)，还可以直接为已有的可染色物品换色。在所有相关合成中，彩虹猪咪都会保留在合成栏内，不会被消耗。

## 单件循环换色

在任意合成栏（含背包的 2×2 合成栏）中放入 1 只彩虹猪咪与 1 件可染色物品，即可将其切换至下一个颜色：

* **16 色循环顺序**：白 → 橙 → 品红 → 淡蓝 → 黄 → 黄绿 → 粉红 → 灰 → 淡灰 → 青 → 紫 → 蓝 → 棕 → 绿 → 红 → 黑 → 白。
* **无色与不可堆叠物品**：无色变体（如玻璃、陶瓦、福鲁伊克斯色线缆、未染色潜影盒）首次换色会转为白色；皮革护甲、盾牌等不可堆叠物品同样支持逐件换色（混合色皮革会先取最接近的标准色再继续循环）。
* **组件保留**：在允许换色的路径中，物品的自定义名称、附魔、存储内容等组件数据会一并保留。

## 四件指定颜色

将彩虹猪咪放在 3×3 工作台正中央，参照对应颜色的染料基底配方位置，把配方中的 4 个**染料基底**替换为 4 件相同且可堆叠的物品，即可一次性获得 4 件指定颜色的成品：

* 摆放位置需与对应颜色的染料基底配方完全一致，不自动旋转或镜像。
* 投入的 4 件物品必须**可堆叠且组件数据完全一致**；不可堆叠物品请使用单件循环换色。
* 使用 4 个染料基底仍按原配方产出 4 个对应颜色的染料；用 8 块圆石围住彩虹猪咪可合成 8 个 [猪咪建材方块](pigmee-building-materials.md)。

## 支持的染色范围

支持原版 16 色方块与物品、猪咪彩色素板/框板及台阶、AE2 与过载线缆，以及按物品 ID 具有完整 16 色变体的模组物品。无色基础物品通过当前已加载的等量染色配方（`n 件同种原料 + 染料 → n 件彩色成品`）自动识别；若同一原料存在多种不同类型的染色产物歧义，则不会自动选定。
