# 大型过载处理工厂

固定 **9 × 7 × 9** 的多方块加工设备，可同步执行配方。中央处理核心决定整台工厂共享的吞吐预算。一个样板若编码了四次源配方，就消耗四次操作额度并支付四份成本。

## 建造

控制器位于正面中心。结构向左右各延伸四格、上下各三格，向控制器背后延伸八格。中央处理核心放在控制器正后方第四格，其余内部空间保持为空气。

普通工厂至少需要一个样板仓或水晶仓，可以放多个加工仓，但最多只能有**一个工艺核心仓**。所有仓室各占一个背面功能位。例如一个工艺核心仓、一个能源仓和七个扩展样板仓，共可放 **1,008 个样板**。

控制器的**结构预览**用粒子标记位置：蓝色为框架／外壳，紫色为中央核心，黄色为背面功能位，红色为被占用的内部空气。**建造外壳**分批消耗玩家背包中的方块，仅填充空位并遵守放置检查。处理核心和需要的仓室自行放置。界面同时显示缺少的材料和错误方块坐标。

## 仓室与网络

* **样板仓：**36 个编码加工样板槽。
* **扩展样板仓：**144 槽，分四页；所有页都参与 CPU 样板发布。
* **水晶仓：**默认九个常驻催化材料槽。放入催化材料后，自动发布对应水晶／粉末配方的虚拟加工样板。真实流体仍是样板输入，常驻材料不消耗。不需要的配方可在条目按钮上禁用。
* **工艺核心仓：**默认九槽。工艺核心解锁配方类别，重复放入不增加吞吐。
* **能源仓：**可选 FE 输入。多个能源仓共享处理核心的 FE 缓冲和吞吐上限。

每个加工仓独立占用**一个 ME 频道**，只从背面朝外的一侧接网，可以分别连接不同的 ME 网络。该仓的材料、闪电、自动 ME 供能和普通回流均属于同一个网络。工艺核心仓、能源仓没有 ME 节点，也不占频道。同网接九个加工仓时，需要保证频道容量足够。

每个加工仓可独立切换两种互斥模式。**CPU 模式**发布启用的样板；**被动模式**撤回 CPU 样板，并从本仓网络主动取料。被动加工先真正提取一份样板原料，再验证配方，随后按共享预算扩批；首份材料只结算一次。空闲约每五秒唤醒，成功加工还可在同 tick 内唤醒后续工作。

## 配方解锁

普通 T1–T4 工厂默认支持最终生效的过载处理配方和 AdvancedAE 反应室配方，包括已经加入这两个目录的兼容配方。

| 工艺核心 | 额外开放的源配方 |
| --- | --- |
| 模拟室 | LT 闪电模拟室 |
| 装配室 | LT 闪电装配室 |
| 催化器 | LT 水晶催化器，通过水晶仓的常驻材料运行 |
| 集成工作站 | NeoECO AE 集成工作站 |
| 水晶聚合 | AE2 Crystal Science 水晶聚合器 |
| 水晶粉碎 | AE2 Crystal Science 水晶粉碎器 |
| 电路蚀刻 | AE2 Crystal Science 电路蚀刻器 |
| 水晶装配 | ExtendedAE 水晶装配器 |

普通加工样板照常插入。首次执行时，工厂检查真实输入签名和**全部产物**，仅仅插入样板不代表其配方已经匹配。配方／标签重载会使旧绑定失效，移走工艺核心会停止对应配方；已经生成的真实产物仍可恢复。

## 吞吐、供能与闪电

T1–T4 默认分别为每 tick **16,384／65,536／262,144／1,048,576 次源操作**。实际批量还受 FE、闪电、原料及服务器工作预算约束。普通模式 FE 成本为**源配方总 FE 的两倍**。这些数值、FE 吞吐／缓冲和辅助仓默认槽数，可在通用配置的 `largeOverloadFactory` 中调整。

所有普通源操作至少收取**一个高压闪电**；源配方更高的闪电成本保留。需要极高压时，内置**四个高压补一个极高压**，也可混合支付极高压和高压，无须再安装坍缩矩阵。极高压不能反向支付高压需求。

默认优先消耗外部 FE 缓冲，再从正在工作的仓室所在 ME 网络补足缺额。**仅外部 FE**关闭新的自动 ME 取电。ME 网络自身仍需正常供能。

## 苍穹成型

星舰内天然存在的**苍穹转换核心**可以替代中央处理核心。围绕原地核心建造，先清空其原有库存并结束旧任务。此模式必须有样板仓，**只支持苍穹转换配方**。

整台工厂固定共享每 tick **1,024 次源操作**，每次支付**一个极高压**或代偿的四个高压，加工 FE 为零。满额一 tick 因而收取 1,024 极高压或 4,096 高压。成型后原核心的手工加工和自动化输入关闭，成型本身不会重新抽取天然战利品。

## 回传与恢复

时间轮和天枢 CPU 可在提交本次派发后接收排队的产物，实现同 tick 连锁。其他 CPU 的产物通过仓室 ME 网络延后回流。同步加工仍受服务器工作预算约束，预算耗尽后续到之后的 tick。

网络存储满、网络改变或结构失效时，已经由工厂持有的材料与产物保存在资源账本中，自动回流需要原来的外部网络锚点。**导出恢复**可以将积压资源变成恢复胶囊；拆除有资源的仓室或有电的控制器也会留下胶囊。手持胶囊对一个联网可用的加工仓使用，即明确将资源退入该网络；未退完的仍留在原胶囊中。复制胶囊不会复制其资源。
