# 挖掘工厂

<BlockImage id="ae2lt:mining_factory" scale="4" />

**挖掘工厂**按方块自身的战利品表产出挖掘掉落，不在世界中放置或破坏方块。放入方块物品与耐久工具或 AE2 破坏面板，接入存有高压闪电的 ME 网络并供应 FE 即可运行。

## 处理与消耗

每批耗时 5 tick，完成时扣除方块、工具耐久、FE 与 1 单位高压闪电。能源不足、工具不可用或输出堵塞时停止运行。

默认无矩阵时每批处理 8 块；安装矩阵后，每枚**闪电坍缩矩阵**提供 256 并行，最多 8 枚，共 2,048 并行。默认采用抽样计算掉落，长期产量与逐块挖掘相同，单批产量波动更大。

工具逐块消耗耐久，时运与精准采集生效，默认每块 256 FE；**破坏面板**按钻石级工具处理并带入其附魔，不耗耐久，默认每块共消耗 1,024 FE。

工具在批次中损坏时，只结算已处理的方块，保留未处理的输入。耐久附魔与不毁属性正常生效。

## 槽位与自动化

| 槽位 | 容量 |
| --- | ---: |
| 方块输入槽 | 4,096 |
| 工具槽 | 1 |
| 矩阵槽 | 8 |
| 输出槽 ×9 | 4,096 / 槽 |

内部缓存 4,000,000 FE，各面均可输入 FE，也可经 ME 网络或绑定频率接收 Applied Flux 电力。管道可输入方块、工具与矩阵并抽取产物。

**自动弹出**与**输出面设置**默认关闭，开启后向所选方向的相邻容器输出产物。内存卡可复制这些设置、频率与矩阵数量，矩阵从背包扣除或归还。

## 兼容范围

支持普通方块物品与带耐久工具组件的工具；不支持带方块实体的方块（含容器）与纯电动工具。依赖世界环境的掉落条件可能无法满足，范围挖掘、连锁砍伐等效果不生效。
