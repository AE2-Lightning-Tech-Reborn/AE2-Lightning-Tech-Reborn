# 过载并行卡

**过载并行卡** 是 LT 与 AE2 水晶科技的可选联动。在闪电装配室用 **2 张 CS 陨石超频卡、1 个闪电坍缩矩阵、2 个 CS 谐振处理器**，再消耗极高压闪电制作。每台支持的 CS 机器最多安装两张。

安装一张后，配方机器每游戏刻最多执行 **8 次**；安装两张后最多执行 **64 次**。每次仍独立消耗完整的 AE 能量与原料，并检查水或其他流体和产物空间。机器内部 AE 储能容量随卡数扩大至原来的 8 倍或 64 倍，连接 AE 网络后由 CS 原有机制正常充电。供电不足、缺料、流体不足或输出满时会停止。单次能耗超过机器缓冲容量的配方仍可能需要多次工作才能完成。材料、能量和输出都充足且维持 20 TPS 时，上限分别为**每秒 160 或 1280 份配方**。

MC 1.21.1 的 CS **1.2.1 正式版**支持电路蚀刻机、水晶粉碎机、水晶聚合器和熵变反应室。当前 1.21.1 的 **1.3.0 快照版**还支持水晶注入器和脉冲离心机。水晶催生仓每游戏刻最多执行 8 或 64 次正常的耗能生长，种子成熟后自动停下。水晶振动室和自装配式样板供应器维持其原有升级效果。

CS 原有的两张陨石超频卡已能让多数配方每 1 游戏刻完成一份，但一台机器每刻仍只处理一份。LT 卡提高的是这一吞吐上限；额外的加速卡或陨石超频卡不会继续提高它的每刻处理次数。
