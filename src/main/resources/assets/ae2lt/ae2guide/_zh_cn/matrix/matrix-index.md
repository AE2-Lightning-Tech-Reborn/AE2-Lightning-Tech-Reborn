# 天枢物质扭曲矩阵

**天枢物质扭曲矩阵**是面向大规模自动合成的多方块结构，专门用于集中存放并高并行执行**分子装配室兼容样板**（工作台合成、切石、锻造等），以单结构替代成片分子装配室阵列。

> 职能区分：**天枢物质扭曲矩阵**负责提供样板与执行分子装配室兼容合成；任务的合成树规划与调度由合成 CPU（如 [天枢超算](../tianshu/tianshu-index.md)）负责。

<SubPages />

## 核心特性

* **固定尺寸**：7×11×7 多方块结构，通过单一端口接入 ME 网络，整座结构仅占用 **1 频道**。
* **能耗**：待机 **8 AE/t**；成功接收合成请求时，每份额外消耗 **1 AE**（网络电力不足时会限制单 tick 实际可执行份数）。
* **可扩展样板仓**：结构夹层提供 50 个样板仓位，支持混装 T1（36 槽）、T2（72 槽）与 T3（288 槽）样板仓，满配 T3 可达 **14,400** 槽位；支持通过控制器原地升级与「一键迁移样板」。
* **可调核心舱**：中央 81 格核心舱由 1 个主核心与 80 个外围单元组成，可根据需要配置线程吞吐、增幅倍率与热控策略。
