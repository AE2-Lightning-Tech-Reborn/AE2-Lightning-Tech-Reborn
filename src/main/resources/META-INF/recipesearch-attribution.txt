Also reviewed: GregTech-Odyssey/GTO's RecipeDB integration, which compiles coarse
candidate indexes, invalidates them on catalog/input changes and retains full
native matching at admission.

AE2LT independently applies that index-then-validate design to known pattern
definitions. It preserves source candidate order, uses native provider mutation
revisions or local dirty flags, and revalidates physical recipes on every lookup.
No RecipeSearch trie implementation or third-party source code is copied or
embedded. This attribution does not relicense the upstream projects.
