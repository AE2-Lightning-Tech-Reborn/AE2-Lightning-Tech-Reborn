## 1 数值与策略验证

| 场景 | 需要观察或比较的结果 |
| --- | --- |
| 首次启动 | 正常世界资源能够建设基础设施并完成首轮，不需要先持有资源点 |
| 载体分级 | 在可比较的外部原料口径下，高级压缩物的原料利用率降低、单位支撑承载物质量提高；低级与混装方案在适当条件下仍有价值 |
| 支撑配比 | 同时比较物质量、支撑数量与等级、开局 `K`、升级成本及成果，不把较低 `K` 单独当成较高收益 |
| 科技升级 | 在相同投入下比较不升级、部分升级与升级到底；新技术提高产率并增加基础资源消耗，能观察到剩余库存与回本关系 |
| 特殊模块 | 不装模块建立基线，计入一次性模块成本后再比较效果、互斥、叠加与路线选择 |
| 首次完整通关 | 完成明确定义的核心流程即可取得自动化资格，不必穷尽可选挑战 |
| 后续周目 | 资格与策略保留，自动化在开局或极早期可用，不要求反复手动玩到中后期 |
| 单堆与多堆 | 在相同功率、物资条件下比较 1 至 5 台的实际点数收益与成本，不仅比较内部速度 |
| 高产慢堆与快堆 | 测量慢堆建立、有限支援消耗与交接成本，计入快堆接口前置、单轮奖励、周目时长和机群长期收益 |
| 暂停轮换 | 比较同时运行与顺序运行、囤积内部资源的效率，确认实时协同是否提供预期价值 |
| 提前结算 | 缺料、低投入短轮、中间目标和完整通关均可结算，检查是否出现无进度正收益或无意义刷空轮 |
| 自动化优化 | 比较物资清单、升级顺序、供电分配、接口路由和结算策略的可优化空间 |
| 天文内部数值 | 数值扩大不会突破单轮奖励上限，不溢出为负数、非有限值或不可存储结果 |
| 外部循环 | 分开验证纯点数兑换回灌与包含外部可再生生产／有效加工的循环；记录三类投入、FE、备料与交付时间、连续多轮的产率 |
| 结算时机 | 先判断有限库存、升级回本与周转效率是否足以形成停止条件；寿命、熵、退化与晚结算减少不作为当前必选项 |
| 低价资源 | 武器、工具、概率和副产物调整不会形成意外零成本兑换或无限额外产物 |

不同物资应保留实际消耗记录，不强行用未经确定的统一价格掩盖瓶颈。单轮奖励有限与单位时间产率有限分别判断。三台、五台、快慢组合何时更优是验证结果，不是预先成立的结论。

## 2 资源与状态验证

| 场景 | 必须满足的行为 |
| --- | --- |
| 启动与并发备料 | 投入实际扣取，只归一个周目持有；不能共享同一份外部库存额度 |
| 支撑限制 | 数量不超过本轮上限，按等级计算提供量，满足启动阈值；零需求不产生除零或无限倍率 |
| 利用率下限 | 利用率 10% 可以启动，低于 10%、超过 100% 或非有限值不能启动；运行和子轮重置不能改值或补料 |
| 两层重置 | 子轮清除普通成长和科技点，关键科技在本次外层内保留；外层结算清空内部科技并只发奖一次 |
| 对数科技点 | 按子轮累计研究量计算累计生成量，再扣已花点数；路线无硬互斥，平均分散与专精按实际数值比较 |
| 升级倍率 | 下降型 Sigmoid 在合法域内有界、不增；开局锁定，仅乘科技升级物耗，转出、加工和阶段重置不重算 |
| 扣费口径 | 实际升级价格与预览一致；初始物质量、普通加工和最终奖励不重复应用 `K`；单买与批量购买遵循明确的舍入规则 |
| 物质账本 | 同一当量口径记录可用物质、设施／产物、残余物与损耗；回收及阶段重置不能重复生成投入 |
| 轮中补料尝试 | 外部物品、流体、点数和其他堆的实物不能补入本轮预算 |
| 内部资源转移 | 来源真实扣减，接收量与传输损耗准确，多个目标不重复消费来源余额；转出资源不再进入来源结算 |
| 接收承载 | 不允许低负载开局锁定较低 `K` 后无界导入物质；按选定规则检查接收预留、累计量、转出转入与循环传输 |
| 实时支援 | 消耗有限预算且与实际支援工作量或受益强度对应；来源减速不能保留完整效果却免除费用，暂停或预算耗尽停止支援 |
| 特殊模块与自动化 | 暂定一次性模块按明确节点扣取，本轮效果不跨结算；自动化资格、外部设备和策略按原规则保留 |
| 暂停 | 不占运行数量，无新推进、产出和实时协同；已经收到的库存可以按规则在其他堆继续使用 |
| 同 tick 暂停与恢复 | 所有运行堆使用一致数量与倍率，不因机器更新顺序获利 |
| 接口与轮次 | 新周目重新解锁接口，不继承旧请求、实时增益或伙伴的奖励资格 |
| 单堆最终结算 | 仅本台轮内状态清空，伙伴周目与已经完成的合法转移不回滚 |
| 提前结算 | 按实际完成且已支付成本的成果发奖，剩余物资清空；缺料不强制零奖励，也不自动强制结算 |
| 成果计价 | 历史里程碑、循环重置、内部大数和共享记录不能重复生成奖励；物质当量与资源点报价分开记录 |
| 交付受阻与重启 | 保留唯一结算记录与待交付点数，重复指令或重启不重复发奖 |
| 拆装 | 不掉出轮内物资，不复制存档或领奖资格；外部设备按独立规则保留 |
| 规则重载 | 已开始周目按锁定的投入、支撑比、升级倍率与规则版本执行，不静默改价或重新结算 |
| 自动化 | 与手动操作使用相同校验和成本，失效指令不重复扣费；执行开销有界 |
| 欠压及可选退化 | 先确定低功率、零功率与运行计数；仅在选用退化后增加损失、恢复、暂停、卸载与结算的组合验证 |

## 3 来源兼容验证

刷怪验证无武器 `D = 1`、使用最大生命值、武器伤害与掉落条件一致，以及无法解析和不能造成伤害的处理。概率验证包括零掉落、多次抽取、完整产物身份、互斥条件、额外事件和低频未命中的未知状态。

村民验证只扣绿宝石与点数，不重新要求被省略的第三种实物。采矿候选验证地质丰度与工具产量分开、正确采集能力、时运与精准采集不混用，以及人工摆矿和新旧生成规则不污染档案。

ME 接入验证自定义资源从终端预估、任务投入到确定交付的完整链路，同时覆盖网络拆分、满输出、取消和退款。兼容范围以实际适配和验收结果为准。

## 4 保留待定的内容

| 主题 | 待定事项 |
| --- | --- |
| 发布与依赖 | 首发版本、加载器、英文名、模组 ID、独立仓库及 AE2、LT、TB 依赖 |
| 增量内容 | 题材包装、阶段、科技树、工艺吞吐与产额、物质当量、阶段重置和首次完整通关目标 |
| 物质载体 | 物质球／奇点／过载奇点等的实际物品、配方、物质量与支撑需求，以及混装与首轮启动成本 |
| 支撑 | 已选有限数量与分级；待定数量上限、各级容量和配方、启动余量、设备规格升级 |
| 升级物耗 | 已选开局下降型 Sigmoid 且仅用于科技升级；待定参数、精度、舍入、批量计费和规则迁移 |
| 特殊模块 | 暂定一次性；待定效果、数量上限、互斥叠加、消耗节点、轮内前置与外部制作成本 |
| 供能 | 基础功率、接收上限、储能、内部时间精度与处理预算 |
| 退化 | 寿命、熵、老化、晚结算损失和独立回收率均待定；欠压处理及运行计数另需明确，不默认采用奖励衰减 |
| 协同 | 所有共享有成本；待定接口类型、速率、有限材料费用、接收负载预留／累计规则、实时增益及交接收益 |
| 结算 | 实际成果的点数报价、阶段与挑战作用、单轮上限和提前结算规则；是否需要严格单位时间产率上限 |
| 自动化 | 通关后开局或极早期开放的具体形式、模块配方、策略界面、脚本语言与 API |
| 永久扩展 | 正版身份绑定、装饰与便利积分、排行榜、跨存档与跨服继承范围；不作为连续自动化前置 |
| 转化器 | 来源模块或独立设施的形态、首发来源、采矿是否采用候选方案、吞吐与缓存 |
| 来源报价 | 武器伤害取值、取整、最低收费、耐久与耗材、统计门槛、村民补货与猪灵金锭投入 |
| 周目经济 | 纯兑换回灌是否允许净正收益、外部新增生产与加工的贡献、三类投入的回本与长期循环 |
| 工程恢复 | 结算账本、拆装恢复、规则版本迁移、储量与存档格式 |

这些待定项不把已讨论的候选机制伪装成定案，也不要求先开发通用多方块框架才能开展本附属的数值原型。
