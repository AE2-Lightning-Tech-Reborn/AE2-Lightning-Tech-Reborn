# 首版数值与测量边界

[增量玩法与两层重置](增量玩法与两层重置.md) · [验证与待定事项](验证与待定事项.md)

2026-10-30 / 原型 0.1.0。本页记录独立网页原型的首版参数与固定策略测量。Demo 源码、运行脚本和原始 JSON 记录保留在仓库外；本仓库只提交设计与验证文档。

## 参数

| 项目 | 首版参数 |
| --- | --- |
| 科技点 | floor(10 × log2(1 + 累计研究量 / 100)) − 已花科技点 |
| 研究消耗 | 1 材料 → 45 研究量 |
| 单路线节点成本 | 12、22、46 TP；合计 80 TP |
| 单路线升级物耗 | 120、240、450，分别乘外层锁定 K |
| 级联解锁 | 两种关键原理 + 50 TP + 600 × K 物质 |
| 基础设施 | 启动/重建消耗 90；各设施初始 1 台 |
| 基础速率 | 处理 6、研究 6、凝聚 4 材料/秒/台 |
| 初始推荐投入 | 20,000 物质，80% 利用率，K = 1.25 |
| 级联工艺 | 产额 ×3.60、凝聚吞吐 ×1.25 |
| 核心完成 | 1,000 点级联成果，并最终结算 |

研究一条主线的 80 TP 至少需要 25,500 研究量（约 566.67 研究耗材）；在同一个子轮取得两条主线的 160 TP 需要 6,553,500 研究量（约 145,633.33 耗材）。对数没有数学硬上限，超大外部输入仍可兼修；常用配置由有限物质形成实际限制。

每种关键科技只保留工艺解锁；子轮内三段普通加成要重新研究。级联工艺初稿产额 ×2.30、吞吐 ×1.10，模拟显示多轮研究和重建的回本不足，初次调整为 ×3.60 / ×1.25，使组合与浅层辅修在中大预算有可观察的用途。

## 固定策略比较

全部使用同一 0.25 秒步长、20,000 投入和 80% 利用率。短轮到 300 秒或耗尽；其余到耗尽或 3,600 秒。策略固定扩建设施、购买顺序与研究分配，并非最优解。表内点数是结算前成果（正式结算向下取整）。

| 策略 | 成果点数 | 内部秒数 | 点/秒 | 点/投入 | 剩余物质 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 不研究短轮 | 6,000.00 | 300.00 | 20.00 | 0.300 | 12,895 |
| 高通量专精 | 18,805.05 | 200.50 | 93.79 | 0.940 | 0 |
| 精炼专精 | 77,784.52 | 1,206.25 | 64.49 | 3.889 | 0 |
| 分散研究 | 25,374.38 | 435.25 | 58.30 | 1.269 | 0 |
| 三子轮级联 | 49,017.60 | 611.75 | 80.13 | 2.451 | 0 |
| 级联 + 浅层精炼 | 73,019.70 | 596.50 | 122.41 | 3.651 | 0 |

观察：高通量快速完成；精炼取得较高单次总产出但耗时较长；级联加浅层精炼缩短高产额生产耗时。低投入适合少重建：5,000 投入时，机械执行三级联模板只剩很少物质供生产。60,000 投入下，精炼专精在 3,600 秒上限仍剩 5,163.12 物质，因此该行不是完整耗尽产出，不能据此声称级联总产额必然更高。

同样研究 60 秒，专精与分散策略都得到 89 TP：专精花 80 TP 完成高通量原理；分散花 68 TP 在两条路线的浅层前置，没有取得关键科技。所有路线都可购买，没有硬互斥。短轮只是对照，不宣称对所有预算或目标有优势。

## 验证与后续

11 项模型检查通过，浏览器已走通手动三子轮与核心目标。物质收支把可用库存、设施、科研、升级、重建损失和成果物质分别记账；成果点是价值，不等于新增物质质量。

这次仅微调首版体验，没有搜索最优策略，没有证明不存在其他支配策略。外部配方、物质球、分级支撑、Sigmoid 曲线、模块、FE、多堆协同与真实库存补给均未接入；游戏内阶段再平衡。独立模型便于继续替换这些参数。
