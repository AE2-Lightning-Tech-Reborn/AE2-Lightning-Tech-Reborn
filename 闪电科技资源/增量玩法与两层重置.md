# 闪电科技资源增量玩法与两层重置

更新：2026-10-30。本文记录增量玩法的收敛结果。网页原型采用 The Modding Tree；原型数值用于体验与策略比较，不能替代 Minecraft 中的实际配方、供电和产线平衡。

## 1 两层重置

外层运行从一次实物投入开始，到最终资源点结算结束。它包含若干内部子轮。外层最终结算基本彻底重置内部状态；跨子轮科技仅在当前外层运行内保留，不跨两次外部启动积累生产能力。

```text
外层启动：投入物质、支撑、特殊模块，锁定预算与升级物耗倍率
  子轮一：发展、研究、专精，取得关键科技
  内部重置：重建普通生产体系，保留关键科技与剩余预算
  子轮二：研究另一方向，或利用已有科技继续发展
  后续子轮：组合研究成果，采用更高级工艺
外层最终结算：交付资源点，清空本次内部科技、设施与库存
```

外部自动化资格、设备、操作策略及已结算资源点沿用原来的保留规则。它们不等于跨外层保留内部科技。

## 2 对数科技点与自然专精

不设置基础路线互斥，也不采用额外的子轮技术承载上限或统一发展规模涨价作为主机制。所有研究路线均可投入；通过科技点的对数增长与深层节点成本形成专精。

```text
X = 本子轮累计完成的研究量
T_total = floor(A × log2(1 + X / X0))
T_available = T_total - T_spent
```

累计研究量与已花科技点分别记账。科技点花掉后不能因为余额下降而重新生成；不是每次刷新都把整个对数值再次加入余额。

集中投入一条路线，可以较早达到深层研究条件；浅层辅修仍然允许。平均分散投入可能使各路线都无法在合理时间内达到关键节点。对数本身没有上界：若研究量受有限物质约束，则科技点实际有上界；若研究量能持续增长，则表现为继续研究越来越不划算。需要连同研究量本身的增长速度一起验证，不能只靠公式宣称必然只能完成一条路线。

科技点决定子轮研究深度，物质决定整个外层运行能承担的建设、升级、研究和生产。升级同时检查科技点、路线前置及物质费用；升级物耗倍率仍只作用于升级物质成本，不影响科技点公式、一般加工或最终结算。

## 3 子轮科技与跨子轮科技

普通研究节点与生产升级服务于当前子轮。达到一条路线的深层节点后，取得能跨子轮保留的关键科技；后续子轮可以研究其他方向，或解锁需要多个关键科技的组合工艺。

跨子轮关键科技优先开放新工艺、研究前置变化、组合能力及前期便利，也可以具有有界的数值效果。下一子轮仍需支付本轮建设和升级成本；物质不会因取得研究成果而免费补充。

子轮内允许主修与辅修，不要求只能购买一条路线。高级组合科技不自动赋予另一条路线全部普通升级。原型先用两条主路线和一个组合节点验证专精、重建与回本，再扩大科技网。

为了避免刷浅重置，保留对象是实际完成的关键科技，未花科技点不跨子轮囤积，重复取得同一科技不重复发奖。深层节点需要本子轮的普通前置；内部重置不会把未完成的浅层研究自动兑换为关键科技。

## 4 子轮重置的原型规则

下表为首个原型采用的明确规则，清除程度、设施回收和完整科技内容可根据试玩修订。

| 状态 | 子轮重置 | 外层最终结算 |
| --- | --- | --- |
| 研究量、已花与剩余科技点 | 清零 | 清零 |
| 普通设施、普通升级、路线前置 | 清除；建设物质按既定规则计入损耗，不恢复初始投入 | 清除 |
| 已完成的关键科技 | 保留 | 清除 |
| 未消耗的基础物质与中间材料 | 保留，仍归同一次外层预算 | 清空，不返还 |
| 已实际生产的可结算成果 | 保留，不重复生成 | 结算一次后清除 |
| 支撑、锁定的升级倍率、特殊模块配置 | 不刷新、不改值 | 本次效果结束 |
| 外部自动化资格、策略与已结算资源点 | 保留 | 保留 |

研究、设施建设、科技升级、加工与损耗需能按同一物质当量对账。已计入成果的物质不能再被回收或重复计入来源余额。纯研究量与科技点是进度，不被当作可兑换实物的物质。

内部重置可由玩家主动触发，不强制完成所有研究。没有取得关键科技时允许重置，但没有固定重置奖励。外层结算可随时提前进行；物质不足不强制零奖励或自动结束。

## 5 生产、研究与自动化

操作采用传统增量游戏的购买设施、购买升级与自动运行，底层采用有限物质生产链。首版不加入空间布局。物质加工、科研和成果生产竞争本次预算，玩家需要决定什么时候投资未来、什么时候转为生产结算成果。

首轮保留手动体验。达到明确的核心终局目标后，后续外层运行可以使用保留的自动化策略；不要求穷尽全部可选研究。网页原型可提供标明用途的时间加速用于试玩，不能把它算作正式供电倍率或已验证的游戏内速度。

界面至少展示两层轮次、剩余物质、中间材料、可结算成果、科技点来源与花费、下一研究条件、关键科技保留范围，以及两种重置分别清除什么。生产、研究暂停和物质不足应能解释原因。

## 6 外部参数与最低利用率

网页原型把外部物质量与升级材料利用率做成相互同步的数值输入框和滑块，暂不实现真实压缩物与支撑配方。这里的利用率定义为 `η = 1 / K`；100% 对应升级物耗 ×1，50% 对应 ×2，10% 对应 ×10。它不减少初始投料，不改变普通加工成本，也不乘入成果结算。

利用率最低为 **10%**。低于 10%、超过 100% 或非有限输入都不能启动，不能静默修正后启动。滑块范围为 10% 至 100%；数值输入需要同样的启动校验。

正式外层启动锁定输入。运行中、暂停中及内部子轮重置都不能补充物质、修改利用率或重发模块。只有结束外层后才能修改下一次启动参数。游戏内阶段再把真实物质、支撑比及 Sigmoid 映射接入同一边界，并检查低于 10% 的配置无法开轮。

## 7 原型验收与数值比较

至少比较：不研究的短轮、单路线专精、平均分散研究、取得一个关键科技后重置研究另一方向、完成组合工艺后的生产，以及低利用率与低投料场景。记录实际成果、研究耗材、升级耗材、轮长、子轮数和剩余物质，不把原型资源点当作已验证的 Minecraft 兑换收益。

必须检查：10% 恰好可启动、低于 10% 不可启动，输入锁定，对数科技点不重复生成，路线无硬互斥，子轮重置不补料或携带未花科技点，外层结算不重复发奖，跨子轮科技不跨外层继承，以及暂停、存档和恢复。
