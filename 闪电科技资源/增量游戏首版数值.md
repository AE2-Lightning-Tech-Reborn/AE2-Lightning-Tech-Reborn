# 增量游戏首版数值

[内容设计](增量游戏内容设计.md) · [设计校验](增量游戏设计校验.md) · [运行架构](JS后端与GraalJS运行架构.md)

2026-11-01，候选参数 v0.2.2。以下数值构成可以复算的内部游戏基线，不是外部资源报价或已经验证的最终平衡。本版补齐载体折算，内部科技费用与吞吐沿用 v0.2.1。数值调整应整体升规则版本，运行中的旧周目继续使用启动时锁定版本。

## 1 基本单位与输入

终局主原料参考量为 `64,000×256,000,000 = 16,384,000,000,000`，压缩加工和支撑成本在这笔量之外单列，详见[投入口径](投入与物质转换.md#21-主原料规模与独立成本)。它是量级基准，不是外部总成本封顶，也不是硬性机器容量。实际 Q0 取决于载体配比与物质球的 Q 标定；本版候选取 M=256 Q，对应物质球每件 256 Q、奇点 128,000 Q、过载奇点 131,072,000 Q，支撑需求分别为 1、250、128,000。

按默认配方原料当量，这笔主原料可以对应 125,000 个过载奇点，合计 Q0=16,384,000,000,000 Q、D_local=16,000,000,000。下界之星等加工投入另计，能否供给足够支撑达到 80% 利用率仍待实际规格验证。普通奇点仅保留一半物质当量，不能把任意载体组合都直接视为同一个 Q0。

P7 候选产额取每 Q **1,000,000 点**。全轮主原料若全部用于 P7，会超过 long；应先扣除真实发展消耗，再判断余料。为保留逐档十倍产额，本版把 P0–P7 点值整体重标为 0.1 至 1,000,000；R3/R4/P7 发展费用与试验工作量为 v0.2 的 100 倍，试验吞吐同步提高 100 倍，工作时间不因扩大数量而增加。P7 生产吞吐改为 10^9 Q/秒。教学段费用保留。所有调整仍是候选，不表示已测得最优配比。

| 参数 | 候选值与定义 |
| --- | --- |
| 物质单位 | Q，内部物质当量；不等同于任意 MC 物品一件 |
| 精确尺度 | Q/A/S/研究与工作尺度 10^9；价值 V 尺度 10^13，单价以万分之一点/Q 计；全部为 BigInt，JSON 用十进制字符串 |
| 原型输入范围 | 100 至 10^15 Q，最多 9 位小数；上限只用于原型参数保护，非正式承载上限；直接解析十进制，不先经过 Number |
| 教学投入 | 2,000,000 Q；升级材料利用率 80% |
| 终局内部输入样本 | 16,384,000,000,000 Q；利用率 80%；不装特殊模块；在 M=256 Q 候选下可对应 125,000 个过载奇点；加工与支撑另计 |
| 利用率 | 10%–100%，按 0.01 个百分点保存为整数 1,000–10,000 |
| 升级 K | `10,000 / 利用率整数`，以有理数参与扣费；80% 对应 1.25 |
| 科技收费 | 每个节点分别按 `ceil(基础价 × K)` 取到整 Q，再转为定点；批量购买求各节点已取整价之和 |
| 其他收费 | 建站、科研、试验、加工、按量通讯不乘 K；定点余量累计 |
| 原型基准供电 | `P/B=1`，单台 N=1，基准 20 TPS；不假定 B 对应某个已定 FE/t 数值 |
| 单轮交付上限 | `9,223,372,036,854,775,807`，仅对最终交付截断 |

开轮不自动扣 300 Q 建站，允许选择零发展投入直接应急收尾。参考路线显式购买基础站。准备参数开轮后锁定，暂停、内部重置均不能变更或补料。

1 Q 科研材料形成 45 X；每个试验的进度不是物质，原料消费记为损耗；1 Q 正常加工则形成 1 Q 的 S，按所用工艺记入对应价值。科技消耗的整份费用都进入科技损耗，不把额外 K 损失再扣一次。

## 2 研究与基础站

基础站：建设 300 Q，提供活化能力 6 Q/秒、科研能力 6 A/秒和普通 P0 转换能力 10 A/秒。科研与生产共用活化料，不各自取得独立免费供给。研究节点与试验条件见内容设计。R1 删除整个基础站。

为避免高层工艺被基础站的 6 Q/秒永久限制，每个 P1–P7 工艺站均包含自己同速的活化段和转换段，两段各有独立吞吐上限，仍共同消耗 Q/A。只有 Q→A 和 A→S 同时正常运行时才能达到表中稳定吞吐；每条新链至少经过一个真实帧的前置延迟。应急粗凝不需要 A。

科技点精确比较可用 `10×log2` 的等价整数不等式：令 `x` 为 X 的定点整数、`u=10^9`，判断生成量是否至少为 T 时比较 `(x+100u)^10 >= (100u)^10 × 2^T`。以位长确定有界二分区间，避免浮点临界点重复发点；不会逐个科技点循环增加。

| 同子轮累计 TP | 所需 X | 若按整 Q 停止研究，至少耗材 |
| ---: | ---: | ---: |
| 80，一条完整路线 | 25,500 | 567 Q |
| 160，两条完整路线 | 6,553,500 | 145,634 Q |
| 240，三条完整路线 | 1,677,721,500 | 37,282,700 Q |

这证明常见教学预算下三路线一起深入很贵，不证明超大输入不能兼修。首轮可以浅辅修；R1 一次只兑换一个晶种，未兑换的试验与研究会清除。

| --- | ---: | ---: | ---: | ---: |
| P0 基础站 | 300 | 0 | 最高转换 10，但活化默认仅 6；还要与研究共享 | 0.1 |
| P1 晶格 | 1,000 | 2,000 | 100 | 1 |

| P3 相位 | 200,000 | 600,000 | 10,000 | 100 |
| P4 星核 | 200,000,000 | 600,000,000 | 1,000,000 | 1,000 |
| P5 星网 | 2,000,000,000 | 6,000,000,000 | 10,000,000 | 10,000 |
| P6 视界 | 20,000,000,000 | 60,000,000,000 | 100,000,000 | 100,000 |

每档每台反应堆只建一座；不通过复制无限站数绕过时间预算。可保留多档站，手动选择一种工艺生产；默认自动化选择当前可用最高档。研究与试验可与生产并行，但争用 Q/A，且会损失未来高产额所需原料。

升级不是必然更优。设当前剩余 R，已有工艺点值 y，升级另花 C，新增工艺点值为 10y，且忽略吞吐、其他费用和已完成价值，则升档增加总收益的条件是 `10(R-C)y > Ry`，即 **`R > 10C/9`**。不是 `R > C/9`；必须把升级吃掉的原料也从高阶生产中扣掉。

例：80% 利用率下，从已建 P2 升 P3 另需 950,000 Q，剩余 Q 要超过 1,055,555.555… 才增加最终总收益。若目标是更短轮长，结论可能不同。若 P2 尚未建，需比较两条分支的完整建站费，不能照搬这个阈值。

P0/P1 的局部有序研究可以提升其点值，最高为基础 ×1.21；不会作用于 P2–P7。基线比较不使用该加成。既有成果 V 不重新计价。

## 5 固定真实帧与余量

基准每帧推进 1/20 秒。工作和加工能力乘获准速度，再按材料和目标量限制批量。提高速度不增加内部 tick、脚本回调和重置次数。

速度取 `sqrt(P/(B×2^(N-1)))`，宿主批准值量化为百万分之一，向下取整。生产乘法保留独立的分子余量；余量不足一个物质最小单位时等待下一帧，不免费取整。试验的有理数速率如 `240×10^9/900` 也保留分母余量，不能先截断成整数速率。暂停不推进余量；清除某设施时其未形成物质的工作余量随设施清除。

本次原型候选的欠压规则：低于基准功率仍按平方根减速，零功率无工作、无新支援、不额外退化。只有非暂停、已加载且宿主为该帧实际批准正 FE 的堆进入共同 N；成员集合在计算速度前固定，不按计算出的速度反复调整。微量正功率仍计数；恢复提示同时展示对其他堆的影响。此规则是供能设计的候选补充，Minecraft 接入前需验证。

价值使用定点累积，帧末不取整成资源点。设 `q_int` 为尺度 10^9 的本次转换物质、`p_int` 为每 Q 单价的万分之一点整数，则 `V_int += q_int × p_int`；最终交付为 `min(LONG_MAX, V_int / 10^13)`，除法取整。这样可以精确记录 P0 的 0.1 点/Q 及有序加成后的 0.121 点/Q。达到上限后的普通生产默认停下并提示结算，停止不删除任何余额。P7 精确覆盖 long 所需物质是 `LONG_MAX/10^6 = 9,223,372,036,854.775807 Q`，尺度 10^-9 Q 可以精确表达。参考算账保守地使用 9,223,372,036,855 整 Q，因此多出的不足 1 Q 不应误解为额外奖励。

## 6 一条完整参考路线

不使用特殊模块、通讯、核心配置或局部生产加成，所有基础科研按 567 整 Q 停止。顺序为：三种 R1 各一次 → R2；重复三次 → R3；重复三次 → R4；P7 两项试验；最终生产。全程发展阶段不提前转换结算物质。

| 操作 | 总次数 | 80% 利用率总耗材 Q | 理想帧数预算，含指定过渡帧 |
| --- | ---: | ---: | ---: |
| R1 | 27 | 55,620 | 27 × 3,092 |
| R2 | 9 | 8,955,000 | 9 × 4,802 |
| R3 | 3 | 900,000,000,000 | 3 × 18,002 |
| R4 | 1 | 4,500,000,000,000 | 36,002 |
| P7 建立与试验 | 1 | 800,000,000,000 | 72,002 |
| 合计 | — | **6,200,009,010,620** | **288,712** |

每个 R1 段为科研 1,890 帧、试验 1,200 帧及 2 个用于链延迟/切换的预算帧；其他段在工作量之外各预留 2 帧。它们是宏观行动计划的估计，不是逐帧核心执行日志，首版实现必须重新验证真实动作能否按该顺序执行。

16,384,000,000,000 Q 开局，参考发展消耗 6,200,009,010,620 Q，约占初始物质的 37.842%；剩余 10,183,990,989,380 Q。以 P7 转换到 long 边界的整 Q 参考量为 9,223,372,036,855，尚有 960,618,952,525 Q 余量，约占初始投入的 5.863%。这笔余量可支付额外轮内操作或随结算丢弃，不能跨轮拿走；压缩加工和支撑成本不在其中。普通奇点占比带来的 Q0 减少需先在轮前扣除，不能再次沿用完整 Q0 的余量，见[载体预算](增量游戏设计校验.md#22-载体折算与终局预算)。

不计发展时，达到 long 的全轮平均点值约为 562,949.95 点/主原料；扣除本参考发展消耗后，需要最终转换约 905,673.63 点/Q，P7 的 1,000,000 点/Q 留有余量。反过来，给定 P7 单价，轮内非生产支出的理论上限约为 7,160,627,963,145.224193 Q，即主原料的 43.705%；超出后即便能解锁 P7，也没有足够余料封顶。

按这份动作计划与 20 TPS、1×供电，发展约 4.01 小时，最终生产约 2.56 小时，合计 **23,659.05 秒，约 6.57 小时**。这是预算预测；本版按相同目标点/秒与工作时长重标数量，不能把与旧预算相同的耗时看成独立验证；没有经过现实 6.57 小时的运行测试，不是近优策略证明。低 TPS、调度限流和玩家停顿延长现实时间；更多 FE 和合理配置可缩短时间。

## 7 教学路线与失败样本

教学路线使用 2,000,000 Q、80% 利用率：执行三个 R1、一个 R2，重新建 P2，再转换 100 Q 得到 1,000 点并结算。耗材总计 1,096,280 Q，未用原料随结算清除；理想行动预算约 704.10 秒。推荐 UI 在首次达标时同时显示“立即解锁自动化”和“继续生产提高本轮收益”，不强迫浪费剩余投入。

选择继续 P2 生产到耗尽，会比升 P3 得到更多总收益；P3 则结束更快，具体对照见设计校验。通关后的自动预设应可选择“收益优先”与“周转优先”，不能把尽早结束无条件标成更优。

一个可以用下界确认的失误样本：80% 利用率、7,000,000,000,000 Q，本来足够支付参考路线。若另将 1,000,000,000,000 Q 用于低层生产或非必需投资，则全轮可分配给强制发展的预算至多 6,000,000,000,000 Q，包括此前已支付的强制发展费；而三个 R3、一个 R4 和 P7 的固定费用就合计 6,200,000,000,000，尚未计下层研究费用。任何等待或纯吞吐配置都不能补回差额。已经形成的低层成果保留，剩余 Q 仍可低层收尾。

10% 利用率仍允许启动，但 K=10 时完整参考发展需 17,750,013,926,969 Q，超过该主原料样本，不能完成本候选的完整终局路线；可在低层生产和提前结算，不代表该轮必须零收益。50% 利用率可以建立 P7，但余料仅 9,193,990,567,991 Q，对应 9,193,990,567,991,000,000 点，略低于 long。把“能登顶”和“余料足够封顶”分开反馈。
