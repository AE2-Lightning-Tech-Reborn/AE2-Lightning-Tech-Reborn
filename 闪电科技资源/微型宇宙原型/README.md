## 状态（2026-11-19）

原型代码是 **U5 做到一半** 的状态，设计文档还停在 U4。

已完成：

- U5 的三项规则改动已写进规则核，规则版本 `0.5.0-U5`。
- 固定策略和扫描脚本的打法空间已按规格第 2 节扩大。
- 试玩界面 `reactor-prototype/web/reactor.html` 已按当前代码重新生成。
- 三组测试通过：规则核 25 项、界面逻辑 8 项、单文件版本 3 项。

没有完成，也没有结论：

- U5 的规则实现没有对照规格逐条核对过。测试数量和 U4 相同，新规则是否有对应的测试没有确认。
- 六个可调参数都还是规格里的候选值，没有调过。
- U5 的全条件复测、退化打法检查和报告都没有做。所以 U5 的设计改动是否成立还不知道。
- 这一版没有人试玩过，界面也没有在真实浏览器里验证过。

扫描的中间数据没有入库，可以用 `reactor-prototype/scripts/winners.js` 重新生成。
