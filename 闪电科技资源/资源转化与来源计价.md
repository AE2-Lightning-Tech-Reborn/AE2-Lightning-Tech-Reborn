# 闪电科技资源转化与来源计价

[设计方案](设计方案.md) · [运行协同与自动化](运行协同与自动化.md) · [验证与待定事项](验证与待定事项.md)

资源转化器消费已结算到外部存储的资源点，按照有效来源与确定报价交付目标资源。概率用于折算价格，不让已经付款的订单随机失败。资源点只在反应堆最终结算时产生；本文件不定义持续产点或内部余额直接兑换。

## 1 资源点与存储

沿用自定义 AEKey 表示一种统一的“资源点数”，不按生物、武器或产物拆成不同点数货币。AEKey 表示资源身份，数量由实际存储持有；反应堆内部货币和候选的永久荣誉积分不使用这个余额。

需要提供该类型的存储与显示支持，覆盖序列化、网络同步、点数存入、提取、任务预留、消费、退款及结算待交付。注册资源身份不等于现有物品存储元件、样板和终端已经支持该类型。

点数采用整数最小单位；是否使用固定精度小数、存储载体和外部数量范围在实现时确定。内部天文数字不得直接进入外部存储数量。输出满、拆装、网络分合、取消和重启必须保持点数守恒。

## 2 来源与解锁

| 来源能力 | 目标资源 | 条件与投入 |
| --- | --- | --- |
| 刷怪 | 满足条件的生物掉落 | 生物样本、可选武器及掉落条件；消费资源点 |
| 种植 | 植物或作物收获物 | 种子或种苗及生长、收获条件；消费资源点 |
| 蜂箱 | 蜂蜜、蜜脾及适配蜂种产物 | 蜂种、花源或其他生产条件；消费资源点 |
| 采矿候选 | 地质条件与工具允许的采掘产物 | 地质档案、采掘工具及环境条件；消费资源点 |
| 村民交易 | 实际有效交易出售的商品 | Easy Villagers 兼容入口、村民和对应交易；只消费绿宝石与资源点 |
| 猪灵交易 | 当前条件下的以物易物产物 | Easy Piglins 兼容入口、猪灵和条件；消费资源点，是否另收金锭待定 |

来源能力可以由转化器模块或配套设施承载，具体结构、并行数量和首发范围待定。早期方案中的 ME 刷怪笼、ME 种植站、ME 蜂箱和候选 ME 采矿站作为这些来源的设计参考，不意味着首版必须同时制作全部独立多方块。

统计目录记录“可能来自哪里”，可用来源决定“当前能够生产什么”。没有样本、合适工具、必要环境或来源设施时，不能因为统计目录已有条目就自动开放兑换。转化器不自动开放任意物品或任意加工样板。

默认按请求交付目标产物。若需要一起交付副产物，必须对整批产出重新定价，不能在已经按目标平均产量折算的价格上再免费附送所有副产物。

## 3 概率与平均产量

固定来源和条件，完成 `N` 次完整生产，目标物品总产量为 `Q`，至少产出一次目标的尝试数为 `K`：

```text
产出概率 p = K / N
平均目标产量 μ = Q / N
命中时平均数量 q = Q / K       （K > 0）
μ = p × q
```

一次生产是一次完整击杀、收获、采掘或交易过程，零掉落和失败尝试也进入分母。同一过程共同执行的多个掉落池合并统计目标产量；互斥条件、不同武器或不同来源分别保留，不能简单相加概率。

来源记录至少包含：来源标识、武器或工具及相关附魔、环境与状态条件、产物的完整数据身份、概率与平均产量、基础成本、数据依据、样本量和规则版本。物品 ID 相同而组件或 NBT 不同的产物不能任意合并。

数据获取采用分层方式：

1. 可以精确解析的规则直接计算。
2. 可以在受控上下文执行的规则进行有预算的统计采样。
3. 依赖实际攻击、死亡或专用事件的产物通过适配器或实际生产观测补足。
4. 无法覆盖的自定义逻辑和低频结果保留为未知，通过显式配置补全。

“统计模组概率掉落”是兼容目标，不是有限采样已经穷尽所有模组条件的证明。没有采到不能记为概率为零。单次调用原始掉落表不能冒充对所有额外事件的完整覆盖。

统计缓存按来源、条件、模组、数据包及配置版本区分；更换工具只更新受影响部分。受控采样不在玩家世界中反复生成真实掉落、消费物品或留下持久副作用。

## 4 刷怪与武器成本

保留已确定的基础关系：

```text
H = 生物最大生命值
D = 提供的武器伤害；未提供武器时 D = 1
κ = 一次等效武器使用的点数成本
μ = 一次击杀的平均目标产量

等效使用次数 U = H / D
一次击杀基础点数 B = κ × H / D
目标单件参考价格 C = B / μ
请求 n 件的参考总价 T = n × C
```

无武器时伤害按 1 计算，不是整次生产只收 1 点。使用最大生命值，不能预先打残样本以降低价格。伤害成本和掉落条件必须来自同一套武器、附魔与目标条件。

无武器不解锁武器专属掉落。提供武器但无法解析伤害时不能静默当作无武器；无效、非有限或无法对目标造成伤害的取值不能用于除法报价。

以下细节尚未确定：面板伤害还是有效伤害；玩家属性、暴击、冷却、药水或附加伤害如何参与；`H / D` 是否取整或至少算一次；武器是否消耗耐久、弹药或能量；`κ`、精度及最低收费。本文不擅自把已有公式改为 `ceil(H / D)` 或设置一击保底。

武器只影响其负责的工作和掉落条件，不替代维度、变体和特殊击杀要求。报价、实际扣费和退款使用同一精度规则，拆单或合单不能创造资源点。

## 5 村民 种植 蜂箱与猪灵

村民交易仅收绿宝石和资源点，不额外索取原交易的其他实物。原交易需要书加绿宝石取得附魔书时，被省略的书是否折入点数及折算方法待定；不能重新要求玩家交付第三种材料。

商品应来自实际有效交易，保持附魔和组件等完整身份。绿宝石报价、补货、折扣、次数与已接订单的关系需要单独确定；出售物品换绿宝石的反向交易未纳入已确定范围。

种植、蜂箱和猪灵可以使用“基础生产成本除以平均目标产量”的结构，但不套用最大生命值除以武器伤害。种植与蜂箱的周期成本、猪灵是否实际投入金锭均待定；村民的绿宝石规则不自动推广到猪灵。

同一物品存在多个来源时，逐个保留报价和条件。调度可以选择当前有效来源，但不能拿全局最低报价交给不满足该报价条件的设施执行。

## 6 采矿候选方案

采矿纳入资源来源范围，具体方案尚未定案。候选方向为“地质档案＋合格采掘工具＋资源点数”，按目标资源确定生产，不在每次兑换时真实挖走世界矿脉。

建议流程：勘探相应维度、群系和高度段，取得服务端认可的档案；安装合格工具；列出条件允许的产物与报价；按单消费点数并交付。档案引用由服务端校验，卡片不能自行声明任意丰度。

初期是否要求所在地与档案的维度、群系一致，是否额外需要矿物样本，以及跨维度访问规则均为待定。完整矿石方块不应未经评估就成为所有矿物的统一入场材料。

### 6.1 地质与采掘分开

```text
ρ = 指定地质条件与统一采样口径下的矿石丰度
S = 检查一个候选位置的点数成本
M = 当前工具采集一块该矿石的点数成本
μ = 采集一块矿石后得到目标物品的平均数量

候选单件价格 C = (S / ρ + M) / μ
```

`S / ρ` 是按丰度折算寻矿成本的模型，不宣称等于真实矿脉中的精确寻矿工作量。采样是否排除空气、包含哪些候选地层必须统一，不能让玩家缩小扫描体积后改变概率定义。

工具速度和效率影响采掘成本 `M`，不能改变矿石生成丰度。时运按实际工具条件影响平均产量；精准采集只开放实际允许的产物，不能同时套用时运产量和精准采集的矿石方块身份。默认交付粗矿、宝石等真实采掘产物，普通熔炼和粉碎留在外部产线。

合格工具和正确采集能力必须实际校验。刷怪的“无武器伤害为 1”不等于采矿可以使用无限制默认钻头。工具耐久、能量和其他耗材是否实际扣除、最低成本与具体系数待定。

### 6.2 分布依据

标准世界生成规则用于识别候选矿物与环境；复杂矿脉、代码生成等通过适配、统一口径的自然生成快照或显式配置补足。不能把矿脉大小乘次数、某个生成权重或矿石标签直接当作精确最终丰度。

若采用自然快照，应在玩家修改地形前取得并记录采样范围、样本量和规则版本，不能让人为摆矿提高丰度。既有普通区块不保证能事后区分天然与玩家放置的矿石。

仅配方可得、结构专属、维度专属或需要特殊工具的矿物分别保留限制。新旧世界生成配置下的样本不混成一个精确概率，数据更新后已有档案的处理策略待定。

## 7 外部订单与交付

向 ME 提供确定投入与确定产出的生产能力。资源点作为订单输入；村民订单同时包含绿宝石。自定义资源在终端、预估、样板和机器接口中的接入需要完整验证，不能只注册 AEKey 就视为已经完成自动合成支持。

建议订单流程：

1. 按当前有效来源、样本、工具和条件生成报价。
2. 预估目标数量、点数和其他合法投入，显示缺口。
3. 接单核对条件和报价版本，实际预留或转入材料。
4. 按既定规则执行，记录已扣费、已生产和已交付部分。
5. 确定交付目标数量；输出受阻时保存待交付结果。

更换武器、移除样本、结构变化或数据重载不静默改价。未执行部分的暂停、取消与退款需具有明确状态，不能重复生成或重复返还。

## 8 与周目经济的边界

反应堆奖励和转化器报价共同决定外部产量。单轮点数有上限，不意味着物品产量有上限：极低单价、免费副产物或未受约束的吞吐仍可能改变结果。

需要验证每轮备料的实际来源与代价、能源投入、转化与加工吞吐、完整与提前结算的净收益。最低兑换成本、最终吞吐及是否设置严格产率上限尚未定案，不能把这些列为已实现的平衡保证。

默认内容应给升级组件保留必要的外部加工链，允许玩家用盈余发展其他模组。来源解析、兼容覆盖和价格调整不能悄悄改变正在运行的反应堆的已锁定实物预算。
