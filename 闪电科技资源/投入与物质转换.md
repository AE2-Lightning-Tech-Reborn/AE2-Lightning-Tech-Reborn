# 闪电科技资源投入与物质转换

[设计方案](设计方案.md) · [运行协同与自动化](运行协同与自动化.md) · [后续设计与原型路线](后续设计与原型路线.md) · [验证与待定事项](验证与待定事项.md)

更新：2026-10-30。本文记录已选定的投入结构与升级物耗机制；配方、容量、科技树和曲线参数仍需原型验证，没有实现代码或已验证的收益数据。

## 1 定位与三类投入

长期玩法是控制一轮轮的备料、发展、协同和结算，持续产出资源点。外部 Minecraft 生产提供基础资源，反应堆内部运行有限物质预算下的转换过程。持续供电推进内部时间，不自动增加物质预算。

| 类别 | 作用 | 当前决定 |
| --- | --- | --- |
| 物质 | 提供本轮基础物质库存，同时占用支撑 | 物质球、奇点、过载奇点等各自定义物质量和支撑需求；允许混装 |
| 支撑 | 承载投入的物质，并影响升级物耗 | 支撑单元数量有限、分不同等级；各等级提供明确的支撑值 |
| 特殊模块 | 解锁本轮特殊加成或特定能力 | 暂定一次性；具体效果、数量限制、互斥和叠加规则待定 |

三类实物均在轮前准备并锁定。正式开轮前可以调整、撤回；开轮后不从外部追加。投入的支撑单元属于本轮投入，外部机器方块与持久自动化设备另算；本次没有修改原有“轮末不返还轮内实物”的边界。

特殊模块与自动化模块不是同一种部件。特殊模块可以通过实物成本换取本轮玩法加成；首次完整通关后保留的自动化资格和设备只负责执行合法操作，不提供生产或奖励倍率。特殊模块暂建议采用“开轮消耗一枚、效果持续本轮、最终结算清除”，实际消耗节点和效果生效前置仍待内容设计；不能因暂定一次性就认定所有效果必须在开局立即生效。

## 2 压缩物的规模与效率

为每种可投入物质载体 `i` 定义：

```text
n_i = 投入件数
q_i = 每件提供的内部物质量
d_i = 每件对应的支撑需求

Q0 = Σ(n_i × q_i)       本轮初始物质量
D_local = Σ(n_i × d_i)  这些物质的支撑需求
```

物品被压缩到一件，并不意味着其支撑负载也按一件普通物品计算。物质球、奇点、过载奇点是载体分级方向；本文不将名称直接绑定为既有模组配方的固定数值，实际配方、物品身份和兼容来源需要核实。

高级载体有两个相反方向的变化：

- 在可比较的外部原料口径下，制造同量内部物质需要更多 MC 原料，即原料利用效率降低。
- 同量内部物质所需支撑更少，即 `q_i / d_i` 提高。

若用 `C_i` 表示同口径的外部基础原料成本，分级目标是 `q_i / C_i` 降低、`q_i / d_i` 提高。`C_i` 是配方分析口径，不是已经存在的统一物品价格；不同材料、加工、时间和 FE 成本应分别记录，不能把任意 MC 物品按件数等价。

因此，高级压缩物主要换取更大的单轮承载规模。基础资源紧张而支撑有余量时，低级载体仍可能有价值；基础资源充裕而支撑紧张时，高级载体更有吸引力。混装用于组合不同负载，不预设最高级载体始终最优。

## 3 有限数量的分级支撑

采用数量有限、等级不同的支撑单元，不采用“无限堆放低级支撑、再用递减效率限制”的主方案。数量上限可以表现为有限支撑位；上限、设备规格是否能升级，以及各等级配方均待定。

```text
u_j = 第 j 级支撑单元的投入数量
s_j = 该级单元提供的支撑值
L   = 本轮允许投入的支撑单元数量上限

Σ u_j <= L
S0 = Σ(u_j × s_j)
R0 = S0 / D0
```

`D0` 为开局锁定的总支撑需求。只考虑本地投料时等于 `D_local`；若允许接收增加物质预算的跨堆输入，需先确定其承载预留规则，见第 6 节。

启动必须满足支撑要求。具体启动阈值 `R_start` 不低于 1；等于需求是否允许启动、是否强制保留余量待参数设计。`D0 = 0` 不进入除法或正常生产周目，不把空投入解释为无限支撑比。零产出预览或配置草稿可以单独存在。

## 4 Sigmoid 只决定升级物耗倍率

开局支撑比通过下降型 Sigmoid 形成并锁定本轮倍率：

```text
K(R0) = K_min + (K_max - K_min) / (1 + exp(a × (R0 - R_c)))

K_min >= 1
K_max >= K_min
a > 0

升级实际物质成本 = 升级基础物质成本 × K(R0)
```

`R_c` 是倍率处于上下界中间的位置，`a` 控制曲线陡峭程度。`K_max` 是曲线的理论上界，不表示在允许启动的区间内一定能够取到；充分支撑时倍率渐近 `K_min`。实现需稳定处理指数计算和大数比较，精度、舍入与批量计费规则待原型确定。

物质损耗明确作用于内部科技升级的物质成本。升级本身随等级增长的基础价格仍由科技树决定；内部货币、阶段前置或模块解锁要求独立检查。这个倍率不再次用于初始物质量、常规加工物耗、产点速度或最终奖励，避免把同一支撑不足重复扣费。

例如基础升级成本为 100、该轮倍率为 1.6，则本次升级扣除 160 单位物质；额外部分计入损耗或废料。该例只说明倍率作用位置，不是正式数值。

讨论中的 `K_min = 1、K_max = 3、R_c = 2、a = 3` 仅为曲线形状候选，对应 `R0 = 1、2、3` 时倍率约为 `2.905、2、1.095`。它们不作为默认平衡参数，也不构成已经验证的效率优势。

开轮保存 `Q0、D0、S0、R0、K`、三类投入和规则版本。轮内消耗、转出物质或阶段重置不重算更优惠的倍率；升级支撑单元、改变压缩物配比属于后续周目的准备操作。

## 5 有限预算中的科技与资源点

内部转换按统一物质当量记账。投入可以分配给科技设施、加工用料、可结算产物、协同工作与残余物。科技升级会消耗本轮库存；回收只把已有残余物变为可用库存，不重新生成一份初始投入。不同内部资源若可互转，转换和循环回收必须保持同一当量口径。

新技术在提高资源点相关产物产率的同时，需要更大的基础物质处理量。以下两项分开设计：

```text
产物产率 = 物质处理速率 × 单位物质产物产额
```

高级技术可以提高吞吐或产额，但建设成本、加工成本、共享成本仍进入有限预算。不能只因新技术显示更高产率，就认定库存较少的短轮也应该攀到最高科技；比较时需计入升级消耗和回本所需的剩余物质。同一技术阶段是否设置精炼、高通量、研究或协同路线，属于待验证的内容提案。

外部资源点仍只在最终结算时发放。轮内可以形成可结算产物或成果记录，但结算依据必须绑定实际完成、已支付成本的转换，不能靠循环触发里程碑、空转内部计数器或同一份转出资源重复领奖。物质当量与资源点价值不是同一种单位；成果报价、科技解锁的转换路径和奖励上限需要共同设计。

晚结算必须减少奖励不是当前要求。仅因物质逐渐耗尽、升级回本不足、耗电和周转时间增加，就可以产生结算取舍。寿命、不可逆熵、设施退化、维护消耗已有成果及独立回收率均保留待定，不作为首版数值模型的默认机制。欠压行为另见运行文档，不能自动等同于必然衰退。

## 6 共享成本与接收承载

所有有实际收益的共享都需要成本。物质转移真实扣除来源余额；研究、稳定或处理能力支援需要持续贡献和有限的本轮消耗，不能只扣可无限再生的计数器或只凭在线状态给永久增益。有限库存约束慢堆的成长和累计输出，持续供电不会把慢堆变成无限资源源头。

开局锁定 `K` 后，接收方不得先空载取得高利用率，再通过跨堆大量灌入物质绕过支撑。建议的原型规则是：开局预留接收负载，将 `D_reserved` 加入 `D0 = D_local + D_reserved`；运行时核对已接受的负载与接收额度。具体采用累计额度还是占用容量、不同资源的负载折算，以及转出后是否释放可用空间，仍需仿真确定，不能自动释放新的免费累计接收额度。

第一版单堆模型可以关闭物质跨堆输入；双堆原型先验证一种有成本的实时支援，再开放物质传输。这是实施顺序建议，不取消已确定的跨堆协同方向。

## 7 当前边界与下一步

已确定：三类投入、有限分级支撑、高级压缩物的双向效率取舍、开局 Sigmoid 升级物耗倍率、有限物质转换、共享有成本，以及通过多轮自动化优化收益。

暂定：特殊模块一次性。未定：题材最终包装、真实物品配方、支撑数量与等级、曲线参数、具体模块和科技树、产物到资源点的计价、接收负载规则、寿命与退化。猪咪居民投放或返还、文明长期养成没有列入当前主线。
