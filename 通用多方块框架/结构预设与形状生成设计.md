# 通用结构预设与形状生成设计

[文档首页](../README.md) · [框架设计总览](设计总览.md)

结构预设、长方体生成器、默认尺寸组、锚点定位和模板选择均由通用框架提供。接入机器引用预设，映射自身外壳、控制器与内部模块，并声明部件数量约束；无需维护一套机器专属的长方体生成算法。

## 定义、预设与机器的关系

| 内容 | 所属与职责 |
| --- | --- |
| 形状生成器 | 框架把尺寸、锚点与布局规则编译为角色格子表；通用长方体生成器使用目标 ID `thunderbolt:cuboid` |
| 结构预设 | 框架维护有命名空间的预设 ID、版本、形状参数、默认尺寸、可调范围和锚点策略 |
| 分层模板 | 通过同一框架加载字符层、角色与局部坐标，可描述非长方体结构 |
| 机器结构配置 | 选择默认/允许预设、映射具体方块与内部模块、声明本机的数量约束；必要时缩小允许尺寸范围 |
| `StructureDefinition` | 解析预设与机器配置后得到的不可变结果，供扫描、预览、材料清单和自动搭建共同使用 |

预设不附带加工倍率。相同预设可用于不同机器，外形大小本身不增加 FE、并行份数或配方通道。机器可以引用扩展预设与模板；已有通用形状和定位规则继续复用框架实现。

## 框架默认长方体预设

尺寸统一写为“宽 X × 高 Y × 深 Z”，数组顺序为 `[W, H, D]`。

| 预设 | 目标 ID | 默认尺寸 | 空间用途 |
| --- | --- | --- | --- |
| 标准工业型 | `thunderbolt:standard_industrial` | 9×7×9 | 一套完整物流、供能与处理部件的常规安装空间 |
| 集群生产型 | `thunderbolt:cluster_production` | 13×9×13 | 多路物料接口与较多通用部件 |
| 中央处理型 | `thunderbolt:central_processing` | 17×11×17 | 大型结构与大量外部连接 |

三种预设共享默认可调范围：宽/深 `7–31`、高 `5–15`，各轴步长为 `1`，允许偶数尺寸。选中预设后按它的默认尺寸初始化；手动修改必须同时满足预设范围、机器允许范围和框架体积/跨度预算。最终允许范围取这些约束的交集，无合法尺寸时在定义加载阶段报错。

这些尺寸组和范围在框架维护。接入机器只选择预设或收窄范围，不复制同一张预设表。

## 表面锚点与通用布局

本预设族使用“固定棱角、可替换表面、内部留空”的长方体布局。控制器采用前表面中央锚点，内部中央模块是可由机器启用的独立位置。生成优先级如下：

1. `(floor(W/2), floor(H/2), 0)` 是唯一控制器位置，占一格外表面，与相邻外壳齐平；结构向控制器背面延伸。
2. 至少两个坐标位于边界的格子是固定棱角角色，包含 12 条棱与 8 个角，不能替换为仓室。
3. 其余外表面是可替换角色位，使用机器声明的默认外壳、观察部件或允许的通用仓室。
4. 若机器启用内部中央模块，则 `(floor(W/2), floor(H/2), floor(D/2))` 为该模块的固定位置；没有启用时该位置仍留空。
5. 其他内部格子要求为空。线圈、夹层与其他内部布局通过框架模板或明确的模块位置声明表达，不任意占用空气位。

控制器与内部中央模块不是同一个方块。奇偶尺寸均使用同一 `floor(size / 2)` 规则，预览明确标记位置；水平四向旋转使用统一局部坐标变换，首期不支持镜像、倒置或任意斜向。规则必须得到唯一控制器和互不冲突的内部模块位置，否则定义无效。

以 9×7×9 为例：总体积 567，外表面 322 格，包含固定棱角 84 格、控制器 1 格和可替换表面 237 格；内部共 245 格。启用一个内部中央模块时，其余空气 244 格，共需 323 个实际方块。方块的具体名称和仓室数量由机器映射及玩家装配决定。

## 预设格式与机器引用

预设的目标资源路径为 `data/<namespace>/multiblock_presets/<path>.json`，机器结构定义仍使用 `data/<namespace>/multiblocks/<path>.json`。预设 ID 由资源路径确定，`format` 表示格式版本；以下是设计格式，不代表已有加载器实现。

标准工业型预设的参数示例：

```json
{
  "format": 1,
  "shape": {
    "type": "thunderbolt:cuboid",
    "default_size": [9, 7, 9],
    "minimum_size": [7, 5, 7],
    "maximum_size": [31, 15, 31],
    "step": [1, 1, 1]
  },
  "layout": "thunderbolt:framed_hollow",
  "anchors": {
    "controller": "front_center",
    "internal_module": "center"
  }
}
```

机器定义使用 `default_preset` 与 `allowed_presets` 引用预设；默认项必须属于允许集合。示例中的内部锚点只提供位置，是否安装及使用何种模块由机器映射声明。框架解析预设、应用机器约束和角色映射后，再编译最终定义；机器引用示例见[大型工厂结构接入](../大型过载处理工厂/结构与建造设计.md#数据包模板)。

## 选择、修改与恢复

控制器的通用结构页面列出允许的框架预设、可调尺寸与数据包模板，统一驱动预览和搭建。切换选择先进入框架维护流程，保留资源与任务，再使旧绑定失效并重新验证，不能自动拆除旧方块或清空带库存部件。

保存已选预设 ID、内容版本、解析后的尺寸、朝向以及机器结构配置版本；使用分层模板时保存模板 ID 与版本。重载后核验引用、角色映射和约束，预设被删除或无法解析时进入可诊断的结构配置缺失状态，保留库存与加工记录，不静默改用另一预设。

## 验收要求

- 两种机器引用相同预设时，角色坐标与材料计数使用同一生成器，差异仅来自明确的方块映射、内部模块与约束。
- 三种默认尺寸、手填奇偶尺寸和四个水平朝向在扫描、预览及搭建中一致。
- 未知预设、默认项不在允许集合、步长或范围无效、锚点冲突与约束交集为空均能定位报错。
- 预设切换、重载与缺失时保留仓室和任务，暂停规则与既有框架运行时一致。
