# 框架配置与参数版本

[文档首页](../README.md) · [框架设计总览](设计总览.md)

框架提供可配置的部件规格、建造与加工策略；具体机器使用这些参数定义自己的默认装配和运行方式。配置读取与版本管理由框架统一处理。

| 参数类型 | 维护位置与边界 |
| --- | --- |
| 结构与建造 | 全局扫描工作预算由框架维护，模板、尺寸、材料、部件白名单与数量由机器定义 |
| 普通仓容量 | [物流通用规范](仓室/物流通用规范.md)维护 T1–T4 键名额、每键容量、过滤与升降级规则 |
| ME 数量 | 标记、过滤与真实库存无设计上限，使用精确大整数；拉取目标由玩家配置 |
| 物流与网络 | [通用仓室网络接口](仓室/网络接入与任务接口.md)和物流规范维护开关、调用预算、频道与待机功耗 |
| FE 与能力贡献 | 能源、并行、调度仓文档维护等级表；机器声明基础份数、基础通道和整机封顶 |
| 加工策略 | [耗能与调度设计](加工/耗能与调度设计.md)定义线性 FE 工作量、默认最少 4 tick、AE/持续生产 3:1 接收权重 |
| 运行记录预算 | [运行状态与持久化](加工/运行状态与持久化.md)默认 256 条未完成批次、1,024 条交付/退款事务、每批 64 种键 |
| 专有成本 | 配方描述与适配器声明，不通过普通物料标记重复计费，不固定要求闪电 |

有限传输窗口、分页、缓存或事务预算不构成 ME 仓容量上限。默认值支持按对应环境实测调整，但不能通过数量截断消除超额库存。

所有容量和规则使用带版本的数据结构。降低参数时保留已接收资源，停止新增并排空或轮候；普通仓降级不满足容量时拒绝，ME 数据分窗和分段保存仍精确。

按“AE 任务机器”“持续生产机器”“两者混合”“大量机器同服”四组场景调参。机器的配置实例与专有规则留在自己的设计目录，大型工厂示例见[配方接入与机器参数](../大型过载处理工厂/配方接入与机器参数.md)。
