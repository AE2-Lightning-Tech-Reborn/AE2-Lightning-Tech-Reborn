# 通用仓室能力汇总与机器接入

[文档首页](../../README.md) · [仓室目录](仓室目录.md)

## 能力分工

通用部件提供能力，框架加工运行时依据机器配置统一调度和消费。结构体积提供部件安装空间，扩大空壳或增加样板总成本身不提高处理速度。

| 部件 | 提供的能力 | 框架加工运行时的职责 |
| --- | --- | --- |
| 能源接入仓 | 独立 FE 库存、当 tick 接收及内部供能额度 | 按真实加工进度请求 FE，不重复计算多方向调用 |
| 批量并行仓 | 当前等级的操作份数贡献 | 读取机器定义的基础份数与总上限，按源配方次数占用共享预算 |
| 协同调度仓 | 当前等级的配方通道贡献 | 读取机器定义的基础通道与总上限，按配方身份与执行指纹分组 |
| 输入仓、ME 输入仓 | 带来源的本地库存或网络物料视图 | 匹配配方、实际取料、处理部分取得与退款 |
| 输出仓、ME 输出仓 | 合法接收路径、库存与输出服务 | 按过滤与路由移交产物，只在成功转移后释放自身记录 |
| ME 样板总成 | 样板库存、provider 桥接与原网络端点 | 校验配方、接受任务、执行加工并提交已完成产物 |

## 汇总与预算

只统计已绑定且有效的部件。能源容量与吞吐分别求和，但真实储能仍独立保存在各能源仓。并行与调度仓按等级提供可相加贡献；基础值和总上限由机器定义，汇总与占用由框架执行，框架不把某台机器的封顶值写入所有部件。

`P = min(机器操作份数上限, 机器基础份数 + Σ并行仓贡献)`

`R = min(机器配方通道上限, 机器基础通道 + Σ调度仓贡献)`

全部输入路径、样板总成和同 tick 多次调用共享所属机器的同一预算。容量查询不是预留；实际接收重新核验并完成所有权提交。操作份数与配方通道相互独立，不因 FE 充足而自动突破任一上限。

## 能力降低与生命周期

拆换、失效或卸载后停止使用旧服务引用，按当前合法绑定重新汇总。机器不得因能力降低丢弃已接收资源：先停止新接收，再按剩余 FE 和通道轮候处理已有记录。部件只报告新能力与生命周期，不直接删除机器任务。

## 参数归属

部件等级、库存容量、吞吐与能力贡献表在各部件文档维护。允许安装的种类、数量上限、基础能力、整机封顶、加工耗能和调度权重由接入机器维护。大型过载处理工厂的配置见[工厂仓室接入方案](../../大型过载处理工厂/仓室接入方案.md)。
