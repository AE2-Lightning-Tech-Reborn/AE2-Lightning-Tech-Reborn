# 批量并行仓设计

[文档首页](../../README.md) · [仓室目录](仓室目录.md)

批量并行仓提高整机可同时承载的源配方操作份数，也限制单个配方的最大批量。

| 项目 | 设计 |
| --- | --- |
| ID 后缀 | `parallel_hatch_t1...t4` |
| 规格 | T1–T4 |
| 安装数量 | 由接入机器的结构定义与计数约束决定 |

## 等级与能力

以下为默认设计参数。

| 等级 | 增加的同时加工份数 |
| --- | ---: |
| T1 | 255 |
| T2 | 1,023 |
| T3 | 4,095 |
| T4 | 16,383 |

各等级提供上表中的份数贡献。所属机器决定基础操作份数和总上限，多个仓室线性叠加后受机器上限约束；汇总公式见[能力汇总与机器接入](能力汇总与机器接入.md#汇总与预算)。

“份”指执行一次源机器配方，不是产物个数，也不是一张样板。若一张样板编码源配方 4 次，接收 100 份样板就占用 400 份操作预算。

所有已接收且未完成加工的批次共享 `P`；空余份数不足时允许部分接收。完成加工但还在等待回网的产物不继续占操作份数，但仍占有界输出账本容量；输出账本满后禁止接新单。

## 界面与拆换

界面显示本仓贡献份数。移除后若当前占用超过新上限，停止新接收并保留全部在途批次，重成形后按当前能力完成，不作废已接收材料。
