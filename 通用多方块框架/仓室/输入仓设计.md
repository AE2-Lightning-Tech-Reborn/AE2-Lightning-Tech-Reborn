# 输入仓设计

[文档首页](../../README.md) · [仓室目录](仓室目录.md)

输入仓为持续生产提供本地普通物料，支持全部合法 AEKey。

| 项目 | 设计 |
| --- | --- |
| ID 后缀 | `input_hatch_t1...t4` |
| 规格 | T1–T4 |
| 安装数量 | 由接入机器的结构定义与计数约束决定 |

## 库存与取料

输入仓允许外部插入和取回闲置资源。机器从所有输入仓形成统一物料视图，同一键可跨仓满足配方，组件不同的键严格区分。已转入任务托管的资源从仓内扣除，不允许外部再次取走。

本地库存使用 `AEKey -> long`，物品、流体与其他合法键共享键名额。各等级的容量、过滤条目上限、适配接口与升降级规则见[物流通用规范](物流通用规范.md#普通仓等级与容量)。

## 过滤与自动拉取

输入仓可选精确键过滤，并带“自动拉取”开关，默认关闭。开启后从玩家启用的外侧方向按过滤与容量拉取；关闭时仍接受合法外部插入，机器仍可消耗已有库存。实际取得多少就记账多少，部分失败的剩余资源保留。

主动物流默认每 5 tick 调度一轮，邻居或库存变化可提前唤醒；多方向调用共享额度。调度、适配器和暂停条件见[自动物流规则](物流通用规范.md#自动拉取与自动输出开关)。

## 界面与拆换

界面显示等级、键名额、容量、过滤、外侧方向和自动拉取状态。拆除时回收仓内剩余库存；已进入任务托管的材料继续由控制器管理，不重复回收。解体后仍可通过有效的独立仓室接口访问本地库存，旧绑定的包装器必须失效。
