# 输出仓设计

[文档首页](../../README.md) · [仓室目录](仓室目录.md)

输出仓保存持续生产产物，支持全部合法 AEKey；AE 样板任务产物仍通过原样板总成回流。

| 项目 | 设计 |
| --- | --- |
| ID 后缀 | `output_hatch_t1...t4` |
| 规格 | T1–T4 |
| 安装数量 | 由接入机器的结构定义与计数约束决定 |

## 库存与接收

输出仓接收机器产物，外部只能提取。本地库存使用 `AEKey -> long`；容量预留覆盖已接受但尚未写入的产物，满时停止向该仓写入，不覆盖已有资源。各等级的容量、过滤条目上限、适配接口与升降级规则见[物流通用规范](物流通用规范.md#普通仓等级与容量)。

## 过滤、路由与自动输出

输出仓可选精确键过滤，并带“自动输出”开关，默认关闭。开启后向玩家启用的外侧方向输出/弹出产物；关闭时保留库存，外部管道仍可主动提取。成功交付多少就扣除多少，部分失败的剩余产物保留。

与 ME 输出仓共存时，控制器按资源配置路由，默认 ME 输出仓优先、普通输出仓兜底。多个输出仓按优先级选择，同优先级轮询，不复制产物。非物品键没有可用传输适配器时保留库存并显示原因，不伪装成物品掉落。

主动物流的 5 tick 调度、多方向共享额度及暂停条件见[自动物流规则](物流通用规范.md#自动拉取与自动输出开关)。

## 界面与拆换

界面显示等级、键名额、容量、过滤、外侧方向和自动输出状态。拆除时保存并回收本仓剩余资源，任务托管中的资源不重复回收；没有实体掉落形式的键使用持久化回收容器。
