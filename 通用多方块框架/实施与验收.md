# 通用框架实施与验收

[文档首页](../README.md) · [框架设计总览](设计总览.md)

框架完成结构、搭建、部件、加工、消耗与恢复的完整验收后，再接入具体机器。结构测试不依赖 AE；部件与加工测试使用真实所需接口、测试配方和可控成本适配器，不依赖 LT 工厂类或闪电类型。

## 结构内核实施顺序

在 Thunderbolt 实现并独立验证：

1. `StructureDefinition`、局部坐标变换、固定/可替换/空气/忽略角色与数量约束。
2. 参数化形状、分层模板加载与定义校验，输出统一格子表和材料需求视图。
3. `StructureScanner` 的有效/无效/区块未加载结果与定位诊断。
4. `StructureIndex` 的成员独占、位置/区块变更索引和原子绑定。
5. `StructureRuntime` 生命周期、立即失效门禁、合并复扫与有界调度。
6. 以两个小型测试定义验证框架不依赖 LT 工厂类、资源、闪电或 AE 合成。

结构内核门槛：不同定义与朝向都能使用同一套扫描和绑定逻辑；未加载区块不引发世界加载；稳定结构不逐 tick 扫描；两个控制器不能共享成员。达到这些条件后进入通用部件实现与验收。

## 通用部件实施顺序

1. 统一仓室角色、稳定部件身份、绑定校验、库存权威归属与回收协议。
2. 普通输入/输出仓的 AEKey 库存、T1–T4 容量、类型适配和自动物流。
3. 能源接入仓的独立 FE、同 tick 吞吐计数；并行/调度仓的等级贡献与能力汇总。
4. ME 输入/输出仓的标记、过滤、拉取/库存模式、大整数库存、网络权限及部分传输恢复。
5. ME 样板总成的库存、GUI、共用 provider 与机器加工接口，复用 TB 批量协议。
6. 部件菜单、分页/增量同步、分段保存、拆换恢复，以及与结构生命周期的联动。

部件门槛：同一组通用仓室能够接入两个不同测试机器定义，库存和任务资源不重复，服务不依赖某个工厂类、配方目录或闪电类型。

## 加工、消耗与恢复实施顺序

1. 实现 `ProcessingRecipeDescriptor`、目录版本、`ResourceInputView` 与无重复占用的材料分配器。
2. 实现 `ProcessingPatternCompiler`、样板真实性/倍率校验、快照及重载失效。
3. 实现 `ProcessingBatch` 和统一运行账本，处理托管、真实取料、部分失败与退款。
4. 实现 `MachineEnergyPool`、`ProcessingScheduler`、FE 工作量、有效时间、操作份数和配方通道预算。
5. 实现可选运行成本调用、真实支付、补偿与已支付恢复，缺省无专有成本。
6. 实现持续生产及 AE 样板流程、产物账本、部分交付、原端口回流和输出背压。
7. 接入机器 UUID 持久化、唯一运行实例、正常保存/加载、拆换与孤立记录恢复。
8. 完成通用搭建/维护页面、仓室 GUI、分页与增量同步。

## 独立测试定义

使用两个小型定义覆盖参数化生成与分层模板两种入口，组合固定部件、可替换位、内部模块、空气位和忽略位。具体方块由测试环境提供，不以大型工厂的仓室清单作为唯一测试素材。

## 结构内核验收场景

| 领域 | 成功条件 |
| --- | --- |
| 定义一致性 | 扫描、预览、材料清单与自动搭建使用同一格子表，空气与忽略位不计材料 |
| 定义校验 | 未知角色、重复位置、层尺寸错误、无效锚点和不可满足约束能在加载时定位 |
| 尺寸与朝向 | 两种定义入口和四个水平朝向共用扫描逻辑；可变尺寸有界，偶数尺寸定位一致 |
| 替换规则 | 只允许声明的部件替换，不因暴露 capability 自动取得合法角色 |
| 区块 | 枚举覆盖的全部必需区块，中间区块未加载返回 `INCOMPLETE`，不触发隐式区块加载 |
| 所有权 | 相交结构只有一个能取得冲突成员，提交失败不留下半绑定 |
| 失效 | 结构变化和区块卸载立即关闭旧服务入口，缓存包装器拒绝过期写入 |
| 生命周期 | 暂停、重新检查、成形和确认解体可区分；框架事件不直接清理机器资源 |
| 调度 | 稳定结构不逐 tick 扫描，同 tick 变更合并，未成形结构的有界候选区域能够被唤醒 |
| 独立性 | Thunderbolt 单独验证时不依赖 LT 工厂类、资源、闪电或 AE 合成 |

## 通用部件验收场景

| 领域 | 成功条件 |
| --- | --- |
| 普通仓容量 | T1–T4 按键名额与每键数量正确限额，各类型共用库存，升降级不丢资源 |
| ME 无限容量 | 超过 128 个标记/过滤项或 `Long.MAX_VALUE` 的单键数量仍精确保存，分页不构成容量限制 |
| 拉取模式 | 只补充启用标记到目标量，关闭补料后仍可消费真实库存 |
| 库存模式 | 无标记不提供物料，同网同键去重；匹配不扣料，实际取料按权限与返回量记账 |
| 模式切换 | 余料返还受阻时不启用重复网络视图，删除标记不删资源或退款记录 |
| 输出 | 开关关闭时保留资源；部分交付只扣实际量，不改道样板任务产物 |
| FE | 多方向和重复调用共享单仓吞吐限额，模拟不占额度，混装不复制储能 |
| 并行与调度 | 等级贡献正确，机器基础值和封顶可不同，多总成共享同一预算 |
| 样板总成 | 只发布本总成经机器验证的样板，100 份接受 24 份返回 76，不修改借用模板 |
| 网络回流 | 完成产物晚于 CPU 记账交付；换网、原端口缺失或归属不明时暂停恢复 |
| 持久化 | 库存、样板、能源与任务各有唯一持有者；部分传输、拆换和正常存档恢复不丢失或复制 |
| 多机器复用 | 同一通用部件服务两种测试机器，不通过具体工厂类提供库存、FE 或样板接口 |

## 完整加工链路验收

| 场景 | 成功条件 |
| --- | --- |
| 搭建 | 同一定义驱动预览、材料清单、搭建和扫描；保留合法带库存部件，失败不丢料或复制方块 |
| 配方 | 重叠 Ingredient、不同组件、标签和多来源物料正确分配；伪造产物、漏副产物和错误倍率被拒绝 |
| 物料 | 模拟不是预留，按真实取得量托管；部分取得失败只退实际持有量，不重复退款 |
| 消耗 | FE 按实际工作量扣除，额外成本缺省为空；部分支付失败不进入运行，恢复不重复扣费 |
| 调度 | 操作份数、不同配方通道与 FE 同时约束；AE 任务和持续生产公平共享能力 |
| 产出 | 满足 FE 和最短有效时间后才生成产物；回网晚于 CPU 记账，部分交付只扣真实数量 |
| 背压 | 事务预算或有限输出容量耗尽时等待；ME 无限库存不被执行预算伪装成容量上限 |
| 取消与恢复 | 未开工可退托管资源，已消费不全额退款；断网、卸载、拆装和正常存档恢复保持唯一归属 |
| 多机器 | 两种不同结构/配方/成本配置使用同一个运行时完成建造到产出的全链路，无 LT 工厂实现依赖 |

## 性能与阶段门槛

扫描按全服务器工作预算排队，失效门禁先于复扫完成生效。记录定义体积、控制器数量、变化频率、扫描工作量和服务器耗时；性能结论来自对应环境实测。

通用部件按端口公平分摊调用预算，库存和标记分页遍历、增量同步、分段保存，不因执行窗口而截断库存。结构、搭建、部件与完整加工链路全部通过后，再按[工厂实施路线](../大型过载处理工厂/实施与验收/实施路线.md)接入具体机器；工厂验收关注部件装配、配方、耗能、闪电与整机任务协作。
