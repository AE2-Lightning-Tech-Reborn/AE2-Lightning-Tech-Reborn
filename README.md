# 通用多方块框架与机器设计文档

`docs` 分支维护相关设计方案，不包含模组实现代码。文档描述目标与约束，不代表已经实现或发布。适用环境：Minecraft 1.21.1、NeoForge、Java 21。

## 维护约定

共用的搭建、仓室、加工、消耗与恢复规则在框架目录维护。具体机器只记录自身定义、配方/成本适配、参数和必要扩展，避免复制框架运行链路。修改共用参数时同步检查接入机器与验收要求。

## 修改规则

所有修改（包括本 README）必须提交以 `docs` 为目标分支的 Pull Request（PR），通过 PR 合并。禁止直接推送到 `docs`，也不允许强制推送或删除该分支。

请从 `docs` 创建修改分支，仅提交与设计文档有关的改动。
