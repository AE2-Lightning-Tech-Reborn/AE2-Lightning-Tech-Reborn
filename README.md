## 本代独立机器：大型过载处理工厂

本代在 LT Reborn 内独立实现，不新增 TB 通用框架。[工厂设计目录](大型过载处理工厂/设计目录.md)维护普通／苍穹专用成型、固定背面九仓位、[36／144 槽样板仓与水晶仓](大型过载处理工厂/仓室接入方案.md)、[工艺解锁与机器参数](大型过载处理工厂/配方接入与机器参数.md)、[0t 与被动调度](大型过载处理工厂/0t执行与被动调度.md)、[供电与闪电成本](大型过载处理工厂/闪电运行成本设计.md)及接入验收。苍穹专用档为整机每 tick 1,024 次源操作、0t，仅执行苍穹转换配方。

## 磁约束球状闪电反应堆（设计草案）

[反应堆设计目录](磁约束球状闪电反应堆/设计目录.md)维护 v0.1 草案：7×7×7 中央反应腔、六向磁极阵列、24 个功能模块，以及 FE、现有高压／极高压闪电和单一原生等离子体之间的产出取舍。结构、运行参数、启停与事故规则在独立目录内维护，配方、最终数值和实现接入方式仍待确定。

## 维护约定

本代工厂的结构、仓室、加工、消耗与恢复以工厂目录为准，在 LT 内实现专用逻辑。框架目录保留下一代抽象与迁移规划，其通用仓室、预设与验收不构成本代交付要求；未来是否抽取共用实现另行决定。
