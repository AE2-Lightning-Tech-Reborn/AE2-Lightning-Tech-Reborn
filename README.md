## 本代独立机器：大型过载处理工厂

本代在 LT Reborn 内独立实现，不新增 TB 通用框架。[工厂设计目录](大型过载处理工厂/设计目录.md)维护普通／苍穹专用成型、固定背面九仓位、[36／144 槽样板仓与水晶仓](大型过载处理工厂/仓室接入方案.md)、[工艺解锁与机器参数](大型过载处理工厂/配方接入与机器参数.md)、[0t 与被动调度](大型过载处理工厂/0t执行与被动调度.md)、[供电与闪电成本](大型过载处理工厂/闪电运行成本设计.md)及接入验收。苍穹专用档为整机每 tick 1,024 次源操作、0t，仅执行苍穹转换配方。

## 磁约束球状闪电反应堆（设计草案）

[反应堆设计目录](磁约束球状闪电反应堆/设计目录.md)维护 v0.1 草案：FE、现有高压／极高压闪电和单一原生等离子体之间的产出取舍。多方块结构整体暂定，7×7×7 削角中央反应腔、六向磁极门架与 48 个模块槽仅为候选方案。结构、[控制器界面](磁约束球状闪电反应堆/控制器界面.md)、运行参数与运行模型、启停与事故规则在独立目录内维护；配方、最终数值和实现接入方式仍待确定，不增加复杂度的完善方向见[待定事项](磁约束球状闪电反应堆/待定事项.md)。

## 猪咪远程工作站（实现设计）

[猪咪工作站实现设计](猪咪远程工作站/实现设计.md)定义过载控制器激活普通、超维和创造猪咪后的玩家代理、第一人称遥控、独立背包装备、原生区块加载及死亡坐标广播。AI 通过客户端 HTTP → 游戏数据包或服务端 HTTP 两条路径使用同一服务端执行器，并通过 MCP 与 skill 完成现场操作、AE2 终端作业和机器配置。文档包含权限、任务恢复与分阶段验收要求；功能尚未实现。

## ME 大型过载集成中心（设计草案）

## 无线过载控制器能源（设计草案）

[控制器能源设计方案](无线过载控制器能源/设计方案.md)定义运行期间从 Applied Flux 提取 FE 补足 AE、频率卡绑定普通用电机器及无线 FE 供电。自动绑定最多试送 100 FE，等待目标执行一次机器 tick 后检查储量增量；手动绑定与已绑定设备运行不探测。文档包含 Trash Cans 与 JustDynaThings 黑洞的实现核对、探测边界和验收场景，功能尚未实现。

## 过载存储管理器（设计草案）

[存储管理器设计方案](过载存储管理器/设计方案.md)定义网络存储来源分层、驱动器逐盘查看、驱动器与磁盘独立适配，以及指定源盘和目标盘的搬运任务。任务支持预检、蓄能后启动、受预算约束的执行、暂停取消及持久化恢复；大任务采用明确的分批执行方式，不能因蓄满能量就无条件在单 tick 扫完全部资源。首批范围为原版驱动器及受支持磁盘，后续扩展存储总线和第三方设备；能耗、蓄能参数与最终兼容范围仍待验证，功能尚未实现。

## 闪电科技资源（独立附属设计草案）

[设计方案](闪电科技资源/设计方案.md)定义独立附属的资源反应堆、封闭周目、提前最终结算和资源转化器。[投入与物质转换](闪电科技资源/投入与物质转换.md)细化物质、支撑、特殊模块三类投入：高级压缩物以外部原料利用率换取承载效率，支撑数量有限且分级，开局支撑比经 Sigmoid 锁定科技升级物耗倍率；内部转换与共享受有限物质预算约束，特殊模块暂定一次性。

[运行协同与自动化](闪电科技资源/运行协同与自动化.md)保留各堆独立重置、有成本的快慢堆协同、按玩家运行数量逐台翻倍耗电和平方根供电加速。首次完整通关后，后续周目可从开局或极早期使用保留的自动化；寿命、退化与晚结算损失继续待定。[资源转化与来源计价](闪电科技资源/资源转化与来源计价.md)维护资源点 AEKey、来源解锁、概率报价及外部经济边界。[后续设计与原型路线](闪电科技资源/后续设计与原型路线.md)安排最小参数表、单堆与双堆原型、可玩界面及 Minecraft 接入；[验证与待定事项](闪电科技资源/验证与待定事项.md)列出检查标准。首发平台、独立仓库、依赖及永久扩展仍待定，当前没有实现代码或已验证的平衡数据。
