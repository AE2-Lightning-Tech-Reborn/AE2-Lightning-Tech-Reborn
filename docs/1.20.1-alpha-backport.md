# 1.20.1-alpha 回移记录

基准：Reborn `main` 的 AE2LT `ef8eb5d0a`（含 `c3189c265` 修复）；目标为 Minecraft 1.20.1 / Forge / Java 17。

## 已适配的功能

- 天枢有线与无线合成工作站：原生合成、锻造、铁砧、切石、存储元件配置，工作站输入随终端保存；共享窗口同步、防重复领取、批量补料和原生回调。
- 无线万能终端合并、天枢磁铁/工具设置、槽位滚动、饰品栏识别；JEI 从真实 ME 库存补料并校验菜单、请求、库存、能量及连接。
- 保存的维持视图与临时界面切换分开；上传失败保留已付费样板；旧种子先返还再补料及返还受阻提示。
- 皮格米建筑方块与连接面板；附近玩家闪电彩蛋范围/显示限制；中文指南与终端美术。
- 轨道炮百分比处决及独立极高压光束模块：配置、模块规则、工作台、设备面板、同步、伤害类型与耗能结算。
- 催化器配方支持明确流体，省略时仍为 1000 mB 水；存档保留流体合同；皮格米版本只接受水、独立世界刻运行且不参与无线频率网络。
- AppGen 条件配方与特殊流体条件配方沿用 Forge 条件/标签格式；AE2LT 自定义配方继续使用其既有 `id` 产物字段。
- 量子桥拆除后清理失效集群，并同步 AE2/WTLib 两层网格缓存，支持远端重建和本地接入点回退。

## 追加核对 main 最新修改

- `c3189c265`：注册无线合成终端的 GridLinkables；原生接入点菜单验证两种终端绑定/重新绑定且 NBT 保持。
- 超大配方数量继续使用 Forge 的正整数 JSON 与 VarInt 网络编码，原生登录配方包验证 1、64、65、99、100、127、128、255、256、16384 的输入/产物数量及输出 NBT。补充拒绝整数越界和非整数，避免 JSON 截断后意外接受。
- `ef8eb5d0a`：同步皮格米工作站、结晶催化器模型及材质；对应资源逐字节一致，模型 JSON 可解析。

## 版本边界

Useless Mod 的通用样板编辑、模具中心和对应 JEI 路由未加入 Forge：已核对该项目远端 `develop/1.20.1` 为 `b51eb2905613b9be24bf0d812789d682f2015105`，其中没有 `OmniversalPatternEncoding`、`AlloyFurnaceRecipeCatalog`、通用样板物品或模具中心。对接这些功能需要先移植外部模组本身。

1.21 的 Data Components、StreamCodec、RecipeHolder、WTLib API 拆分和独立图标注册使用 1.20.1 的 NBT、FriendlyByteBuf、Recipe 与原生 WTLib 接口实现。平台专属客户端调试探针未移入；保留可在 Forge 执行的游戏内回归夹具。

## 验证入口

使用 Java 17，先在同级 Thunderbolt 仓库执行 `./gradlew publishToMavenLocal`。

```sh
./gradlew build publishToMavenLocal
./gradlew -I scripts/tianshu-workstation-test.init.gradle runGameTestServer
./gradlew -I scripts/alpha-feature-test.init.gradle runGameTestServer
./gradlew -I scripts/main-fixes-test.init.gradle runGameTestServer
```

- 工作站/JEI：12 项原生 GameTest，验证真实 ME、JEI 服务端转移、精确 NBT、原生点击/回调、共享窗口、磁铁和 WUT。
- 催化器/轨道炮/量子桥：28 项原生 GameTest，含完整加工周期、存档、堵塞恢复、反加速、实际伤害与资源结算、拆桥重连。
- 未安装的外部模组条件配方会跳过其专属生产周期；通用流体行为通过水/岩浆夹具验证。这些结果不等同于所有外部模组组合的游戏实测。
- 最新 main 修复：4 项原生 GameTest（配方数据包加载、真实登录同步包、非法数量拒绝、无线接入点真实菜单绑定）。
- 1218 项 JUnit 通过；发布 JAR 不包含 GameTest 夹具。
