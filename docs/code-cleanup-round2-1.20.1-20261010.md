- 删除没有调用的 3 个私有方法：`RailgunBinding.distance`、`TianshuPatternEncodingTermScreen.setViewMode`、`PhaseFlightSubmodule.booleanOption`。

- 修正装甲容器注释为本版本实际的 ItemStack NBT 持久化方式。
