# AE2 Lightning Tech 2.1.4-beta

Minecraft 1.21.1 / NeoForge · Beta

## 中文

相对正式版 2.1.3 的更新：

- 新增矩阵 T3 样板仓，单仓可容纳 288 个样板，50 仓总容量为 14,400。支持使用致密拓扑晶格将已有 T2 仓原位升级为 T3，保留已存样板。
- 矩阵改为由各样板仓独立发布样板并接收合成请求；端口样板管理支持逐仓切换，减少大型矩阵的单次同步量。
- 特斯拉线圈和水晶催化器支持 AE2 红石卡，可选择忽略红石、有信号工作或无信号工作；暂停时保留加工进度。
- 修复 Mekanism 自动回收对流体和化学品输入的保护，仅回收机器配置为产物输出的储罐内容。
- 修复与 MBD2／LDLib 共用时，异步保存 AE 节点触发 `Server thread required` 异常并持续刷日志的问题，保留原有无线能源记账规则。
- 修复 Mekanism Extras 等机器名称颜色动态变化导致天枢样板上传失败的问题；有线、无线终端均适用，保留上传撤回，并继续拒绝真实改名或目标内容变更后的旧请求。
- 天枢样板上传支持 ExtendedAE Plus 的超级与终极矩阵。
- 安装 Apothic Attributes 时，可用漂浮物质将粗制药水酿造成其漂浮药水。
- 统一过载合金锭的通用标签，改善配方兼容；调整 GUI 文字对比度、无线终端按钮布局，并统一机器输出配置界面。
- 依赖 Thunderbolt Core 2.0.3；核心没有新增内容，本次不更新其版本。

## English

Changes since the stable 2.1.3 release:

- Added T3 matrix pattern warehouses with 288 slots each, or 14,400 slots across 50 warehouses. Upgrade existing T2 warehouses in place with dense topological lattices while preserving stored patterns.
- Matrix warehouses now publish their own patterns and receive their corresponding crafting requests. The port menu switches between individual warehouses to reduce synchronization size.
- Tesla Coils and Crystal Catalyzers now accept AE2 redstone cards, with ignore, high-signal and low-signal modes. Pausing preserves crafting progress.
- Protected Mekanism fluid and chemical inputs during automatic returns; only tanks configured as product outputs are exposed for extraction.
- Fixed repeated `Server thread required` errors and log spam when MBD2/LDLib serializes AE nodes asynchronously, while preserving wireless energy accounting.
- Fixed Tianshu pattern uploads failing when machines such as Mekanism Extras factories animate their name colors. Applies to wired and wireless terminals, preserves undo, and continues to reject stale requests after actual renames or target content changes.
- Added Tianshu pattern upload support for ExtendedAE Plus super and ultimate matrices.
- Floating Matter can brew Awkward Potions into levitation potions when Apothic Attributes is installed.
- Unified the common overload alloy ingot tag, improved GUI text contrast and wireless terminal button placement, and consolidated machine output configuration screens.
- Requires Thunderbolt Core 2.0.3. The core has no new changes and is not being rereleased.
