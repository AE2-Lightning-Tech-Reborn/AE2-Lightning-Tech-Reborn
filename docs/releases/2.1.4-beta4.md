# AE2 Lightning Tech 2.1.4-beta4 (NeoForge 1.21.1)

对比版本 / Compared with: `2.1.4-beta3`

## 中文

- 接入 MMCR 原生批量样板发配，支持智能翻倍及跨加工周期探测。
- 完善闪电模拟室后期合成配方与苍穹采集升级产线。
- 修复频率卡终端连接与石英纤维网络隔离，补齐天枢闭环样板仓界面。
- 兼容 Inventory Essentials，避免其整理操作干扰 AE2 仓储槽位。
- 修复过载接口配置库存读取递归，并保留替换库存的限制。
- 修复天枢万象模式标签图标触发的客户端崩溃。

需要 Thunderbolt Core 2.0.3（NeoForge 1.21.1）。本版本仅发布到 GitHub。

## English

- Added native MMCR batch pattern dispatch with smart batch scaling and detection across processing cycles.
- Expanded late-game lightning simulation chamber recipes and the Firmament collection upgrade progression.
- Fixed frequency-card terminal connections and quartz-fiber network isolation, and added the Tianshu closed-loop pattern storage screen.
- Added Inventory Essentials compatibility to keep inventory sorting from interfering with AE2 repository slots.
- Fixed recursive overloaded-interface configuration inventory access while preserving replacement inventory restrictions.
- Fixed a client crash caused by the Tianshu Omniversal mode tab icon.

Requires Thunderbolt Core 2.0.3 for NeoForge 1.21.1. This prerelease is published only on GitHub.
