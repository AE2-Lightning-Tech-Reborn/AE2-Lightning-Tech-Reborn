# AE2 Lightning Tech 2.1.4-beta3 (NeoForge 1.21.1)

对比版本 / Compared with: `2.1.4-beta2`

## 中文

- 天枢一键迁移支持样板磁盘内的合成配方，覆盖磁盘供应器方块与部件、批处理装配室及 ECO F 系列样板总线；按磁盘 API 消耗空白样板，保留磁盘并在拒收时回滚。
- 修复天枢编码自动上传时的界面闪烁，保留当前编码界面的连续操作。
- 修复闪电过载接口缺失 ME 存储能力导致存储总线无法正常连接子网的问题。
- 精简矩阵样板迁移按钮提示，并完善磁盘迁移及矩阵仓库路由回归场景。

继续依赖 Thunderbolt Core 2.0.3（NeoForge 1.21.1）；封包供应器可继续使用 1.2.4-beta2。

## English

- Tianshu pattern migration now supports crafting recipes stored on pattern disks in block/part disk providers, batch assembly chambers and ECO F-series pattern buses. Migration follows the disk API blank-pattern accounting and rollback protocol while keeping disks in their original devices.
- Fixed screen flicker during automatic uploads from the Tianshu pattern encoding terminal.
- Fixed overloaded-interface subnet connections by exposing the expected ME storage capability to storage buses.
- Simplified matrix pattern migration button tooltips and updated disk migration and warehouse-routing regression scenarios.

Requires Thunderbolt Core 2.0.3 for NeoForge 1.21.1. Packaged Pattern Provider 1.2.4-beta2 remains compatible.
