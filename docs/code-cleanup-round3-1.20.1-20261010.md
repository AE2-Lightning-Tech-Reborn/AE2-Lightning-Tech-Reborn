# Forge 1.20.1 第三轮代码精简（2026-10-10）

本轮针对 `1.20.1-alpha`，基线为 `ff6845d19df7225c08e2e9d2c4778fdea7fbb4dc`。

## 修改

- 水晶催化器、闪电组装室、闪电模拟室的输出设置屏幕复用已有 `MachineOutputConfigScreen`。保留原屏幕类和构造入口，每个屏幕继续指定自己的 JSON、标题与清除按钮文字。
- 闪电模拟室输出按钮复用超载工厂按钮的绘制逻辑，保留原状态提示词；既有按钮构造入口保留。
- 5 个 JEI 分类和 EMI 统一使用不依赖查看器 API 的 `RecipeEnergyFormat`，消除 6 份相同的能量缩写和舍入算法。
- 删除仅写不读的装甲惯性 armor-id 缓存、爆炸半径平方和催化器输出槽字段。输出槽仍正常注册。
- 删除 8 个私有辅助方法中的 11 个未使用参数；保留函数接口要求的参数和公开签名。
- 删除固定非空 `List.of` 之后不可达的空列表判断。

涉及 29 个生产 Java 文件（含一个共用格式化类），源码净减少 468 行，不含本报告。测试与资源文件、公开 API、网络协议、存档字段、许可证和署名均未修改。
