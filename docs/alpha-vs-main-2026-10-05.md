# AE2LT Reborn alpha 相对 main 的变更

本文整理截至 2026 年 10 月 5 日，Minecraft 1.21.1 版本 alpha 相对 main 的实际功能、数值和资源差异，供版本审阅与发布说明使用。比较基线为 main [`8c22d712`](https://github.com/AE2-Lightning-Tech-Reborn/AE2-Lightning-Tech-Reborn/commit/8c22d712b99cc5b4a3fd22a4b10e8f0c28ef2ba0) 和 alpha [`03fd858f`](https://github.com/AE2-Lightning-Tech-Reborn/AE2-Lightning-Tech-Reborn/commit/03fd858f1bda128d71eb38c5a16647356c62798c)，并包含与本文同批次的极高压光束模块配方、代偿和颜色修复。

当前 main 已包含采矿工厂、超载 IO、苍穹织雷护甲、彩虹猪咪、天枢工作站及工厂借用配方等基础功能。以下记录这些功能在 alpha 中的后续变化，合并过的基础功能不重复计为新增。

## 机器容量与数值

| 项目 | main | alpha |
| --- | --- | --- |
| 雷电装配室 FE 容量 | 1M | 20M |
| 雷电模拟室 FE 容量 | 1M | 20M |
| 采矿工厂 FE 容量 | 1M | 4M |
| 采矿工厂默认基础并行 | 1，与工厂共用相关配置 | 8，使用独立配置 |
| 采矿工厂矩阵数量上限 | 32 | 8，每个矩阵提供 256 并行，最高 2048 |
| 超载 IO 物品基础单次转移额度 | 32,768 | 8,388,608 |
| 超载 IO 每个矩阵的额度倍率 | ×8 | ×32 |
| 超载 IO 矩阵数量上限 | 16 | 8 |
| 超载 IO 基础转移尝试次数 | 1 | 4，每个矩阵增加 2 次，最多 16 次 |
| 11 种 AE2CS 母岩配方基础产出 | 8 | 16 |
| 极高压光束模块的晶格材料 | 1 个超维拓扑晶格 | 16 个纠缠拓扑晶格 |

超载 IO 按 AE 操作数计算转移额度，流体等资源按各自的操作单位换算，并对数量溢出进行饱和处理。默认每 5 tick 转移以及速度卡缩短间隔的规则继续沿用。

采矿工厂未安装矩阵时使用基础并行，安装后改用矩阵提供的并行。掉落采样预算配置的最大可选值从每 tick 1024 提高到 4096，默认值仍为 8。

## 机器充电与输入转出

- 修复机器从 ME 网络提取 FE 的补充逻辑。首次检查及每 20 tick 的周期检查都会在存在缺额时尝试补电，部分补充后继续充至满容量。
- 修复空闲、缺少材料或输出受阻时不充电，以及网络后来加入 FE 后无法恢复的问题，覆盖特斯拉线圈、装配室、模拟室、超载处理工厂、晶体催化器和采矿工厂。
- 装配室、模拟室、超载处理工厂和采矿工厂增加“转出输入物品”按钮。操作将输入转入输出，并按现有自动导出设置尝试导出；未转出的物品保留在原库存，界面反馈转出与剩余数量。
- 修复采矿工厂对 Silent Gear 等损坏后仍保留物品的工具判断。工具损坏后停止加工，保留损坏工具，并按实际处理的输入扣除消耗。

## 配方与晶体催化器

### 极高压光束模块

将极高压光束模块配方中的 1 个超维拓扑晶格替换为 16 个纠缠拓扑晶格。调整后的完整输入与消耗为：

| 材料或消耗 | 数量 |
| --- | ---: |
| 过载模块基底 `ae2lt:overload_module_base` | 1 |
| 纠缠拓扑晶格 `ae2lt:entangled_topological_lattice` | 16 |
| 闪电坍缩矩阵 `ae2lt:lightning_collapse_matrix` | 8 |
| 苍穹超导丝 `ae2lt:firmament_superconducting_wire` | 16 |
| 过载处理器 `ae2lt:overload_processor` | 16 |
| FE | 32,000,000 |
| 极高压闪电 | 256 |
| 产出极高压光束模块 | 1 |

配方见 [railgun_module_ehv_beam.json](../src/main/resources/data/ae2lt/recipe/lightning_assembly/railgun_module_ehv_beam.json)。

### 母岩与处理器

- 新增紫水晶母岩、AE2 完美赛特斯母岩、LT 完美超载晶体母岩，以及 AppGen、NeoECO 对应完美母岩的可复用催化配方，基础产出为 16；模组兼容配方按对应条件加载。
- 修正催化器并行计算，计入配方产量、矩阵倍率和输出槽容量，避免高产量配方在空输出槽下仍无法启动。
- 增强处理器原料推导，支持仅中间槽输入的压印步骤，继续向前展开原料链，不把中间印刷件作为直接输入。
- 优先使用数量可逆的压缩块路线，避免为已压缩的材料额外生成重复散装路线；硅块优先采用 ExtendedAE，其次采用 LT。无法安全展开的循环或超限路线会被跳过。
- 删除旧的 `ae2_fluix_pearl` 与 `appflux_harden_insulating_resin` 两条工厂配方。
- 采矿工厂合成改用超载机器框架，超载 IO 合成改用终极超载核心。

处理器推导细节见 [过载工厂复用反应仓配方](overload-factory-borrowed-recipes.md)。

## 电磁炮代偿与光束颜色

- 极高压光束接入过载内核的高压代偿。优先消耗现有极高压闪电，仅对缺额按 16 高压闪电兑换 1 极高压闪电；未装内核或资源不足时停火。
- 支付前检查两种闪电库存，实际扣除出现短缺时退回已扣闪电及本次 FE，避免半扣费。
- 服务端同步实际光束模式。普通高压光束为青蓝色，极高压光束为粉白色，主光束、端点、旁支电弧和连锁电弧一起切换；高压代偿保留极高压的颜色与伤害。
- 光束更新与连锁效果数据包新增模式字段，并提升这两个数据包的协议版本；服务器与客户端需要同时更新。

## 天枢合成报告与终端

- 恢复“打开合成树”和终端样式按钮，支持小、中、高和全屏布局。中等布局与 AE2 原生尺寸一致，修复滚动到最后一行等问题。
- 接入原生缺料提示，以及取消、重试、重新计算流程。
- 重新计算始终使用首次计算时的库存快照，扣除实际发现的缺料。同一种材料在重复失败时记录最大缺额，每轮重新计算只扣减一次；不会重新读取网络库存或把库存增加回来。
- 调整锻造、铁砧和切石等工作区的槽位、箭头、滚动条与按钮位置，补充升级槽背景及翻页提示，并修正终端明暗模型映射。

## 接口与无线传输

- 统一超载接口和超载样板供应器的翻页控件：左键下一页、右键上一页、滚轮翻页；单页隐藏页码，由服务端统一处理翻页状态，避免重复翻页。
- 修复无线模式下 AppliedFlux 向相邻方块供电的问题。无线模式仅向绑定目标供电；未绑定时不会通过相邻方块绕过绑定规则。
- 修复供应器关闭“导入过滤”后，自动回收仍受到样板产物限制的问题。
- 频率卡增加瞄准设备切换连接的快捷键，默认不绑定按键。可从手持、饰品栏、快捷栏与背包查找已绑定卡；存在歧义时提示玩家手持指定卡。
- 无线连接目标的准入判断交由供应器接口处理，支持附属模组扩展目标与拒绝原因。
- 优化库存变化唤醒、成功槽位缓存、原版桶传输路径、批量补料及传输节奏，减少重复扫描和冷启动探测。库存唤醒注入采用可选形式，无法注入时保留轮询路径。

## 猪咪与配方查看器兼容

- 修复 IPN 对猪咪虚拟槽执行 Shift 点击、丢弃操作时误操作玩家快捷栏物品的问题，保留真实背包槽的正常操作。
- 彩虹猪咪增加颜色循环和四件相同物品的布局染色，保留名称、附魔、容器内容等组件数据。
- 调整彩虹表面的像素效果、原版方向光照及从前向后斜向流动的颜色效果。
- 修复连接材质方块和半砖的物品显示变换。
- 改善不同 JEI 版本的配方转移按钮兼容，保留 Alt 连续上传操作及模拟点击与实际点击的区分。

## 物品显示与资源

- 恢复采矿工厂、超载 IO、超载合金砧、天枢合成终端和猪咪建筑系列在创造物品栏中的显示，并移除 EMI 对这些物品及相关配方的隐藏。
- 更新超载合金砧模型、贴图及染色基底贴图。
- 更新采矿工厂、超载 IO、晶体催化器与猪咪指南，将部分冗长提示移入指南。

## 代码组织与比较范围

客户端类按合成、机器、供应器、天枢、渲染等功能分包，逻辑类按供应器、接口与传输等职责分包；同时增加充电、无线供电、翻页、合成报告、IPN、染色等测试与客户端验证工具。

上述两个基线提交的文件树之间共有 458 个文件差异，其中 222 个涉及重命名或移动。该统计不含本文及同批次的极高压光束配方、代偿和颜色修复，也不表示新增了 458 项功能。

两端声明的版本一致：Minecraft 1.21.1、NeoForge 21.1.220、AE2LT 2.1.1、Thunderbolt 2.0.0。本次比较仅覆盖 Reborn LT 的这两个基线，不包含其他 Minecraft 版本分支或尚未迁入 alpha 的本地功能。
