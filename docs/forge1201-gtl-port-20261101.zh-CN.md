# 普通 Forge 1.20.1 内容移植至 GTL（2026-11-01）

来源为 [普通 1.20.1 的 `2df9c5b5`](https://github.com/AE2-Lightning-Tech-Reborn/AE2-Lightning-Tech-Reborn/commit/2df9c5b5d4c1f8efb6567b4bc01f4b1edf9c59f7)，相对前次已合入范围 `c568e675` 共 18 提交、442 条上游路径。保留 GTL 分支的批量回执、AE 预付与退款、天枢派发及可选接口边界，形成单个本地汇总提交；未推送。GTO 不参与比较，main/alpha 的新红石控制、配色和酿造功能不在本次同版本范围内。

当前产物为 **AE2LT Forge 1.20.1 GTL 2.1.3-beta1**，配套 **Thunderbolt Core GTL 2.0.4**。移植和定向检查完成不代表完整整合包验收通过，性能及未验收项见下文。

## 内容与适配

- 纳入此前独立工作树中已完成的无线 FE 供电、网络管理、远程菜单、频率卡批量连接及持久化能量账本。
- 纳入上传别名、服务端撤销、精确请求路由、JEI 新旧接口、Useless 万象草稿/转移、实际水晶采集、Omni Upgrades、移动包装器与机器升级绑定修复。
- 保留 GTL 批量导出、能量与资源回执、木桶通知及调度适配；纳入接口拆装的预付 AE/待退 FE 交接，以及上传撤销时的异常回调、背包溢出返还保护。网络协议为 `15`，客户端和服务端须成对更新。
- 移植 `2df9c5b5`：异步保存 AE 节点时只输出已有 claim，避免访问服务端线程专属 ledger 或导出临时预算；主线程仍保留同 tick 拆分/合并的预算关系。claims 使用同步 IdentityHashMap，ledger 的线程保护保持有效。
- 移植三个异步序列化 GameTest，并加入原无线管理测试入口，覆盖无能量状态节点、既有 FE/AE/隔离余额与未决提取，以及同 tick 网络拆分合并预算。
- 将资源过滤明确设为 UTF-8，修复 Windows 系统编码下 `pack.mcmeta` 中文被损坏的发行问题。初次失败制品和审计原样保留，修复后另行冻结。

新增上游 NeoECO 适配、注册、配方和测试夹具继续排除；没有恢复六条已排除路径。既有 GTL 基线的 NeoECO 文件、依赖与 Mixin 状态保持原样，发行审计逐项核对。项目许可证及必要署名保留。
