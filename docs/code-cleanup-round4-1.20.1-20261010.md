# Forge 1.20.1 第四轮代码精简（2026-10-10）

本轮针对 `1.20.1-alpha`，基线为 `19c8f1a73ad1d0a735df4388dd0167e3e59f477e`。

## 修改

- 闪电组装室、闪电模拟室、特斯拉线圈、大气电离器的能量条复用已有 `OverloadProcessingFactoryEnergyBar`。保留原类、构造入口、数据来源和各自的翻译键；工厂原有两个构造入口也保留。
- 保留水晶催化器能量条的变体隐藏和数值限制逻辑。
- 苍穹转换配方输入复用已有 `RecipeContainerInput`，删除重复的只读容器空操作。原容器方法继续由基类提供，槽位校验、输入复制和索引行为保留。
- 删除 15 个私有辅助方法中共 16 个未使用参数，包括只剩转发用途的参数。公开入口与函数接口要求的参数保留；删除的调用实参均为普通变量读取。
- 压缩批量合成核心和配方输入基类的重复说明，保留输入模板、上游材料提取、容量/能量检查和五 tick 输出节奏的约定。

涉及 13 个生产 Java 文件，源码净减少 272 行，不含本报告。测试和资源文件、许可证及必要署名未修改；网络协议和存档字段未修改。
