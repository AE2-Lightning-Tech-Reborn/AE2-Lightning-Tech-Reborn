# 天枢合成终端与工作台

有线、无线天枢合成终端共用合成台、锻造台、铁砧、切石机与元件工作台。安装完整 AE2WTLib 时，无线版还接入万能终端、装备、磁铁设置和垃圾页。只有嵌入的无线终端 API 时，仍提供独立无线终端。

本功能恢复自原项目 alpha 的合成终端及其后续修复，保留 Reborn 的大数量库存显示。配方查看器支持 JEI；EMI 不在此次恢复范围内。

## JEI 与 Ctrl 补料

合成、锻造、切石和铁砧可通过 JEI 转移配方。普通点击使用现有物品。Ctrl 点击先使用工作槽、网络库存和背包中的实际材料，再对仍然缺少且存在样板的物品打开 AE2 原生合成确认。相同物品的缺额合并计数；例如需要四个铁锭、已有一个时只请求三个。任务完成后，再次转移即可使用产出的材料。元件工作台不参与配方补料。

服务端从配方 ID 解析实际锻造、切石配方，重新核对库存、视图过滤和锁定背包槽。铁砧请求携带输入模板；真实输入保留组件，产物、材料消耗和费用由原生菜单及模组回调决定。不会用新造的完整工具替代需要修理的受损工具。

## 工作台输入的保存

锻造、铁砧、切石的六个真实输入槽，以及元件工作台的存储元件、复制模式和配置，均归终端所有。有线终端保存到部件 NBT；无线终端保存到物品组件。铁砧编辑名称、切石配方选择一并保存，输出预览与经验费用由原生菜单重新计算。

切换工作页、万能终端类型、进入合成确认和关闭界面均保留这些输入；它们不会在关闭时返还背包。打开同一有线终端的玩家共享工作台，输入改变后立即使其他查看者的旧结果失效。拆除有线终端时仅掉落实际输入，并清空存储；无线输入随终端物品保存和移动。普通 3×3 合成格沿用 AE2 的终端存储规则。

元件工作台的标记区和升级卡区分别滚动；隐藏槽位拒绝迟到的操作，避免切页后误改另一行。升级卡、过滤配置和存储内容继续使用元件自身的数据组件。

## 工作台音效

成功取出锻造、铁砧或切石结果后，在操作者处播放对应的原版音效。一次操作只播放一次，Shift 或批量制作不会按产出数量叠加。空间不足、经验不足、切页和恢复输入时不播放；虚拟工作台不会因此损坏世界中的铁砧。

## 验证

`src/jdb` 中的原生测试覆盖 AE2 真实点击与 Shift 包、材料/目标空间边界、组件敏感配方、锻造和铁砧回调与费用、输入保存重载、多人结果失效、元件滚动、万能终端合并、磁铁过滤和每玩家每 tick 去重。测试探针不进入发布 JAR。

使用 `scripts/tianshu-workstation-test.init.gradle` 运行隔离存档中的测试。完整 WTLib 与仅嵌入 API 两种环境应分别验证。客户端与服务端需更新到同一构建。
