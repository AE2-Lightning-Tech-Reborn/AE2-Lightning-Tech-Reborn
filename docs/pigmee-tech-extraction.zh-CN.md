# 猪咪科技拆分

本分支基于 1.21.1 `alpha` 的 `b2f43ff9`，本体版本为 `2.1.4-alpha.2`，对应 [Pigmee Craft](https://github.com/AE2-Lightning-Tech-Reborn/Pigmee-Craft)。

## 内容归属

本体保留两位作者玩偶、过载 TNT 的爆炸触发和神秘元件的抽取机制。未安装附属时，研究笔记抽取权重为零。

猪咪变体、核心、机器、存储元件、建筑方块与台阶、染色配方、佩戴特效、首登礼物、研究笔记、仪式及其演出迁入 `pigmeecraft`。研究笔记、超维猪咪和猪咪转换进度由猪咪工艺提供。多维展开、雷暴发生器和可观测黑洞三个进度归 LT，触发条件只使用 LT 内容，挂在 LT 的闪电坍缩矩阵进度下；开发阶段不迁移这三个进度在旧猪咪版本中的记录。

Applied Create 玩偶雷击彩蛋的触发、网络包、界面与贴图也由 LT 提供。

本体提供通用扩展点：神秘元件可选奖励、闪电转化事件、电离仪闪电事件、神秘元件检查事件、水晶催化器策略和玩偶渲染扩展。无需附属也能独立启动。

## 升级旧存档

备份后，同时更新本体并安装匹配的猪咪科技。不要先只装拆分本体启动旧世界并保存；当迁出的注册项缺失时，Minecraft 可能删除对应内容，之后再装附属无法恢复已删除的数据。

附属负责旧 `ae2lt:` ID 到新 `pigmeecraft:` ID 的注册表别名、旧配方查询、成就读取合并、研究笔记原始材料 ID 和配置迁移。普通猪咪也迁入 `pigmeecraft:pigmee_fumo`；旧 `ae2lt:fumo` 方块实体只在对应猪咪方块上转换为 `pigmeecraft:fumo`，保留名称与旋转状态，不影响本体作者玩偶。迁移详情与精确清单见附属 README。

## 验证

运行 `./gradlew -I scripts/returned-progression-test.init.gradle runGameTestServer` 可在不安装猪咪工艺的环境验证三个 LT 进度，覆盖进度树、元件类型识别与双核心获取条件。

拆分初期（LT `2.1.4-alpha.2` / Pigmee `1.0.0-alpha.3`）验证记录：

- 猪咪科技 40 项单元测试通过；无 LT 的 41 项 GameTest、有 LT 的 120 项 GameTest 通过，包括实际合成任务、赠送、数据迁移、银行储罐和猪咪催化器拒绝红石卡的行为。
- 本体单独运行 10 项 GameTest 通过，覆盖猪咪内容不再注册、未安装附属时无研究笔记奖励，以及普通水晶催化器和特斯拉线圈红石控制回归。
- 有、无 LT 的真实客户端均完成银行储罐操作、合成站界面与模型检查；各自另行加载 JEI、EMI、Jade、Curios 后检查通过。
- 从旧 Pigmee `1.0.0-alpha.2` + LT `2.1.4-alpha.1` 创建隔离存档；五种猪咪在有、无 LT 环境迁移后，物品名称、已放置方块名称、朝向、旋转均保留，保存后的第二次启动也通过。

初次拆分曾完成 88 项附属 GameTest、独立母岩掉落重载测试、81 种物品和 74 种方块的旧 alpha 世界迁移及 32 种建筑的客户端验证；这些历史结果不等同于本轮重新执行全套旧世界测试。

验证没有覆盖任意整合包。最小 LT 环境仍会因缺少 ExtendedAE 条件序列化器记录 `ae2lt:assembler/overload_processor` 配方加载错误；JEI 与 EMI 同时加载也有重复合成分类等日志。本轮所验证的功能正常，未将这些既有兼容日志视为已修复。
