# 猪咪科技拆分

本分支基于 1.21.1 `alpha` 的 `6bc37c51`，本体版本为 `2.1.4-alpha.1`，对应 [Pigmee-Tech](https://github.com/AE2-Lightning-Tech-Reborn/Pigmee-Tech) `1.0.0-alpha.1`。

## 内容归属

本体保留普通 `ae2lt:pigmee_fumo`、两位作者玩偶、过载 TNT 的爆炸触发和神秘元件的抽取机制。未安装附属时，研究笔记抽取权重为零。

猪咪变体、核心、机器、存储元件、建筑方块与台阶、染色配方、佩戴特效、首登礼物、研究笔记、仪式及其演出迁入 `pigmeetech`。猪咪及研究链成就（包括多维展开、雷暴发生器和可观测黑洞）也由附属提供。

本体提供通用扩展点：神秘元件可选奖励、闪电转化事件、电离仪闪电事件、神秘元件检查事件、水晶催化器策略和玩偶渲染扩展。无需附属也能独立启动。

## 升级旧存档

备份后，同时更新本体并安装匹配的猪咪科技。不要先只装拆分本体启动旧世界并保存；当迁出的注册项缺失时，Minecraft 可能删除对应内容，之后再装附属无法恢复已删除的数据。

附属负责旧 `ae2lt:` ID 到新 `pigmeetech:` ID 的注册表别名、旧配方查询、成就读取合并、研究笔记原始材料 ID 和配置迁移。普通猪咪 ID 保持不变。迁移详情与精确清单见附属 README。

## 验证

- 本体单元测试及开发源码编译通过。
- 本体单独运行的 2 项 GameTest 通过：只注册普通猪咪，遍历 10,000 个抽取区间不会产生附属奖励。
- 附属 88 项 GameTest 通过，覆盖设备、合成站、六面相邻存储、砧板、建材、染色、佩戴和旧数据读取；独立母岩掉落重载测试通过。
- 使用拆分前 alpha 写出的真实隔离世界，迁移加载后检查 81 种物品、74 种已放置方块和方块实体数据，以及存储元件内的物品数量；保存后第二次启动检查也通过。
- 真实客户端探针检查 32 种建筑的世界模型与物品模型、六面连接和贴图，截图与检查通过。

测试使用的最小模组组合没有覆盖任意整合包；原 alpha 的 `ae2lt:assembler/overload_processor` 在缺少 ExtendedAE 条件序列化器时仍会记录配方加载错误，该既有兼容问题未包含在本次拆分中。
