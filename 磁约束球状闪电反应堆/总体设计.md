# 磁约束球状闪电反应堆总体设计

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

## 定位与玩法

磁约束球状闪电反应堆是一套兼顾能源、闪电和终局物质生产的高能反应系统。玩家配置外围磁场装置，并调节运行负荷，决定当前更偏向 FE 发电、闪电生产或原生等离子体生产。

三种倾向由模块配比和运行状态自然形成，不是互斥的硬编码模式。系统不提供同时取得最大 FE、最大闪电、最大等离子体和最高稳定性的唯一最优配置。

## 资源流

| 阶段 | 输入或条件 | 作用 |
| --- | --- | --- |
| 正常运行 | 高能相变燃料 | 专属运行燃料，持续驱动反应 |
| 每次启动 | 球雷胚核 | 正式进入点火时消耗；正常停机或断料后的重启也需要新的胚核 |
| 启动 | 闪电资源 | 满足启动消耗，具体档位与用量待定 |
| 启动 | 外部 FE | 建立磁场，并为停堆储能预充 |
| 停堆 | 内部 FE 储备 | 停止注入后继续为余能约束供能 |
| 首次建立球雷 | 闪电苦力怕 | 提供首次建立球雷所需的活体雷电现象与初始高能扰动 |
| 点火与运行 | 完整中央反应腔、六套完整磁极阵列及相应磁场条件 | 建立并维持球状闪电约束场 |

正常运行产生四类输出，归属三种生产方向：

| 生产方向 | 输出 | 边界 |
| --- | --- | --- |
| 发电 | FE | 大规模能源输出 |
| 闪电 | 高压闪电、极高压闪电 | 只使用现有两档，不新增第三档或更高等级 |
| 终局物质 | 原生等离子体 | 反应堆只直接生产一种统一的等离子体 |

```text
高能相变燃料
    ↓ 球状闪电驱动完整相变
FE + 高压闪电 + 极高压闪电 + 原生等离子体
```

首次点火的完整条件以及后续恢复运行的区别见[启停与事故处理](启停与事故处理.md)。

## 磁场供能与停堆储能

闪电与 FE 仅在启动阶段作为输入消耗：闪电满足启动需求，外部 FE 用于建立磁场，并将内部停堆储能预充到最低启动要求。首次点火与从休眠恢复运行均遵循这项规则；启动闪电的档位与用量、FE 功率、预充量与耗时尚未确定。

正常运行只持续消耗高能相变燃料，由燃料反应维持磁约束。运行中不要求外部 FE 或闪电供给，FE 产物不承担额外的磁场维持或停堆储能回充消耗。

停堆储能由启动阶段预充，是反应堆内部保留的 FE 储备，不作为可对外提取的产物。停止燃料注入后，该储备用于继续维持磁场约束，支持球状闪电从高能状态衰减至安全休眠。储能提供停堆缓冲，不能修复损坏的磁极阵列，也不保证已经严重失稳的反应堆一定能够安全停机。

启动消耗、储能容量、最低预充量、停堆供能时长及储能不足或耗尽时的处理规则，见[待定事项](待定事项.md)。

## 高能相变燃料

高能相变燃料是可稳定储存的亚稳态高能流体。普通设备无法有效释放其中的能量；只有球状闪电同时提供的强电场、强磁场和极端高能环境，才能促使其发生完整相变。

燃料的配方、制作产线、单位能量价值与消耗速度尚未确定。

## 原生等离子体

原生等离子体是反应堆唯一的终局物质产物，用作后续高阶材料、机器和加工体系的基础原料。

后续可以通过独立加工链将其分化为不同性质的等离子体，但不在反应堆内部直接生产多种等离子体。分化种类、加工机器、配方、终局材料与材料简化配方另行设计。

## 核心设计原则

| 原则 | 约束 |
| --- | --- |
| 产出必须取舍 | 三类模块及 C／U／F 相互影响，不能同时最大化所有产出与稳定性 |
| 结构固定、对称、易理解 | 玩法深度来自模块配比、燃料注入率与运行风险，不来自逐方向调参、距离差、方向偏置或复杂位置公式 |
| 风险来源可解释 | 事故由高注入、高磁通、约束不足、低均匀度或结构故障等状态导致，不以随机概率触发 |
| 保留事故抢救时间 | 稳定度具有惯性；降负荷、修复和紧急停堆应有实际作用 |
| 正常停机安全衰减 | 正常停机、普通断料和安全维护保留球雷建立状态；再次启动仍消耗新的胚核、闪电与 FE |
| 实体破坏范围受控 | 限制结构损毁与次生爆炸范围，灾难性事故后需要维修和重新点火 |
| 保留既有设备价值 | 提供大规模 FE、现有闪电与原生等离子体；后续终局加工通过新产线展开，不把反应堆做成万能加工机 |

本目录独立维护反应堆方案；具体实现方式与框架接入关系尚未确定。
