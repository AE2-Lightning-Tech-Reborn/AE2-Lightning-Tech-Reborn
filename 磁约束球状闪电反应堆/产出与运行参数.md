# 磁约束球状闪电反应堆产出与运行参数

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

本页确定参数含义、影响方向和取舍关系，暂不提供最终公式、模块系数或基础产率。

## 三种功能模块

六套阵列共提供 24 个等价模块槽。模块配比决定反应堆偏向何种产出；模块在各阵列及各槽位中的分布不增加方向效果。

| 模块 | 主要倾向 | 收益 | 代价 |
| --- | --- | --- | --- |
| 磁场增幅模块 | FE 发电 | 提高约束强度和大发电潜力 | 降低场均匀度、增加磁通积累，提高高负荷控制难度 |
| 相位稳定模块 | 闪电生产与安全运行 | 提高场均匀度、闪电提取效率和整体可控性 | 削弱部分有效约束、降低磁通，抑制部分等离子体产出潜力 |
| 磁通调制模块 | 原生等离子体 | 主动提高磁通与等离子体形成效率 | 显著降低场均匀度、提高失稳风险，对约束系统要求更高 |

磁通调制模块是三者中最激进、风险最高的一种。

## 磁场参数及相互影响

C、U、F 由模块配置和运行状态共同计算，不是三个可独立设置的滑条，也不以同时达到最高值为目标。

| 参数 | 含义 | 提高后的主要作用 | 过高时的取舍或负担 |
| --- | --- | --- | --- |
| 约束强度 C | 将球状闪电压制、锁定在中心的能力 | 提高 FE 发电能力，支撑更高燃料注入率和能量密度 | 可能压制自然放电、降低闪电输出效率、加剧磁通积累并降低场均匀度 |
| 场均匀度 U | 六向磁场的规整、稳定和同步程度 | 提高高压／极高压闪电输出效率与可控性，减缓失稳传播 | 球雷趋于平静，部分大发电潜力、有效约束、高磁通状态和等离子体高产能力受到抑制 |
| 磁通水平 F | 球雷与外围磁场中积累的高能磁通及扰动程度 | 提高原生等离子体产出，使相变反应更激进 | 降低均匀度，提高约束负担与失稳风险 |

三者必须相互干扰。提高 C 主要强化发电，但可能牺牲 U 和放电效率；提高 U 主要强化闪电与安全性，同时压低 F；提高 F 主要强化等离子体生产，同时提高约束负担与事故风险。

## 产出计算方向

| 产出 | 主要影响因素 | 限制与取舍 |
| --- | --- | --- |
| FE | C、燃料注入率 | U 过低造成能量损失，F 过高带来波动或效率惩罚 |
| 高压／极高压闪电 | U、燃料注入率 | C 过强压制放电，F 过高增加混乱放电；高 U、低 F 可提高极高压闪电占比 |
| 原生等离子体 | F、燃料注入率 | 需要基础约束；U 过高抑制高能扰动，高产天然伴随更高风险 |

这些关系描述设计方向，不代表已经确定线性增益、固定倍率或各类产出的最低值。

正常运行的维持成本统一计入燃料消耗。胚核、闪电与 FE 的启动消耗规则见[启停与事故处理](启停与事故处理.md)，磁场供能与停堆储能见[总体设计](总体设计.md#磁场供能与停堆储能)。

## 产物存满与恢复

FE、高压闪电、极高压闪电与原生等离子体独立判断存储空间。某一产物存满时，仅停止生成该产物，已有库存保留；其他产物继续按当前模块配置和燃料注入率正常生成。腾出空间后，该产物自动恢复生成。

产物存满不触发整机降负荷、停堆或额外的失稳惩罚。即使全部产物均已存满，反应堆仍按当前燃料注入率持续消耗燃料并维持反应；是否降负荷或停堆由玩家决定，原有运行风险仍按实际状态计算。

各产物的缓存容量与外部输出接入方式，见[待定事项](待定事项.md)。

## 典型运行倾向

以下是模块配置自然形成的典型表现，不新增独立的运行模式开关：

| 倾向 | 典型配置与磁场 | 预期产出 | 风险 |
| --- | --- | --- | --- |
| 发电 | 增幅模块较多、C 高，磁场相对激进 | FE 高、闪电一般、等离子体中等 | 控制难度较高 |
| 闪电 | 稳定模块较多、U 高、F 低 | 高压／极高压闪电效率高，FE 和等离子体相对较低 | 相对安全 |
| 等离子体 | 调制模块较多、F 高、U 较低 | 原生等离子体产率高，FE 与闪电不保证高产 | 风险最高，对磁场控制要求最高 |

## 燃料注入率

玩家可以调节当前燃料注入率。模块配比决定生产倾向，注入率决定运行负荷。

低、中、高、满功率和过载是当前档位思路；`25% / 50% / 75% / 100% / 125%` 仅为示例，不是最终档位，也不代表已经确定具体的 mB/t。

提高注入率会提高总体产量，同时提高约束需求与磁通压力，使稳定度更难维持。具体注入速度和可用负荷范围留待平衡。

## 稳定度 S

稳定度 S 是 0%～100% 的综合运行状态，由 C、U、F、当前燃料注入率及六向阵列完整性动态计算，不能直接设置。

稳定度必须具有惯性，不应瞬间跳变；从失稳到事故恶化应给玩家留下抢救时间。建议展示区间如下，端点按下表划分以避免重叠，最终阈值和变化速度仍待确定：

| 建议区间 | 状态 |
| --- | --- |
| 80% ≤ S ≤ 100% | 稳定 |
| 50% ≤ S < 80% | 波动 |
| 25% ≤ S < 50% | 严重失稳 |
| 10% ≤ S < 25% | 临界 |
| 0% ≤ S < 10% | 约束濒临崩溃 |

低稳定度不直接等同于爆炸；灾难性约束崩溃需要结合磁通、球雷能量和反应负荷判断，见[启停与事故处理](启停与事故处理.md)。

## 失稳来源与应对

失稳应有可解释的原因：燃料注入过高、约束不足、场均匀度过低、磁通过高，以及六向阵列损坏。正常运行不依赖外部 FE 或闪电供给，外部供给中断本身不构成运行故障；停堆期间储能不足或耗尽的具体处理规则尚待定义。

玩家可通过降低燃料注入、调整模块配比、修复磁极阵列或执行紧急停堆尝试恢复。模块更换时的结构与稳定度规则见[模块更换与维护](结构与磁场系统.md#模块更换与维护)。
