# 磁约束球状闪电反应堆产出与运行参数

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

本页确定参数含义、影响方向和取舍关系，暂不提供最终公式、模块系数或基础产率。

## 三种功能模块

六套阵列共提供 24 个等价模块槽。模块配比决定反应堆偏向何种产出；模块在各阵列及各槽位中的分布不增加方向效果。

| 模块 | 主要倾向 | 收益 | 代价 |
| --- | --- | --- | --- |
| 磁场增幅模块 | FE 发电 | 提高约束强度和大发电潜力 | 降低场均匀度、增加磁通积累，提高高负荷控制难度 |
| 相位稳定模块 | 闪电生产与安全运行 | 提高场均匀度、闪电提取效率和整体可控性 | 削弱部分有效约束、降低磁通，抑制部分等离子体产出潜力 |
| 磁通调制模块 | 原生等离子体 | 主动提高磁通与等离子体形成效率 | 显著降低场均匀度、提高失稳风险，对约束系统要求更高 |

磁通调制模块是三者中最激进、风险最高的一种。

## 磁场参数及相互影响

C 与 U 由模块配比决定，F 由模块配比和实际反应负荷共同决定；三者不是可独立设置的滑条，也不以同时达到最高值为目标。

| 参数 | 含义 | 提高后的主要作用 | 过高时的取舍或负担 |
| --- | --- | --- | --- |
| 约束强度 C | 将球状闪电压制、锁定在中心的能力 | 提高 FE 发电能力，支撑更高燃料注入率和能量密度 | 可能压制自然放电、降低闪电输出效率、加剧磁通积累并降低场均匀度 |
| 场均匀度 U | 六向磁场的规整、稳定和同步程度 | 提高高压／极高压闪电输出效率与可控性，减缓失稳传播 | 球雷趋于平静，部分大发电潜力、有效约束、高磁通状态和等离子体高产能力受到抑制 |
| 磁通水平 F | 球雷与外围磁场中积累的高能磁通及扰动程度 | 提高原生等离子体产出，使相变反应更激进 | 降低均匀度，提高约束负担与失稳风险 |

三者必须相互干扰。提高 C 主要强化发电，但可能牺牲 U 和放电效率；提高 U 主要强化闪电与安全性，同时压低 F；提高 F 主要强化等离子体生产，同时提高约束负担与事故风险。

F 不作为独立状态记录：配比决定其基线，调制模块抬高、稳定模块压低、增幅模块略抬，实际反应负荷再按比例抬高它；F 的惯性全部继承自球雷余能。

## 产出计算方向

产出跟随实际反应负荷变化，而不是仅按当刻燃料注入率开关。燃料注入决定新增能量，球雷余能决定已积累能量的持续释放及约束负担，见[球雷余能与实际反应负荷](#球雷余能与实际反应负荷)。

| 产出 | 主要影响因素 | 限制与取舍 |
| --- | --- | --- |
| FE | C、实际反应负荷 | U 过低造成能量损失，F 过高带来波动或效率惩罚 |
| 高压／极高压闪电 | U、实际反应负荷 | C 过强压制放电，F 过高增加混乱放电；高 U、低 F 可提高极高压闪电占比 |
| 原生等离子体 | F、实际反应负荷 | 需要基础约束；U 过高抑制高能扰动，高产天然伴随更高风险 |

这些关系描述设计方向，不代表已经确定线性增益、固定倍率或各类产出的最低值。

正常运行的维持成本统一计入燃料消耗。胚核、闪电与 FE 的启动消耗规则见[启停与事故处理](启停与事故处理.md)，磁场供能与停堆储能见[总体设计](总体设计.md#磁场供能与停堆储能)。

## 产物存满与恢复

FE、高压闪电、极高压闪电与原生等离子体独立判断存储空间。某一产物存满时，仅停止生成该产物，已有库存保留；其他产物继续按当前模块配置和实际反应负荷生成。腾出空间后，该产物按当前运行或停堆状态恢复允许的生成行为，不绕过 SCRAM 的产出停止规则。

产物存满不触发整机降负荷、停堆或额外的失稳惩罚。即使全部产物均已存满，反应堆仍按当前燃料注入率持续消耗燃料并维持反应；是否降负荷或停堆由玩家决定，原有运行风险仍按实际状态计算。

产物存满不阻断球雷余能的耗散，也不把未生成的产物转为额外余能或其他产出；普通停堆不能因输出堵塞而无法完成安全衰减。

各产物的缓存容量与外部输出接入方式，见[待定事项](待定事项.md)。

## 典型运行倾向

以下是模块配置自然形成的典型表现，不新增独立的运行模式开关：

| 倾向 | 典型配置与磁场 | 预期产出 | 风险 |
| --- | --- | --- | --- |
| 发电 | 增幅模块较多、C 高，磁场相对激进 | FE 高、闪电一般、等离子体中等 | 控制难度较高 |
| 闪电 | 稳定模块较多、U 高、F 低 | 高压／极高压闪电效率高，FE 和等离子体相对较低 | 相对安全 |
| 等离子体 | 调制模块较多、F 高、U 较低 | 原生等离子体产率高，FE 与闪电不保证高产 | 风险最高，对磁场控制要求最高 |

等离子体倾向的高风险体现为安全负荷范围更窄、配比要求更高，以及升负荷或结构故障时抢救窗口更短，不代表该路线必然失稳。玩家应能牺牲部分极限产量换取长期稳定运行，不必通过周期性停堆维持日常生产。

## 燃料注入率

玩家可以调节当前燃料注入率。模块配比决定生产倾向，注入率决定运行负荷。

低、中、高、满功率和过载是当前档位思路；`25% / 50% / 75% / 100% / 125%` 仅为示例，不是最终档位，也不代表已经确定具体的 mB/t。

提高注入率会提高总体产量，同时提高约束需求与磁通压力，使稳定度更难维持。给定配比，稳态稳定度随注入率单调下降，稳定度仍处于稳定区间的最高注入率即该配比的安全上限；三种倾向安全范围的宽窄由此得出，不单独手写。具体注入速度留待平衡。

## 球雷余能与实际反应负荷

球雷余能描述球雷内已经积累、仍需释放或约束的反应能量，是内部连续变化的运行状态，不是额外燃料、可直接提取的资源或玩家可独立调节的参数。余能与磁通 F 分开：F 表示磁通及扰动程度，低 F 不等于球雷已经处于低能安全状态。

注入把燃料能量带进余能，释放速率随余能升高而增大；固定注入率下余能收敛到一个平衡值，不无限积累，平衡余能与注入率单调对应。实际反应负荷就是当前释放速率，稳态下等于注入率，升降负荷的快慢即余能收敛的快慢。停止注入不将余能或实际反应负荷瞬间归零，只有衰减至安全休眠阈值以下才视为完成停堆；该阈值为常量，不随配比变化。

在合理配比与持续供料的安全负荷下，余能、磁通与稳定度应能维持在可持续区间，不随运行时间无限积累或持续恶化。升降负荷、停堆衰减和事故判断使用同一套余能状态，不以切换运行阶段重置余能。

释放量在运行与普通停机时按 C、U、F 分配给三类产出与损耗，停机后产出随释放逐渐降低；SCRAM 停止新产物生成，释放全部进损耗并加速；不成型时无产出，释放照常。存满产物的份额进损耗。余能释放对应已投入反应但尚未释放的燃料能量，不得重复计入已生成的产物；停堆 FE 储备与余能分开记录，不作为产物来源。两种停堆方式见[停机与恢复运行](启停与事故处理.md#停机与恢复运行)。

余能的计量单位、释放速率曲线、安全休眠阈值取值与产出分配系数留待平衡，不在本版增加新的操作滑条。

## 稳定度 S

稳定度 S 是 0%～100% 的综合运行状态，表示有效约束相对当前运行负荷的富余程度，不能直接设置。有效约束由 C、结构成型状态及 U 对约束的抑制共同得到，运行负荷与约束负担由燃料注入率、球雷余能和磁通 F 共同形成；U 对可控性的作用体现在失稳推进速度，不进入稳定度的取值。稳定度是这些量的读数，不反过来改变它们，也不作为独立项重复进入事故判定。

稳定度必须具有惯性，不应瞬间跳变：惯性来自球雷余能的逐步积累与释放，以及有效约束对成型状态变化的滞后跟随；从失稳到事故恶化应给玩家留下抢救时间。建议展示区间如下，端点按下表划分以避免重叠，最终阈值和变化速度仍待确定：

| 建议区间 | 状态 |
| --- | --- |
| 80% ≤ S ≤ 100% | 稳定 |
| 50% ≤ S < 80% | 波动 |
| 25% ≤ S < 50% | 严重失稳 |
| 10% ≤ S < 25% | 临界 |
| 0% ≤ S < 10% | 约束濒临崩溃 |

低稳定度不直接等同于爆炸；灾难性约束崩溃需要在球雷仍处于高能状态时，由稳定度持续偏低达到相应持续时间判断，有效约束已经通过稳定度体现。运行失稳与结构失约束的边界见[约束崩溃的触发原则](启停与事故处理.md#约束崩溃的触发原则)。

## 失稳来源与应对

失稳应有可解释的原因：燃料注入过高、约束不足、场均匀度过低、磁通过高，以及结构不成型。正常运行不依赖外部 FE 或闪电供给，外部供给中断本身不构成运行故障；停堆期间储能不足或耗尽的具体处理规则尚待定义。

玩家可通过降低燃料注入、调整模块配比、修复磁极阵列或执行紧急停堆尝试恢复。模块更换时的结构与稳定度规则见[模块更换与维护](结构与磁场系统.md#模块更换与维护)。
