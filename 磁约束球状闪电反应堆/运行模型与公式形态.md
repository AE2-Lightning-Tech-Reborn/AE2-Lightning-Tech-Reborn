# 磁约束球状闪电反应堆运行模型与公式形态

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

本页把[产出与运行参数](产出与运行参数.md)中的定性关系整理成可实现的运行模型：确定状态量的含义与归属、参数之间的耦合结构，以及各关系的函数形态（单调方向、边界与饱和、惯性来源）。系数、阈值与曲线取值仍以符号表示，不作为最终平衡数值。

本页只描述单机内部的运行数学，不新增操作项、冷却剂或运行期外部供给；启动、停机与事故流程仍以[启停与事故处理](启停与事故处理.md)为准，结构与端口仍以[结构与磁场系统](结构与磁场系统.md)为准。

## 状态量与符号

| 符号 | 名称 | 归属 | 说明 |
| --- | --- | --- | --- |
| `I` | 燃料注入率 | 玩家设置 | 每 tick 注入的燃料能量，档位为示例取值 |
| `E` | 球雷余能 | 运行时状态 | 球雷内已积累、待释放的能量，连续变化 |
| `R` | 释放速率 | 派生 | 等于当前实际反应负荷 |
| `C`／`U`／`F` | 约束强度／场均匀度／磁通水平 | `C`、`U` 由配比决定，`F` 由配比与实际反应负荷决定 | 归一化到 0～1 |
| `K` | 有效约束 | 派生 | 当前能提供的约束能力 |
| `L` | 约束负担 | 派生 | 当前运行负荷对约束的需求 |
| `S` | 稳定度 | 派生，控制器记录当前值 | 0～100，有效约束相对负荷的富余程度 |
| `D` | 危险度 | 运行时状态 | 事故累积量 |
| `P` | 停堆储能 | 状态，控制器记录 | 启动阶段预充的 FE 储备 |
| `E_sleep` | 安全休眠阈值 | 常量 | 与配比无关 |

持久化的是球雷建立状态、`E`、`P` 与带滞后的结构成型状态；`S` 由这些量与配比重建并保留当前值用于显示，`F`、`K`、`L` 不单独持久化。`E` 与 `P` 始终分开记录。

## 配比到 C／U／F

设 48 个模块槽中增幅、稳定、调制模块的数量为 `a`、`s`、`m`（`a + s + m = 48`），模块只按总数量统计，与所在门架和槽位无关。

各参数只确定单调方向，不隐含线性叠加或固定倍率：

| 参数 | 形式与单调性 |
| --- | --- |
| `C` | 随 `a` 单调递增 |
| `U` | 随 `s` 单调递增，随 `m`、随 `a` 单调递减 |
| `F` 基线 | 随 `m` 单调递增，随 `s` 单调递减，随 `a` 略微递增 |

`F` 不是独立记录的状态：先由配比得到基线，再按实际反应负荷按比例抬高，`F = F_base · (1 + φ·R̂)`，`R̂` 为归一化实际反应负荷，`φ` 待定。`F` 的惯性完全继承自 `E`。

## 余能与实际反应负荷

余能按一阶平衡演化：

```text
dE/dt = I − R(E)
```

`R` 在 `[0, ∞)` 上满足 `R(0) = 0`、严格单调递增且有上界（饱和），因此对任意注入率存在唯一平衡 `E* = R⁻¹(I)`，余能不无限积累。

- 稳态：`R(E*) = I`，实际反应负荷等于注入率。
- 惯性：收敛时间常数 `τ(E*) = 1 / R′(E*)`，由 `R` 的斜率决定；`R` 越接近饱和越平坦，升降负荷越慢。
- 改变注入率后 `E` 以 `τ` 收敛到新的 `E*`，不跳变。
- 停注入：`I = 0`，`dE/dt = −R(E) < 0`，`E` 单调下降；以 `E` 降至 `E_sleep` 以下判定安全休眠，不要求 `E` 归零。
- 紧急停堆：使用加速释放 `R_scram(E) ≥ R(E)`，且释放全部计入损耗，使 `E` 更快降到 `E_sleep`；`R_scram` 与 `R` 的比值即加速系数，待定。
- 在合理配比与安全负荷下，`E`、`F` 与 `S` 维持在可持续区间，不随时间无限积累或持续恶化。

## 释放分配

`R` 按当前 `C`、`U`、`F` 分配给三类产出与损耗：

| 去向 | 随参数的变化方向 |
| --- | --- |
| FE | 随 `C` 递增 |
| 高压闪电 | 随 `U` 递增 |
| 极高压闪电 | 随 `U` 递增、随 `F` 递减，高 `U` 低 `F` 提高其占比 |
| 原生等离子体 | 随 `F` 递增，需要基础约束 |
| 损耗 | 剩余份额，`U` 过低或 `F` 过高时增大 |

约束：

- 各份额非负且和为 1；同一份燃料能量只结算一次，已生成产物不重复计入余能释放。
- 存满的产物份额计入损耗；紧急停堆期间全部计入损耗；结构不成型时无产物，全部计入损耗。
- 损耗不转化为其他产出，也不回流余能；普通停堆不因输出堵塞而无法完成安全衰减。

## 稳定度 S

稳定度由有效约束与约束负担决定：

```text
S = 100 · sat(1 − L / K)      （K > 0；不成型时 K = 0，直接令 S = 0）
```

- `K = K(C, U, 成型)`：随 `C` 单调递增，随 `U` 单调递减（`U` 提高会抑制部分有效约束），结构成型时取满值，不成型时趋于 0。
- `L = L(R, E, F)`：随实际反应负荷、余能与磁通单调递增；注入率通过 `E` 间接影响 `L`。
- `S` 是读数：`K` 与 `L` 的变化驱动 `S`，`S` 不反过来改变 `K`、`L` 或 `R`。

惯性有两个来源，均不产生瞬间跳变：

- `L` 通过 `E` 继承余能的一阶惯性；
- `K` 对结构成型状态做一阶滞后跟随，拆装结构后按时间常数趋近目标值，稳定度不会因重新成型瞬间复原。

`U` 的两个作用通道在此明确区分（细化[产出与运行参数](产出与运行参数.md)中“`U` 对可控性的作用不进入稳定度取值”的表述）：

| 通道 | 作用位置 | 说明 |
| --- | --- | --- |
| `u_k` | 进入 `K`，从而进入 `S` | `U` 提高会抑制部分有效约束，是稳定模块的代价 |
| `w` | 进入失稳推进速度，不进入 `S` | `U` 提高减缓失稳传播，是稳定模块的主要安全性来源 |

两者由同一个 `U` 决定，但作用在不同环节。稳定模块的安全性主要来自 `w` 与对 `F` 的压低，其对 `K` 的抑制是代价；因此“稳定模块较多”不等于稳定度读数更高。

## 失稳推进与事故判定

危险度在稳定度低于失稳阈值时按速率累积：

```text
dD/dt = w(U) · max(0, S_thr − S)
```

- `w` 随 `U` 单调递减：场均匀度越低，失稳推进越快。
- `S ≥ S_thr` 时不累积，并可按衰减规则回落，`w` 与衰减速率待定。
- 崩溃条件：`E ≥ E_high`（球雷仍处于高能状态，`E_high > E_sleep`）且 `D ≥ D_crit`。

两条事故路径统一在同一判据下，不要求同时成立：

| 路径 | 进入方式 |
| --- | --- |
| 运行失稳 | 结构成型正常，`L` 因高注入、高 `F` 持续超过 `K`，`S` 长期偏低，`D` 累积到阈值 |
| 结构失约束 | 结构不成型使 `K` 趋于 0、`S` 趋于 0，`D` 快速累积 |

结构成型状态只通过 `K` 进入 `S`，不重复进入 `w`，避免同一因素被重复计入判定。因此：

- 低 `F` 不能豁免结构失约束：`F` 只进入 `L`，不成型时即使 `F` 很低，`S` 仍趋于 0。
- 高磁通不是结构失约束的必要条件：崩溃条件不含 `F` 的下限。
- 燃料是否仍在注入不是必须条件：停堆后的高余能同样需要约束。
- 已进入安全休眠（`E < E_sleep`）时拆装结构属于安全维护，不满足 `E ≥ E_high`，不触发事故。

抢救窗口来自三处：`D` 按有限速率累积、`K` 对成型状态滞后跟随、`E` 按 `τ` 衰减。降注入、修复结构、紧急停堆分别作用在 `E`、成型状态与 `R` 上。

## 注入档位与安全上限

给定配比（`C`、`U`、`F` 基线固定）后，稳态量随注入率的变化方向：

```text
I ↑  ⇒  E* ↑  ⇒  L* ↑  ⇒  S*(I) 单调递减
```

- 安全上限 `I_max = max{ I : S*(I) ≥ S_safe }`，`S_safe` 为稳定区下界（示例 80）。
- 三种倾向的安全范围宽窄由配比推出，不单独手写：调制模块抬高 `F` 基线、压低 `U`，使 `L*` 随 `I` 增长更快且 `w` 更大，因此等离子体倾向的 `I_max` 更小、抢救窗口更短；稳定模块方向相反。
- 低／中／高／满功率／过载是 `I` 的离散示例档位，最终倍率与流量留待平衡。

## 停堆储能与停堆过程

- `P` 在启动阶段预充到不低于 `P_min`；正常运行不扣减，`F`、`K`、`L`、`S` 的运行计算不使用 `P`。
- 停注入后 `P` 为磁场约束供能，维持 `K` 与 `w` 所需的基础约束，直到 `E < E_sleep`；紧急停堆期间额外支持 `R_scram` 的加速释放。
- `P_min` 的下界约束：结构完整且无既有失稳时，对允许范围内的任意正常负荷 `I ≤ I_max`，从稳态 `E*` 完成停机所需供能不超过 `P_min`。这保证单纯断料不会因储备随时间耗尽而引发事故。
- 超出正常负荷的过载、既有失稳与结构受损不在该保证内；`P` 不修复损坏的磁极门架。
- `P` 耗尽时的状态转换与处理规则仍待定。
