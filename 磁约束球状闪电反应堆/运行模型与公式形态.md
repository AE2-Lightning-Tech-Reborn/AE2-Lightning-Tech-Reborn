# 磁约束球状闪电反应堆运行模型与公式形态

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

本页把[产出与运行参数](产出与运行参数.md)中的定性关系整理成可实现的运行模型：确定状态量的含义与归属、参数之间的耦合结构，以及各关系的函数形态（单调方向、边界与饱和、惯性来源）。系数、阈值与曲线取值仍以符号表示，不作为最终平衡数值。

本页只描述单机内部的运行数学，不新增操作项或冷却剂；磁场模块在维持磁场时按固定功率耗能并需要补能，不另设停堆专用供能。启动、停机与事故流程仍以[启停与事故处理](启停与事故处理.md)为准，结构与端口仍以[结构与磁场系统](结构与磁场系统.md)为准。

## 状态量与符号

| 符号 | 名称 | 归属 | 说明 |
| --- | --- | --- | --- |
| `I` | 实际燃料注入率 | 按玩家档位、可用燃料与当前可运行条件执行 | 每 tick 实际成功扣入的燃料折算的能量；停止注入或磁场不可用时为 0，档数与取值待定 |
| `E` | 球雷余能 | 运行时状态 | 球雷内已积累、待释放的能量，连续变化 |
| `R` | 释放速率 | 派生 | 每 tick 从球雷余能中释放的能量，等于当前实际反应负荷 |
| `C`／`U`／`F` | 约束强度／场均匀度／磁通水平 | `C`、`U` 由配比决定，`F` 由配比与实际反应负荷决定 | 归一化到 0～1 |
| `K` | 有效约束 | 运行时状态 | 按惯性跟随目标值的当前约束能力 |
| `L` | 约束负担 | 派生 | 当前运行负荷对约束的需求 |
| `S` | 稳定度 | 派生，控制器记录当前值 | 0～100，有效约束相对负荷的富余程度 |
| `D` | 危险度 | 运行时状态 | 事故累积量 |
| `E_sleep` | 安全休眠阈值 | 常量 | 与配比无关 |

球雷建立状态、`E`、`D`、`K`（有效约束的滞后值）、启停阶段（含 SCRAM）、注入档位、启动结算进度及反应堆输入和产物库存由控制器保存；`S` 由当前 `K`、`L` 重建并用于显示，`F`、`L` 由配比与余能重算，不单独持久化。`K` 就是已有的约束滞后状态，不另外保存一份带滞后的磁场可用标记。六向磁场装置各自保存本向 FE 缓存，控制器只读取其储量与供能状态，普通端口也不复制库存；这些充能与 `E` 分开，不作为反应能量或产物。资源扣除与对应启动进度需保持一致，恢复时不得重复结算，流程见[区块卸载与读档恢复](启停与事故处理.md#区块卸载与读档恢复)。

下述运行演化以控制器仍存在为前提。拆除控制器按[唯一控制器](结构与磁场系统.md#唯一控制器)与[拆除与库存处理](结构与磁场系统.md#拆除与库存处理)清除状态及自身缓存，不继续模拟；正常区块卸载与世界重载不是拆除。

模型时间只随整机具备完整加载条件的实际运行 tick 推进。卸载或等待相关区块期间跳过整次更新，保留 `E`、`D` 与约束滞后状态；不能仅把 `I` 设为 0 后继续释放余能，也不能将未加载当成磁场失效而使 `K` 衰减。加载齐后根据实际结构和供能更新目标，再从保存值继续计算，不补算离线时长。

## 配比到 C／U／F

以当前暂定的 48 个模块槽为例，设增幅、稳定、调制模块的数量为 `a`、`s`、`m`（`a + s + m = 48`），模块只按总数量统计，与所在门架和槽位无关。槽位总数随最终结构确定，不是玩家可调参数。

各参数只确定单调方向，不隐含线性叠加或固定倍率：

| 参数 | 形式与单调性 |
| --- | --- |
| `C` | 随 `a` 单调递增 |
| `U` | 随 `s` 单调递增，随 `m`、随 `a` 单调递减 |
| `F` 基线 | 随 `m` 单调递增，随 `s` 单调递减，随 `a` 略微递增 |

`F` 不是独立记录的状态：先由配比得到基线，再按归一化反应负荷抬高，并将最终结果限制在 0～1：

```text
R̂ = R(E) / R_max
F = sat(F_base · (1 + φ · R̂))
sat(x) = min(1, max(0, x))
```

`F_base` 取值为 0～1，`φ ≥ 0`，具体系数待平衡。归一化负荷始终使用普通释放曲线 `R(E)`；SCRAM 的额外加速耗散不作为更高的反应负荷抬高 `F`。`F` 的惯性完全继承自 `E`，不新增缓存状态或玩家调节项。

`F = 1` 只表示磁通指标饱和，不直接触发事故，也不封顶 `E` 或约束负担。继续提高注入仍可通过更高的 `R` 与 `E` 增加约束负担；事故沿用稳定度与危险度判定。

## 余能与实际反应负荷

`I` 由实际扣入的燃料折算，而不是直接使用玩家设置的档位值。允许注入时，燃料充足则按档位需求扣除，不足则扣入剩余量；最后一笔已扣燃料仍须计入余能，用尽后才停止后续注入。档位设置不因这次不足而改变，扣料规则见[燃料注入率](产出与运行参数.md#燃料注入率)。

余能按一阶平衡演化：

```text
dE/dt = I − R(E)
```

普通释放曲线 `R(E)` 在 `[0, ∞)` 上连续、严格单调递增，满足 `R(0) = 0`，并趋近有限的饱和上限 `R_max > 0`。`R_max` 是最大释放速率，与 `I`、`R` 同为每 tick 的内部能量量值，不是 `E` 的容量上限，也不直接等于对外 FE/t。

所有可选档位折算后的注入率均须满足 `0 ≤ I < R_max`。在此范围内持续固定注入时，存在唯一有限平衡 `E* = R⁻¹(I)`，余能不无限积累；不允许注入率达到或超过 `R_max`。这只保证能量收支存在平衡，不保证配比具备足够约束能力。

- 稳态：`R(E*) = I`，实际反应负荷等于注入率。
- 惯性：在平衡点附近且 `R′(E*) > 0` 时，局部收敛时间常数为 `τ(E*) = 1 / R′(E*)`；斜率越小，局部收敛越慢。
- 改变注入率后 `E` 按上述能量平衡式连续趋向新的 `E*`，不跳变；`τ` 不是整个升降负荷过程的固定耗时。
- 停注入：`I = 0`，余能仍为正时 `dE/dt = −R(E) < 0`，`E` 单调下降；以 `E` 降至 `E_sleep` 以下判定安全休眠，不要求 `E` 归零。
- 紧急停堆：磁场可用时，在停堆衰减范围内使用加速释放 `R_scram(E) > R(E)`，且释放全部计入损耗，使 `E` 更快降至 `E_sleep` 以下；磁场不可用时仍按 `R(E)` 释放，不解除 SCRAM。`R_scram` 与 `R` 的比值即加速系数，待定。
- 在合理配比、安全负荷且磁场供能正常时，`E`、`F` 与 `S` 维持在可持续区间，不随时间无限积累或持续恶化。

## 释放分配

`R` 按当前 `C`、`U`、`F` 分配给三类产出与损耗：

| 去向 | 随参数的变化方向 |
| --- | --- |
| FE | 随 `C` 递增 |
| 高压闪电 | 随 `U` 递增 |
| 极高压闪电 | 随 `U` 递增、随 `F` 递减，高 `U` 低 `F` 提高其占比 |
| 原生等离子体 | 随 `F` 递增，需要基础约束 |
| 损耗 | 剩余份额，`U` 过低或 `F` 过高时增大 |

约束：

- 各份额非负且和为 1；同一份燃料能量只结算一次，已生成产物不重复计入余能释放。
- 份额与资源换算须满足[正常发电收益](产出与运行参数.md#正常发电收益)原则；该原则约束后续平衡，不改变释放总量或另设产物来源。
- 存满的产物份额计入损耗；紧急停堆期间全部计入损耗；结构不成型或任意一向模块无法维持磁场时无新产物，全部计入损耗。
- 损耗不转化为其他产出，也不回流余能；普通停堆不因输出堵塞而无法完成安全衰减。

## 稳定度 S

稳定度由有效约束与约束负担决定：

```text
S = 100 · sat(1 − L / K)      （K > 0；K = 0 时令 S = 0）
```

- `K` 的目标值由 `C`、`U` 与磁场可用状态决定：磁场可用时随 `C` 单调递增、随 `U` 单调递减，否则为 0。磁场可用要求当前阶段已启用磁场、结构成型且各向模块均能维持磁场；仅缓存有电不代表休眠时仍在建场。当前 `K` 从已保存的滞后值继续趋近目标，不因断能、重新供能或读档瞬间跳变。
- `L = L(R, E, F)`：随实际反应负荷、余能与磁通单调递增；注入率通过 `E` 间接影响 `L`。
- `S` 是读数：`K` 与 `L` 的变化驱动 `S`，`S` 不反过来改变 `K`、`L` 或 `R`。

惯性有两个来源，均不产生瞬间跳变：

- `L` 通过 `E` 继承余能的一阶惯性；
- `K` 对磁场可用状态做一阶滞后跟随，结构或供能变化后按时间常数趋近目标值，稳定度不会因重新成型或恢复供能瞬间复原。

`U` 的两个作用通道分别结算，不把失稳速度直接当作稳定度加成：

| 通道 | 作用位置 | 说明 |
| --- | --- | --- |
| 约束代价 | 进入 `K` 的目标值，从而影响 `S` | `U` 提高会抑制部分有效约束，是稳定模块的代价 |
| 失稳速度 | 通过 `w(U)` 影响危险度累积，不进入 `S` | `U` 提高减缓失稳传播，是稳定模块的主要安全性来源 |

两者由同一个 `U` 决定，但作用在不同环节。稳定模块的安全性主要来自 `w` 与对 `F` 的压低，其对 `K` 的抑制是代价；因此“稳定模块较多”不等于稳定度读数更高。

## 失稳推进与事故判定

危险度 `D` 使用同一份累积量，按当前阶段与稳定度选择累积、固定回落或保持，不因恢复供能、进入休眠或重新点火而清零：

| 条件 | 危险度更新 |
| --- | --- |
| 整机未加载或相关区块未加载齐 | 优先跳过更新，既不累积也不回落，不补算离线时间 |
| 运行、普通停机衰减或 SCRAM，且 `S < S_thr` | 按失稳程度与 `w(U)` 累积 |
| 运行、普通停机衰减或 SCRAM，且 `S ≥ S_thr` | 按固定速率 `r_D` 回落，最低为 0 |
| 安全休眠 | 同样按 `r_D` 回落，不以撤场后的稳定度读数判定继续失稳 |
| 尚未启动、建场或等待点火 | 保持已有 `D`；从休眠重启不重置残留值，进入运行后再按稳定度更新 |

参与结算的模型时间步长为 `Δt`，两种更新分别为：

```text
累积：D_next = D + w(U) · (S_thr − S) · Δt
回落：D_next = max(0, D − r_D · Δt)
```

- `w` 随 `U` 单调递减：场均匀度越低，失稳推进越快。
- `r_D > 0` 为固定回落速率，不随模块配比、C／U／F 或普通停机／SCRAM 改变；`w` 与 `r_D` 的具体数值仍待平衡。回落沿用 `S_thr`，不新增恢复阈值，也不要求稳定度回满。
- 回落只降低 `D`，不清空 `E`、不自动恢复注入，也不提前解除 SCRAM。维护与启动沿用既有条件，不额外要求 `D = 0`；未消退的危险度仍参与重启后的事故判定。
- 崩溃条件：`E ≥ E_high`（球雷仍处于高能状态，`E_high > E_sleep`）且 `D ≥ D_crit`。

上述回落只用于事故尚未正式触发时的运行恢复，不能撤销已经触发并开始结算的事故。拆除控制器直接清除核心运行状态的既定规则不变。

两条事故路径统一在同一判据下，不要求同时成立：

| 路径 | 进入方式 |
| --- | --- |
| 运行失稳 | 结构成型正常，但配比与注入负荷不匹配，`L` 相对 `K` 过高，使 `S` 持续低于 `S_thr`，`D` 累积到阈值 |
| 结构失约束（含模块断能） | 结构不成型或任意一向模块无法维持磁场，使 `K` 趋于 0、`S` 趋于 0，`D` 累积；停止注入不清空余能或危险度 |

结构与供能共同决定磁场可用状态，该状态只通过 `K` 进入 `S`，不重复进入 `w`，也不按断能方向数量叠加事故惩罚。因此：

- 低 `F` 不能豁免失约束：`F` 只进入 `L`，结构不成型或模块断能时即使 `F` 很低，`S` 仍趋于 0。
- 高磁通不是结构失约束的必要条件：崩溃条件不含 `F` 的下限。
- 燃料是否仍在注入不是必须条件：停堆后的高余能同样需要约束。
- 已进入安全休眠（`E < E_sleep`）时拆装结构属于安全维护，不满足 `E ≥ E_high`，不触发事故。

抢救窗口来自三处：`D` 按有限速率累积、`K` 对磁场可用状态滞后跟随、`E` 按 `τ` 衰减。降注入作用于 `E`，修复结构或恢复模块供能作用于磁场可用状态，紧急停堆在磁场可用时作用于 `R`。

## 注入档位与安全上限

燃料充足、结构完整且各向模块持续维持磁场时，给定配比（`C`、`U`、`F` 基线固定）后，在 `0 ≤ I < R_max` 范围内，稳态量随注入率的变化方向：

```text
I ↑  ⇒  E* ↑  ⇒  L* ↑  ⇒  S*(I) 单调不增
```

- 安全上限 `I_max` 取实际可选档位中满足 `S*(I) ≥ S_safe` 的最高注入率，`S_safe` 为稳定区下界（示例 80）；若无满足条件的档位，则该配比没有安全档位。它描述当前配比可安全承受的注入水平，与普通释放曲线的上限 `R_max` 不同，不用于锁定可选档位。
- 三种倾向的安全范围与抢救窗口由完整配比和系数共同确定，不单独手写。调制模块抬高 `F`、压低 `U`，会同时改变约束负担、有效约束和失稳速度；稳定模块压低 `F`、提高 `U`，也伴随有效约束受抑制的代价。不能只凭单项变化推出 `I_max` 必然增大或减小；具体结果需验证是否符合[典型运行倾向](产出与运行参数.md#典型运行倾向)的设计目标。
- 注入采用离散档位，不设独立过载档或过载模式，具体档数、倍率与流量留待平衡。选用高于当前配比安全上限的档位时，仍按现有 `S` 与 `D` 规则判断风险，不新增加成或惩罚。

## 磁场供能与停堆过程

启动成本、各向独立缓存、固定维持功率与休眠停耗统一见[启动消耗与磁场模块供能](总体设计.md#启动消耗与磁场模块供能)，不把启动 FE 或模块储能计入 `E`。

运行或停堆衰减期间，外部断电但储能仍能维持磁场时，磁场可用状态不变；任意一向已无法维持磁场时，立即令实际注入 `I = 0`，沿用上述失约束判定。停注入后 `E`、`K` 与 `D` 继续演化，恢复供能不重置它们，也不自动恢复注入或解除 SCRAM；操作流程见[停机与恢复运行](启停与事故处理.md#停机与恢复运行)。

本页未确定的系数、阈值、曲线取值、计量单位与档位倍率见[待定事项](待定事项.md)，暂不填写数值或推荐配比。
