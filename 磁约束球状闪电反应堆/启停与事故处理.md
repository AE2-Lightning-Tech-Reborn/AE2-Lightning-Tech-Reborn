# 磁约束球状闪电反应堆启停与事故处理

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

## 首次点火

首次建立球状闪电需要同时具备以下条件；其中结构数量与布局沿用[当前候选方案](结构与磁场系统.md)，随最终模板统一修订：

1. 完整的中央反应腔。
2. 六套完整且核心在线的磁极门架，各向磁场模块均已充能并能维持磁场。
3. 放入控制器、供本次启动消耗的新球雷胚核。
4. 高能相变燃料。
5. 一只位于反应空间内的闪电苦力怕。
6. 满足最低磁场启动条件。
7. 具备启动所需闪电与可用启动 FE，输入资源通过普通端口进入控制器缓存。

闪电苦力怕提供首次建立球雷所需的活体雷电现象与初始高能扰动，只要求位于中央反应空间内，实体不算空腔检查的阻挡；多只只消耗一只。点火演出后续定义。

启动分三步执行，首次点火与从安全休眠重启共用同一流程，后者不需要闪电苦力怕：

| 步骤 | 内容 | 消耗 |
| --- | --- | --- |
| 条件检查 | 瞬时完成上述各项检查 | 不通过不扣启动资源；已工作的磁场模块仍按自身规则耗能 |
| 建场 | 扣除胚核，从控制器的启动 FE 输入缓存按进度扣除本次启动所需 FE，普通 FE 输入端口可继续补入；六向装置按固定维持功率各自消耗本向缓存 | 胚核已扣不返还；启动 FE 以实际扣除为消耗，和六向装置充能分别结算 |
| 点火 | 本次启动 FE 消耗完成后，复查结构、磁场、燃料、启动闪电及首次点火所需苦力怕；条件满足才扣除闪电，首次点火同时消耗苦力怕，球雷建立并进入运行 | 闪电一次性扣除；不重复要求或扣除已在建场阶段消耗的胚核与启动 FE |

建场期间取消或结构不成型，按取消处理：胚核与已消耗的启动 FE 不返还，也不抵扣下一次启动消耗，反应堆回到启动前的状态。控制器输入缓存中尚未消耗的 FE、各向磁场装置中尚存的充能都不随取消被清空，但不计作已经完成的下一次启动进度。闪电不足、闪电苦力怕不在位或模块暂时无法维持磁场时，不得点火，停留在建场阶段等待，玩家可随时取消。

## 胚核消耗与球雷建立状态

球雷胚核是每次启动都要消耗的材料。首次点火、从安全休眠重启和事故后重新点火，均需装入新的胚核；停堆衰减期间恢复注入不是启动，不消耗胚核。

启动条件检查不通过时不消耗胚核。检查通过并进入建场时扣除本次胚核；此后启动失败、取消启动或停机均不返还。

首次成功点火后获得“球雷已建立”状态。正常停机、燃料耗尽、安全完成的 SCRAM 和保留控制器的安全维护不清除该状态；这里的“熄火”表示反应衰减并进入休眠。建立状态与胚核物品分开记录，保留状态不能免除下次启动的胚核消耗。

球雷建立状态保留时，无需重新准备闪电苦力怕。灾难性约束崩溃或拆除控制器都会清除该状态，恢复时需重新完成首次点火流程。拆除控制器会直接清除球雷及核心运行状态，重新放置不是接续原来的反应；需要新的胚核、启动闪电与 FE，以及首次点火所需的闪电苦力怕。拆除时的未消耗资源与产物缓存按[拆除与库存处理](结构与磁场系统.md#拆除与库存处理)结算，不与取消启动或正常卸载混用。

## 停机与恢复运行

首次点火、衰减期间恢复注入，以及从安全休眠或事故后的重启，均由玩家在控制器上手动发起。补充胚核、燃料、启动能源、恢复模块供能或修复结构不会自动开堆。读档后接续卸载前正在执行的阶段不属于新启动，按[区块卸载与读档恢复](#区块卸载与读档恢复)处理。

| 情况 | 处理过程 | 结果与边界 |
| --- | --- | --- |
| 正常停机 | 立即停止燃料注入，受控释放余能，产出随实际反应负荷逐渐降低，直至安全休眠 | 保留余能利用，停堆过程相对较慢；衰减期间可恢复注入或转入 SCRAM，进入安全休眠后保留球雷建立状态，重启需新的胚核 |
| 单纯燃料耗尽 | 不足一个 tick 用量的最后一份燃料按实际量注入并计入余能，用尽后停止后续注入，按普通停机路径释放余能，产出逐渐降低并进入休眠 | 保留原注入档位，不自动换档；磁场持续可用、无既有失稳时，单纯断料不触发爆炸；补料后仍需手动恢复，衰减期间恢复不消耗胚核，进入安全休眠后重启需新的胚核 |
| 衰减期间恢复注入 | 普通停机衰减中，结构完整、燃料充足且各向模块均能维持磁场时，由玩家手动恢复注入，沿用当前余能、稳定度与危险度继续运行 | 不消耗胚核，不另查停堆专用储备；SCRAM 衰减期间不允许 |
| 从安全休眠重启 | 确认结构完整、燃料充足，补入新的胚核，并满足启动闪电、FE 与磁场条件后，由玩家手动启动，按首次点火的三步流程执行 | 消耗本次胚核，继承尚未回落的危险度；不额外要求危险度归零 |
| 紧急停堆（SCRAM） | 立即停止燃料注入和新产物生成，在磁场可用时通过磁场系统主动加速余能耗散 | 放弃剩余产出以争取更快休眠；一经发起不可撤销，直至安全休眠；不能保证在严重事故条件下成功 |

在同等初始状态、结构与约束仍可控且磁场供能正常的条件下，SCRAM 应比普通停机更快降低余能并进入安全休眠。它使用现有磁场系统，不改变模块充耗能规则，不额外引入冷却剂、新耗材或独立的停堆电源。停止新产物生成不清空已有库存，也不阻断已有库存的正常外部提取。

正常停机、断料和 SCRAM 不清空模块储能，也不改变补能规则或固定维持功率；模块在衰减期间继续按运行时的功率耗能，不能因为停止注入就停止约束高能球雷。供能规则见[启动消耗与磁场模块供能](总体设计.md#启动消耗与磁场模块供能)。

只有进入安全休眠后，才停止维持磁场及对应耗电，不另收待机耗电；各向缓存保留且仍可充能，下次手动启动再恢复建场。休眠后的正常撤场不视为模块断能或结构失约束，不因此累积危险度，也不因切换到休眠而清零既有余能或危险度。剩余危险度在整机加载条件满足时按固定速率逐步回落至 0，不要求继续供电维持磁场，也不需要等其归零才能按安全维护处理。

紧急停堆不是立即清除所有危险状态。如果既有运行失稳、结构不成型或模块断能已使约束接近崩溃，且球雷仍处于高能状态，停止注入后仍可能发生事故。单纯断料导致安全休眠，与既有高能失稳在断料或 SCRAM 后继续恶化，是不同情况。

停止注入、停止产出和进入安全休眠是不同状态。普通停机与 SCRAM 都沿用现有球雷余能继续计算，不能因按下停堆按钮而清零余能或瞬间恢复稳定度；只有完成安全衰减后才允许按安全维护处理，也只有进入安全休眠后才允许用新的胚核发起启动。

运行或衰减期间，稳定度恢复到失稳阈值及以上后，危险度使用与安全休眠相同的固定速率回落，不叠加模块配比加成，也不因执行 SCRAM 直接加速清除危险度。回落不自动恢复注入、不提前解除 SCRAM；建场或等待点火期间保留已有危险度，不因重新启动刷新。完整更新规则见[失稳推进与事故判定](运行模型与公式形态.md#失稳推进与事故判定)。

## 磁场模块断能与恢复

以下故障处理针对运行或停堆衰减期间仍需约束球雷的情况。外部供电中断但模块剩余储能仍能维持磁场时，反应堆继续按当前状态工作，不立即停机或判定失约束。任意一向模块已无法维持磁场时，立即停止燃料注入，并沿用结构失约束期间的处理：停止新产物生成，余能继续衰减，稳定度与危险度继续计算，不立即爆炸。模块断能不等于方块结构不成型，控制器应提示实际故障原因；建场期间供能不足仍按等待点火的规则处理，休眠时没有磁场不属于这类故障。

补能后各向模块重新具备维持磁场的能力时，约束按原有惯性恢复，不能清空余能或危险度。未进入 SCRAM 且仍处于衰减阶段时，按普通衰减期间的规则手动恢复注入；已进入安全休眠则走重启流程。SCRAM 不因补能或结构修复而解除；磁场不可用期间不享受主动加速耗散，仍按失约束规则处理。

## 区块卸载与读档恢复

区块卸载、退出世界和世界重载只暂停反应堆，不视为停堆、取消启动或拆除控制器。控制器保存球雷建立状态、余能、危险度、有效约束 K 的滞后值、启停阶段（含 SCRAM）、玩家设置的注入档位、本次启动结算进度，以及自身持有的输入和产物库存；六向储能由对应磁场装置各自保存，普通端口不保存第二份库存。读档不补满、清空或重复生成这些资源，也不把当前有效约束直接重置为目标值。

未加载或等待相关区块加载齐期间，暂停整机运行结算：不消耗燃料、启动资源或磁场维持能量，不生成新产物，不衰减余能，不推进约束变化，也不累计或回落危险度。恢复后不按离线时长补算产出、消耗、停堆进度或事故时间。

控制器所在区块已加载但结构涉及的其他区块尚未加载时，保持等待，不把未加载的方块判为缺块或模块断能，也不为恢复反应堆而强制加载区块。全部相关区块可用后，先检查实际结构、燃料与模块供能；确实缺块、缺料或断能时按现有规则处理，不凭存档中的旧成型状态直接恢复生产。

检查后按保存的阶段继续：

| 卸载前阶段 | 恢复行为 |
| --- | --- |
| 建场或等待点火 | 继续本次启动进度，只结算尚未完成的步骤；不重新要求或重复扣除已消耗的胚核、启动 FE、闪电或苦力怕 |
| 正常运行 | 运行条件仍满足时接着运行，不再执行点火流程；条件不满足则按现有缺料或失约束规则处理 |
| 普通停机衰减 | 接续原有余能和危险状态继续衰减，不自动恢复燃料注入 |
| SCRAM | 接续紧急停堆，不解除锁定，不恢复注入或新产物生成 |
| 安全休眠或尚未点火 | 保持原阶段，仍需玩家手动发起启动；安全休眠的危险度从保存值继续回落，不补算卸载期间的回落量 |

卸载期间的暂停不能重置危险度或解除 SCRAM；拆除控制器直接清除运行状态的规则仅适用于真实拆除，不适用于卸载。

## 约束崩溃的触发原则

真正的灾难性事故是球状闪电约束场彻底崩溃。事故由运行与结构状态决定，不以随机概率触发；稳定度低也不直接等于爆炸。

以下持续判定以控制器仍存在为前提。拆除控制器直接清除运行状态，不延续失约束倒计时，也不额外引爆；已经触发并开始结算的事故不因控制器随后被拆除或损毁而撤销。

约束崩溃区分以下两条恶化路径，满足其中任意一条的崩溃条件即可触发事故，不要求两条路径同时成立：

| 路径 | 失稳来源 | 判定边界 |
| --- | --- | --- |
| 运行失稳 | 高注入、高磁通、低均匀度等使实际反应负荷持续超出磁场控制能力 | 即使结构完整，也可能因持续超负荷而失去约束；不能仅凭某个参数偏高就直接判定爆炸 |
| 结构失约束（含模块断能） | 结构被拆除、损毁而不成型，或任意一向模块断能，使高能球雷失去约束 | 两种故障共用判定，不要求磁通同时很高；低 F 不能豁免事故 |

两条路径共用同一判据：运行或停堆衰减期间，稳定度 `S` 低于失稳阈值 `S_thr` 时累积危险度 `D`，只有球雷仍处于高能状态（`E ≥ E_high`）且危险度达到崩溃阈值（`D ≥ D_crit`），才进入灾难性崩溃。稳定度越低或场均匀度越低，危险度累积越快；不另外要求稳定度降到 0 或磁通达到 1。有效约束已经通过稳定度体现，不重复计入判定。燃料是否仍在注入不作为必须条件，停堆后的高余能同样需要约束。

两条路径都保留失稳惯性和抢救过程，不把结构不成型或模块断能直接等同于立即爆炸。重新成型或恢复供能不会瞬间恢复稳定度，降低注入也不会立即清空余能；抢救是否有效取决于能否在崩溃前恢复约束或降低余能。已经进入低能安全休眠时，拆装结构仍属于安全维护，不因结构暂时不成型而触发高能事故。

判定形态见[失稳推进与事故判定](运行模型与公式形态.md#失稳推进与事故判定)，具体阈值与危险度累积、回落速率仍待平衡，不承诺固定的爆炸倒计时。设计上区分普通断料、正常停机、设备故障和灾难性事故：缺少燃料会使反应衰减，无法约束仍处于高能状态的球雷才是爆炸风险。

## 事故后果

| 对象 | 后果 | 限制 |
| --- | --- | --- |
| 控制器 | 控制器必定损毁 | 控制器是唯一明确规定必毁的关键功能块 |
| 中央反应腔 | 部分框架、玻璃与端口损毁 | 不无条件删除整个反应腔，保留抢修价值 |
| 六向磁极门架 | 随机损坏部分磁极结构与功能模块 | 不无条件全部删除；损坏比例可随事故严重度提高 |
| 结构外周边 | 出现若干小范围次生爆炸，表现高能放电逸散 | 可以破坏附近管线和少量装饰，范围不以摧毁整个基地为目标 |
| 连接的 AE 网络 | 瞬间抽空受影响网络中可实际提取的全部高压闪电与极高压闪电，不设损失上限 | 抽空效果不清理 FE、普通物品、普通流体或其他 AE 网络资源，范围见下节 |

“事故不随机”约束的是触发机制；事故已经触发后，外围门架的具体受损位置可以随机，两者不冲突。

网络抽空的设定解释为：约束场崩溃后，球雷沿 AE 闪电网络的最低阻抗通路吸收网络中可用的闪电能源，并在崩溃中释放。

灾难性事故清除球雷建立状态，后续必须重新完成首次点火。

### AE 网络抽空范围

受影响网络按灾难性约束崩溃正式触发瞬间，反应堆端口的实际有效接入关系确定，在结构损毁与次生爆炸执行前锁定范围并完成闪电抽空。触发后断开连接不撤销损失，事故自身造成的端口或线缆损毁也不改变本次结算范围；不使用已失效的端口绑定追溯旧网络。

| 接入情况 | 处理范围 |
| --- | --- |
| 多个端口接入同一网络 | 按实际网络身份去重，该网络只结算一次，不按端口数量重复计算损失 |
| 反应堆接入多个独立网络 | 分别处理每个实际接入的网络，不任选其中一个，也不按距离波及附近未接入的网络 |
| 子网或外部存储向接入网络暴露库存 | 通过受影响网络的存储接口可实际提取的两档闪电纳入范围；只看当前可访问资源，不另行沿线搜索或跨网传播 |
| 触发前已完全隔离的网络或库存 | 不受本次抽空影响；完全隔离要求既没有反应堆直接接入，也不再向受影响网络暴露可提取的相关库存，仅换成独立网络名称不代表已经隔离 |

本次损失以存储接口实际提取成功的数量为准，不能把显示库存或模拟提取结果直接当作已扣除量。多个网络访问同一份外部库存时，同一份闪电只能实际扣除一次，也不能重复计入事故损失或释放量；不直接按各网络显示的库存求和后强制清空底层存储。

只处理本次触发范围内可提取的高压闪电与极高压闪电，不追踪事后新接入的网络或新流入的资源，不修改其他资源。普通端口的日常吞吐限额不限制这笔事故结算，也不改变上述可访问范围与实际扣除要求。网络闪电损失不设数量上限，不代表实体爆炸范围无限扩大，结构损毁与次生爆炸仍受原有范围约束。

网络识别、资源提取及共享库存去重的具体接口与实现验证仍见[待定事项](待定事项.md)，不新增端口种类、隔离模块或网络传播机制。

## 事故后恢复

1. 修复中央反应腔。
2. 修复六向磁极门架。
3. 重新放置控制器。
4. 准备并装入新的球雷胚核。
5. 重新准备闪电苦力怕。
6. 补足燃料、启动闪电与 FE，并为各向磁场模块充能，满足最低启动条件，重新完成首次点火。

事故会增加结构维修、闪电苦力怕准备和网络闪电损失，恢复时还需承担每次启动的常规耗材。损毁比例与次生爆炸范围留待平衡。
