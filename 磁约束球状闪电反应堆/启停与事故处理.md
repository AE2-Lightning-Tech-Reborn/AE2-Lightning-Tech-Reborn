# 磁约束球状闪电反应堆启停与事故处理

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

## 首次点火

首次建立球状闪电需要同时具备：

1. 完整的中央反应腔。
2. 六套完整且核心在线的磁极阵列。
3. 放入控制器、供本次启动消耗的新球雷胚核。
4. 高能相变燃料。
5. 一只闪电苦力怕。
6. 满足最低磁场启动条件。
7. 具备启动所需闪电与外部 FE，且停堆储能达到最低启动要求。

闪电苦力怕提供首次建立球雷所需的活体雷电现象与初始高能扰动。具体的放置、识别、融合过程以及点火演出后续定义。

## 胚核消耗与球雷建立状态

球雷胚核是每次启动都要消耗的材料。首次点火、正常停机后重启、断料后恢复和事故后重新点火，均需装入新的胚核。

启动条件检查不通过时不消耗胚核。检查通过并正式进入点火时扣除本次胚核；此后启动失败、取消启动或停机均不返还。

首次成功点火后获得“球雷已建立”状态。正常停机、燃料耗尽、安全完成的 SCRAM 和安全维护保留该状态；这里的“熄火”表示反应衰减并进入休眠。建立状态与胚核物品分开记录，保留状态不能免除下次启动的胚核消耗。

球雷建立状态保留时，无需重新准备闪电苦力怕。灾难性约束崩溃会清除该状态，恢复时需重新完成首次点火流程。

## 停机与恢复运行

首次点火，以及正常停机、断料或事故后的恢复，均由玩家在控制器上手动发起。补充胚核、燃料、启动能源或修复结构不会自动开堆。

| 情况 | 处理过程 | 结果与边界 |
| --- | --- | --- |
| 正常停机 | 立即停止燃料注入，受控释放余能，产出随实际反应负荷逐渐降低，直至安全休眠 | 保留余能利用，停堆过程相对较慢；保留球雷建立状态，重启需新的胚核 |
| 单纯燃料耗尽 | 停止燃料注入，按普通停机路径释放余能，产出逐渐降低并进入休眠 | 单纯断料不触发爆炸，恢复需新的胚核 |
| 恢复运行 | 确认结构完整、燃料充足，补入新的胚核，并满足启动闪电、FE、停堆储能及磁场条件后，由玩家手动启动 | 消耗本次胚核 |
| 紧急停堆（SCRAM） | 立即停止燃料注入和新产物生成，优先调用停堆储能，通过磁场系统主动加速余能耗散 | 放弃剩余产出以争取更快休眠；不能保证在严重事故条件下成功 |

在同等初始状态、结构与约束仍可控的条件下，SCRAM 应比普通停机更快降低余能并进入安全休眠。它使用现有磁场系统和内部停堆 FE 储备，不额外引入冷却剂、新耗材或运行期外部 FE 依赖。停止新产物生成不清空已有库存，也不阻断已有库存的正常外部提取。

正常停机、断料和 SCRAM 后，内部停堆 FE 储备继续为磁场供能，支持对残余高能球雷的约束。最低预充量必须满足正常负荷下的安全停堆底线；两种停堆方式的功率、耗时与储能不足时的处理仍待细化，见[磁场供能与停堆储能](总体设计.md#磁场供能与停堆储能)。

紧急停堆不是立即清除所有危险状态。如果既有运行失稳或严重阵列损坏已使约束接近崩溃，且球雷仍处于高能状态，停止注入后仍可能发生事故。单纯断料导致安全休眠，与既有高能失稳在断料或 SCRAM 后继续恶化，是不同情况。

停止注入、停止产出和进入安全休眠是不同状态。普通停机与 SCRAM 都沿用现有球雷余能继续计算，不能因按下停堆按钮而清零余能或瞬间恢复稳定度；只有完成安全衰减后才允许按安全维护处理。

## 约束崩溃的触发原则

真正的灾难性事故是球状闪电约束场彻底崩溃。事故由运行与结构状态决定，不以随机概率触发；稳定度低也不直接等于爆炸。

约束崩溃区分以下两条恶化路径，满足其中任意一条的崩溃条件即可触发事故，不要求两条路径同时成立：

| 路径 | 失稳来源 | 判定边界 |
| --- | --- | --- |
| 运行失稳 | 高注入、高磁通、低均匀度等使实际反应负荷持续超出磁场控制能力 | 即使结构完整，也可能因持续超负荷而失去约束；不能仅凭某个参数偏高就直接判定爆炸 |
| 结构失约束 | 磁极阵列严重损坏，剩余有效约束不足以控制现存高能球雷 | 不要求磁通同时很高；低 F 不能使仍处于高能状态的球雷免于结构失约束事故 |

两条路径都结合球雷余能、有效约束能力、稳定度和危险状态持续时间判定：球雷仍处于高能状态，约束持续不足，稳定度恶化至极低并达到相应持续触发条件，才进入灾难性崩溃。燃料是否仍在注入不作为必须条件，停堆后的高余能同样需要约束。

两条路径都保留失稳惯性和抢救过程，不把拆除一个模块直接等同于立即爆炸。补齐结构不会瞬间恢复稳定度，降低注入也不会立即清空余能；抢救是否有效取决于能否在崩溃前恢复约束或降低余能。已经进入低能安全休眠时，拆装模块仍属于安全维护，不因结构暂时不完整而触发高能事故。

各路径的具体阈值、持续时间与判定公式尚未确定。设计上区分普通断料、正常停机、设备故障和灾难性事故：缺少燃料会使反应衰减，无法约束仍处于高能状态的球雷才是爆炸风险。

## 事故后果

| 对象 | 后果 | 限制 |
| --- | --- | --- |
| 控制器 | 控制器必定损毁 | 控制器是唯一明确规定必毁的关键功能块 |
| 中央反应腔 | 部分框架、玻璃与端口损毁 | 不无条件删除整个 7×7×7 结构，保留抢修价值 |
| 六向磁极阵列 | 随机损坏部分磁极结构与功能模块 | 不无条件全部删除；损坏比例可随事故严重度提高 |
| 结构外周边 | 出现若干小范围次生爆炸，表现高能放电逸散 | 可以破坏附近管线和少量装饰，范围不以摧毁整个基地为目标 |
| 连接的 AE 网络 | 瞬间抽空其中全部高压闪电与极高压闪电，不设损失上限 | 抽空效果不清理 FE、普通物品、普通流体或其他 AE 网络资源 |

“事故不随机”约束的是触发机制；事故已经触发后，外围阵列的具体受损位置可以随机，两者不冲突。

网络抽空的设定解释为：约束场崩溃后，球雷沿 AE 闪电网络的最低阻抗通路吸收网络中可用的闪电能源，并在崩溃中释放。

受影响网络按灾难性约束崩溃正式触发瞬间的实际连接关系确定，在结构损毁与次生爆炸执行前锁定范围并完成闪电抽空。触发前已与反应堆完全隔离的网络不受本次抽空影响；触发后断开连接不撤销损失，事故自身造成的端口或线缆损毁也不改变本次结算范围。

多端口、多网络、子网与外部存储的具体归属及清空实现，见[待定事项](待定事项.md)。

灾难性事故清除球雷建立状态，后续必须重新完成首次点火。

## 事故后恢复

1. 修复中央反应腔。
2. 修复六向磁极阵列。
3. 重新放置控制器。
4. 准备并装入新的球雷胚核。
5. 重新准备闪电苦力怕。
6. 补足燃料、启动闪电与 FE，满足最低启动条件，重新完成首次点火。

事故会增加结构维修、闪电苦力怕准备和网络闪电损失，恢复时还需承担每次启动的常规耗材。损毁比例与次生爆炸范围留待平衡。
