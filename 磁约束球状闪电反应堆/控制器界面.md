# 磁约束球状闪电反应堆控制器界面

[文档首页](../README.md) · [反应堆设计目录](设计目录.md)

本页确定控制器的信息分层、操作入口与状态反馈，不规定最终贴图、像素尺寸或控件样式。界面只展示和操作既有反应堆规则，不增加运行模式、自动调参或独立监控系统；结构数量和位置从最终模板读取，不把当前候选结构写死在界面中。

## 页面分层

采用一个总览页与三个详情页，通过同一层标签切换，不再嵌套多级子界面。长列表在所属页面内滚动，数值解释使用悬停提示或就地展开。

| 页面 | 主要用途 | 保留的信息 |
| --- | --- | --- |
| 总览 | 判断当前是否正常、调整负荷和执行启停 | 运行阶段、安全状态、注入、余能、供能摘要、实际产出、当前主要问题 |
| 资源 | 查看库存、启动消耗与输入输出 | 胚核槽、燃料、启动 FE 与闪电、四类产物及实际吞吐 |
| 磁场 | 查看配比、参数和逐向供电 | 三类模块数量与占比、C／U／F、各向储能与维持状态 |
| 诊断 | 解释不能启动、不能恢复或正在失稳的原因 | 条件清单、结构与端口问题、运行参数明细、规则说明 |

所有页面共用顶部状态栏：当前阶段、最重要的一条异常、其余异常数量，以及紧急停堆入口。点击异常跳转到对应详情；不能把正在发生的危险只藏在诊断页。状态用文字与图标说明，颜色只作辅助。

运行阶段与故障原因分开显示，例如“普通停机衰减 · 磁场供能不足”“SCRAM · 磁场不可用”。等待区块加载是暂停提示，仍注明原阶段，不把 SCRAM 或启动进度替换成一个含义不明的“故障”状态。

## 总览

总览围绕“能否安全运行、现在生产多少、需要做什么”组织，不铺开全部公式。固定显示下列摘要，点击对应区域进入详情页。

| 信息组 | 默认显示 | 说明 |
| --- | --- | --- |
| 当前阶段与维护 | 未启动、建场／等待点火、运行、普通停机衰减、SCRAM、安全休眠；维护状态为可维护／不可维护／待确认 | 只有未启动且没有进行中的启动流程，或已安全休眠时，才提示可进行常规结构维护；数据未验证时显示待确认，不能仅凭瞬时注入为 0 判定安全 |
| 运行安全 | 稳定度数值与状态文字；存在危险积累时突出危险度及累积／回落／保持状态 | 危险度表示距崩溃阈值的积累程度，不是爆炸概率；不能只显示稳定度而隐藏已有危险度 |
| 球雷余能 | 当前余能、上升／下降／保持状态，以及是否已降至安全休眠范围 | 不把余能画成具有固定容量的 FE 电池；实际阶段仍由运行逻辑决定，不因数值暂低就显示已休眠 |
| 燃料注入 | 设定档位、目标用量与实际用量，附燃料库存摘要 | 用量显示为 mB/t 等实际燃料单位；内部能量注入率 `I` 放入详情，不与 FE/t 混用 |
| 磁场供能 | 各向简明状态及异常方向 | 区分正在维持、缓存维持但输入不足、无法维持、休眠待机、未加载／未验证；不只用六向储能总和判断供能是否正常 |
| 实际产出 | FE、高压闪电、极高压闪电、原生等离子体四项实际生成速率及满缓存标记 | 此处是成功生成到控制器缓存的量，不是外部已提取量；两档闪电分别显示，不合成含义不清的总产率 |

建场时，注入区域改为本次启动阶段与已结算进度，并给出等待原因和资源页入口；不同时展示一整屏尚未发生的运行读数。运行后恢复注入显示，不新增启动专用页面。

未启动或安全休眠时，稳定度位置显示“不适用／安全休眠”，不以撤场后的低稳定度显示濒临崩溃，也不伪造 100% 稳定度。安全休眠但危险度仍大于 0 时，注明“残留危险度回落中”，不因此将维护状态改成不可维护；余能与危险度的真实记录仍可在诊断页查看。等待区块加载时明确显示暂停，危险度改为保持／暂停，缺失数据标为未验证，不能沿用旧绿灯宣称可以启动或安全维护。

常规维护提示不改变拆除控制器的特殊规则，也不禁止玩家挖掘方块；控制器拆除会清除运行状态并要求重新首次点火，说明放在诊断页，不作为新的“消除危险”按钮。

## 操作与阶段

日常操作集中在总览；紧急停堆固定可见于所有页面。只保留已有操作，不增加磁场开关、危险度清零、自动换档或按生产倾向切换的按钮。

| 操作 | 可用场景与反馈 |
| --- | --- |
| 选择注入档位 | 显示目标燃料用量；改变设定不等于启动或恢复注入，停机及 SCRAM 期间不会因此解除停机状态；不按当前配比安全上限锁死档位 |
| 启动 | 未启动或安全休眠时显示；条件不满足则禁用，并在按钮旁写明主要缺项，可展开完整条件清单 |
| 恢复注入 | 普通停机衰减期间替代启动入口；检查现有恢复条件，不重复要求胚核、启动 FE 或启动闪电 |
| 普通停机 | 正常运行时可用；执行后立即标明已停注入、仍在衰减，不显示成安全休眠 |
| 取消启动 | 建场或等待点火时替代启动入口；明确提示已消耗资源不退还，不把未消耗库存写成已损失 |
| 紧急停堆 | 运行或普通停机衰减期间可用；无需切换页面或多层确认，进入 SCRAM 后显示锁定；磁场不可用时仍可发起，并提示当前不能主动加速耗散，而不是因缺电禁用抢救操作 |

禁用按钮必须有明确原因，不能只有灰色。SCRAM 期间不提供取消、恢复注入或重新启动入口；安全休眠后才重新按启动条件处理。不以危险度尚未归零额外禁用启动或普通衰减中的恢复注入，只提示将继承当前危险度；危险度归零也不提前解除 SCRAM。切换页面、关闭界面或补齐缺项都不会代替玩家发起新的启动或恢复注入；已手动发起的建场／等待点火流程则按原有步骤继续，不要求玩家因补齐缺项重新点击启动。

## 资源

输入与产物分组显示，避免把不同用途的能量合成一根“整机电量”条。

| 分组 | 显示内容 | 边界 |
| --- | --- | --- |
| 球雷胚核 | 控制器已有胚核槽与未消耗数量 | 使用同一个真实槽，不为界面新增库存；本次已扣胚核在启动进度中标为已结算，不继续报缺少胚核 |
| 运行燃料 | 库存／容量、实际输入量、目标与实际消耗量 | 库存充足不代表负荷安全；燃料耗尽后注明需手动恢复，不因补料自动恢复 |
| 启动 FE 与闪电 | 各自输入库存／容量、实际输入速率；启动时列出本次需求、已结算与尚待消耗的部分 | FE 缓存只表示未消耗电量，不与已完成的启动进度、发电缓存或磁场储能相加；闪电类型与单位沿用资源定义 |
| 四类产物 | 各自库存／容量、实际生成速率、外部实际提取速率、是否存满 | FE 与两档闪电、原生等离子体分别列出；端口共享库存，不按端口数重复统计容量 |

各缓存的输入／输出读数旁可展开查看整机每 tick 共享上限，说明多个同类端口共用该值，不按端口数相乘，也不提供分配额度的操作项。接口达到本 tick 吞吐上限与库存已满／已空分别提示，不把接口限流写成反应堆故障；规则见[共享吞吐](结构与磁场系统.md#共享吞吐)。

生成与外部提取分列：产物存满、SCRAM 或失约束导致新生成停止时，缓存仍可能被外部取走，不能统一写成“无输出”。满缓存提示说明仅停止该产物生成、燃料不会因此自动停耗；既有产出规则见[产物存满与恢复](产出与运行参数.md#产物存满与恢复)。

资源页只复用已有胚核槽；其他资源为库存与流量读数，不借此新增手动灌入、抽取或转移能源的渠道。六向磁场储能在磁场页逐向查看。资源页附简短提醒：“拆除控制器会丢失自身流体与能源缓存；未消耗胚核正常掉落。”详情遵循[拆除与库存处理](结构与磁场系统.md#拆除与库存处理)，不新增打包或退款按钮。

## 磁场

上部显示增幅、稳定、调制三类功能模块的总数量与配比，以及约束强度 C、场均匀度 U、磁通水平 F。参数用中文名称配数值显示，悬停补充作用与代价；C／U／F 只读，不做成滑条。F 到顶说明为磁通饱和，不单独标成“必炸”。

下部按方向逐行显示磁场装置，不再为每个方向开子页：

| 字段 | 显示要求 |
| --- | --- |
| 方向与结构 | 方向名称、装置位置、已验证的结构／绑定状态；未加载与真实缺块分开 |
| 独立储能 | 本向 FE 储量／容量，不借用其他方向电量填补显示 |
| 实际接收 | 本向实际收到的 FE/t，而非接口宣称的最大接收能力；接收上限放在悬停详情 |
| 维持需求与消耗 | 固定维持功率、当前实际消耗；休眠显示待机且消耗为 0，不把有电误写成已维持磁场 |
| 当前状态 | 能否维持本向磁场、缓存正在增加／减少／保持，以及供能不足原因 |

仅观察到接收量为 0 时，写“当前未收到 FE”，不能断言外部线路断开；缓存已满也可能暂时不接收。实际输入低于维持需求但缓存仍够用时，提示“缓存维持，补能不足”；只有实际不能维持磁场才报断能故障。不能因为另外几向还有电，就把故障方向合并成整机供能正常。

模块只按总配比参与计算，逐向列表用于定位供能与结构问题，不暗示把功能模块换个方向会增加收益。缓存属于各向装置，界面只读状态，不提供自动均分或一键转移电量。

## 诊断

默认展开当前异常与当前操作的条件清单，其他内容按需展开。提示以“原因、影响、处理方式”组织，同一原因合并显示，不把每个相关数值都变成一条报警。

| 区域 | 包含内容 |
| --- | --- |
| 当前异常 | 失约束、危险度积累、磁场补能不足、燃料耗尽、产物存满等实际状态；危险问题优先于启动缺项与资源提示，已解决问题不继续冒充当前故障 |
| 启动／恢复条件 | 按当前阶段列出结构、燃料、磁场与所需启动资源；首次点火才检查闪电苦力怕，休眠重启与衰减恢复不混为一套清单；本次已结算资源标记完成，不重复要求 |
| 结构与端口 | 成型结果、已检测到的缺块／错误部件及相对位置；端口的位置、模式、绑定与对应接口状态；未加载标记等待，不生成虚假的缺块清单 |
| 运行明细 | 球雷建立状态、当前阶段及 SCRAM 锁定、`I`、`E`、`R`、`K`、`L`、`S`、`D` 与实际使用的阈值；明确区分当前值、阈值和设定值，不开放修改内部参数 |

运行明细需要能解释两件事：当前约束负担为什么使稳定度降低，以及“高余能”和“危险度到阈值”这两个事故条件目前各自是否满足。危险度达到阈值不等于脱离余能条件也会爆炸；正常休眠撤场不作为故障处理。

典型提示保持直接，例如：

- “东向磁场无法维持：已停止注入和新产物生成；仍有余能，请恢复供能。”
- “燃料已耗尽：正在普通停机衰减；补料后需手动恢复。”
- “SCRAM 进行中：磁场不可用，当前仅按普通速率耗散；恢复供能可恢复加速，但不会解除 SCRAM。”
- “启动已消耗胚核，等待启动闪电；不会重复扣除胚核。”
- “极高压闪电缓存已满：该产物暂停生成，其他产物与燃料消耗按原规则继续。”
- “等待相关区块加载：整机结算暂停，保留原运行阶段。”

结构与端口列表只用于查看和定位，不增加自动搭建、批量改模式或新的资源路由功能。AE 事故损失说明遵循[网络抽空范围](启停与事故处理.md#ae-网络抽空范围)：接入网络可实际提取的外部库存同样有风险，不能仅凭子网名称或存储位置承诺已经隔离；未验证可访问性时明确标为未验证，不新增全网探测页面。也不新增事故历史数据库或控制器拆除后仍保留的运行档案。

## 数据与显示边界

- 主界面采用短名称和适当缩写，悬停显示精确数值、单位与解释；资源单位沿用实际定义，不预设尚未确定的平衡数值或余能单位。
- 所有读数来自控制器及各向装置的实际状态。速率统计使用已成功结算的量，不把计划注入、理论产率、接口上限或模拟提取结果当作实际吞吐。
- 不提供精确爆炸倒计时、保证安全的剩余运行时间或自动配比推荐；趋势仅反映当前变化，不增加一套预测与历史曲线系统。
- 区块未加载、关联失效或状态尚未同步时显示未知／待验证；若保留上次读数，必须标明不是当前确认值。暂停期间不把旧速率继续显示成正在生产，也不因打开界面推进结算或强制加载区块。
- 服务器决定按钮是否可用，并在执行时重新检查当前阶段、条件和控制器身份；客户端只提交操作意图，不能靠旧界面绕过 SCRAM、重复扣启动资源或读写已失效的库存引用。
- 页面切换只改变展示；不复制库存、不增加第二份运行状态、不重置危险度，也不因打开或关闭界面自动启停。

各按钮的实际行为以[启停与事故处理](启停与事故处理.md)为准，数值含义以[运行模型与公式形态](运行模型与公式形态.md)为准。
