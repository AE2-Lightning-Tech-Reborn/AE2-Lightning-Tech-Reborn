## 后续验证重点

在相应实现或数值具备后，按正文规则验证以下边界，不另起一套事故或验收机制：

| 范围 | 验证重点 |
| --- | --- |
| 运行与产出 | 长期稳定运行、正常持续发电的净 FE 收益、F 饱和后继续升负荷、不足一个 tick 的余料按实际量结算、断料普通停机，以及输出存满不堵余能衰减 |
| 磁场与停堆 | 外部断电但缓存仍足够、任意一向断能及补能恢复、SCRAM 后修复不解除锁定、休眠停耗与继续充能 |
| 卸载与恢复 | 建场、运行、普通停机和 SCRAM 的重载续算；跨区块等待不误判缺块，暂停不结算 E／K／D，启动资源不重复扣除 |
| 拆除与库存 | 未消耗胚核掉落、控制器其他自身缓存清空、未拆磁场装置保留充能、端口不带走库存、储能磁场装置仅清空本向 FE；与正常卸载和取消启动区分，不通过掉落物 NBT 或切模式恢复已清理库存 |
| 危险度 | 阈值两侧及等于阈值时的累积／固定回落、最低为 0、休眠撤场后回落、重启继承、卸载暂停；不额外阻止启动或维护，不提前解除 SCRAM |
| 端口吞吐 | 同 tick 多端口／多接口共享、切模式或增减端口不重置额度、不同缓存互不抢额、模拟调用不扣额度 |
| 网络抽空 | 同网去重、多网共库不重复扣、子网与外存可提取范围、完全隔离、触发前后断线；只抽两档闪电，不受日常吞吐限制 |
| 界面反馈 | 阶段按钮与既定流程一致，主要危险常驻可见，未加载数据不误报，实际生成与外部提取分列 |
