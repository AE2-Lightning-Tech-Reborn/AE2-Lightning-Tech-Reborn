# 磁约束球状闪电反应堆待定事项

## 原草案保留的设计事项

以下内容尚未确定，不把示例数值或定性关系当成最终实现规格。

| 主题 | 待设计内容 |
| --- | --- |
| 高能相变燃料 | 具体配方、制作产线、每桶／每 mB 能量价值、消耗与注入速度 |
| 球雷胚核 | 具体配方、是否使用现有终局材料、制作成本 |
| 原生等离子体后续体系 | 分化种类、加工机器、配方、终局合金与材料体系、材料简化配方 |
| 基础产出 | FE/t、高压闪电产率、极高压闪电产率及其占比、原生等离子体产率 |
| 模块与磁场 | 三类模块系数、C／U／F 最终公式、相互影响与损失计算 |
| 运行负荷与稳定度 | 各生产倾向的可持续安全负荷范围、燃料注入档位、最低启动条件、有效约束与运行负荷的计算、稳定度公式、状态阈值及惯性变化速度 |
| 球雷余能 | 计量方式、积累与耗散公式、与实际反应负荷及产出的对应关系、升降负荷速度、安全休眠阈值；不得重复结算已生成的产物 |
| 启动消耗 | 已确定每次启动消耗新的胚核、闪电与 FE，正常运行只消耗燃料；待定启动闪电档位与用量、FE 功率及启动耗时 |
| 停堆储能 | 已确定启动预充且正常运行不扣减；待定满足正常负荷安全停堆底线的容量与最低预充量，以及异常情况下储能不足或耗尽时的处理规则 |
| 停堆过程 | 普通停机与 SCRAM 各自的 FE 功率、耗时、余能耗散速度，以及普通停机期间产出衰减的具体规则 |
| 事故数值 | 运行失稳与结构失约束各自的阈值、持续触发时间及抢救窗口，损坏比例、事故严重度、次生爆炸数量和范围 |
| 中央结构 | 7×7×7 外壳逐层模板、削角形状、控制器与端口的合法替换位置 |
| 外围结构 | 磁极阵列最终固定距离及坐标定义，空隙格数的计量口径 |
| 视觉与演出 | 球雷模型、光束、粒子、材质、发光、报警、点火过程与爆炸效果 |

## 整理时识别出的待补充边界

这些问题用于后续完善草案，不代表已经新增玩法或确定实现方式。

| 边界 | 需要明确的问题 |
| --- | --- |
| 闪电苦力怕参与点火 | 放置位置、识别范围、融合流程及点火失败时如何处理；与反应空间的方块检查分开定义 |
| 启动能源结算 | 闪电与 FE 的扣除方式和时机，以及启动失败或取消后剩余能源的处理规则 |
| 休眠与状态保存 | 普通维护和世界重载时，启动结算状态、球雷建立状态、余能、稳定度、停堆储能及运行／停堆阶段的保存和恢复 |
| 产物缓存与输出接入 | 各产物缓存容量与外部输出的接入方式 |
| AE 网络归属与抽空实现 | 多端口、多网络、子网及外部存储接入时的闪电归属；如何执行全量抽空而不影响其他资源 |
| 实现接入 | 反应堆的具体实现方式，以及与现有多方块能力或未来通用框架的关系 |

## 当前示例的使用边界

- 约 4 格阵列空隙是结构建议，最终距离固定且六向一致。
- `25% / 50% / 75% / 100% / 125%` 是注入档位示例，不是确定的倍率或流量。
- 稳定度的五档区间用于表达反馈层次，最终阈值、变化速度和事故触发时间仍待平衡。
- 模块作用和产出关系仅确定方向，不隐含线性叠加公式，也不确定最终收益系数。
