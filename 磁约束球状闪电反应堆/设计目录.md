# 磁约束球状闪电反应堆设计目录

[文档首页](../README.md)

项目：AE2 Lightning Tech Reborn。设计版本：v0.1。状态：整体设计草案，不代表相关功能已经实现或发布。

磁约束球状闪电反应堆是终局大型多方块设施。玩家通过磁场模块配比和燃料注入率，在 FE、现有闪电与原生等离子体三种产出方向之间取舍，并承担相应的失稳风险。

多方块结构尚未定稿。本文档中的反应腔尺寸与轮廓、六向门架、48 个模块槽及相关布局均按当前暂定方案描述，不作为最终建造规格；结构条件与数量随最终模板统一修订。
